## 1. 作品与赛道

- 作品：**Axiom 学习白板**
- 选择赛道：**赛道 1「学业赋能」**
- 核心问题：学习资料通常把文字、公式和图形割裂开；Axiom 把文字作为知识主干，把函数、几何和公式推导放在主干两侧，并让它们围绕同一个变量联动。
- 当前目标：以定积分面积和拉格朗日乘数法两条人工精修场景作为精品基准，同时保留一套覆盖数学、物理、自然科学与人文学科的通用结构化白板。

## 3. 当前半成品是什么

当前包含两层能力，二者承担不同任务：

1. **精品基准**：`calculus_area_v1` 与第二条精品基准 `lagrange_multiplier_v1` 都经过人工编排和数学复核。精确命中拉格朗日乘数法、约束极值与梯度平行这一教学目标时，Axiom 在调用扣子前直接选择本地精品场景，因此即时返回且不消耗扣子积分；拉格朗日插值、拉格朗日力学等相邻主题不会被误替换。
2. **通用生成**：扣子 v2 负责未命中精品场景的其他数学、物理、自然科学与人文学科目标，并输出严格 `scene_spec`。贝叶斯、光合作用和拉格朗日乘数法曾完成真实试跑或页面端闭环，证明同一工作流可以跨学科运行；但通用原语当前的视觉编排和推导表现仍低于两条人工精修基准，不能宣称已经自动达到同等质量。

页面不是首页、仪表盘或产品介绍页。打开 `/board` 后直接进入知识内容，只有顶部一行学习目标输入；教材/笔记输入默认折叠，技术状态默认折叠并放在全文之后。

当前受支持的内容与演示：

- `calculus_area_v1`：保留的定积分精品场景。
- `lagrange_multiplier_v1`：第二条精品基准；文字沿“约束运动 → 切向变化率 → 梯度平行 → 联立求候选 → 结论边界”推进。
- `structured_scene_v2`：通用场景，正文可组合段落、定义、公式、关键推导、例题、列表与比较表。
- 拉格朗日精品场景新增一组可复用知识语法：共享 `theta`、约束曲线、等高线与交点 `P/Q` 合并、切向量和两个梯度同步，以及保留公式项身份的语义公式变形。这些能力当前首先在精品场景中验证，尚未全部进入 `structured_scene_v2` 的自动生成合同。
- 演示原语包括公式变换、函数图像、几何图、受力图、概念图、时间线、概率条形图和过程图。通用场景若只返回正文推导，Axiom 会从首条至少三步的关键推导确定性补出侧栏关键步动画；动画进入视野后才播放且可重演，普通两步代数不自动动画化。
- 文字负责定义、问题、推导和结论，是学习路径的主干。
- 左右两侧承载函数、几何、黎曼和与公式变换演示。
- 支持纯白与暗色背景翻转。
- 离线内置定积分、拉格朗日乘数法、导数、贝叶斯公式、牛顿第二定律和英国工业革命样例，用来验收确定性展示与跨学科渲染；未精确命中精品基准的实时主题仍由扣子 v2 生成。
- 如果扣子没有配置且主题没有匹配的离线样例，系统明确提示需要连接工作流，不再用不相关的白板冒充成功。

### 两阶段学习动作底座（2026-08-09）

在文字主干之外，通用白板已经完成前两阶段的非文本能力。它们不是额外堆卡片，而是把静态文字看不见的“变化、约束、误差和因果方向”外显出来：

**第一阶段｜统一学习动作底座**

- 所有动态演示共用播放、暂停、单步、拖动进度、倍速与重演时间轴；只有进入视野后才自动开始，减少离屏播放和寻找起点的摩擦。
- 正文 block 与图中的曲线、向量、读数使用白名单 semantic id 双向联动；聚焦正文时只强调对应图元，操作图元时也能反向定位概念。
- 同一 parameter id 进入共享参数总线，一个滑杆可同步驱动图像、向量、数值和公式；同名实验全页只有一个自动播放 driver，手动操作会夺回控制，后端同时拒绝范围、步长或单位冲突的同名参数。
- prediction 采用“预测一次 → 揭示同一演示 → 解释差异”，允许直接跳过；不要求信心评分，不累计分数，不把错误做成惩罚。

**第二阶段｜四类可复用知识演示**

- `linked_lab`：一个参数同步驱动曲线、向量、读数和公式，用于函数共变、运动关系、波与物理量联动。
- `limit_microscope`：拖动 `h` 观察割线趋向切线、近似值和误差；用三个尺度比较左右差商，只有稳定同收敛时才画切线，明确分离或发散时判为不存在，证据不足则显示“当前尺度尚未收敛”。
- `constraint_geometry`：只允许点沿约束轨迹拖动，并持续显示不变量；当前基准为同弧圆周角。
- `field_experiment`：同步磁场、磁通、电动势、方向与时间曲线；物理变化时间和观看动画时长彼此独立。

电磁感应离线基准同时覆盖共享参数、场实验、对象联动和预测；数学离线基准同时覆盖极限显微镜与约束几何。新合同、渲染器和本地回归已经通过，比赛 VPS 的备用页面与异步生成网关也已同步；但已发布扣子 v0.0.7 的场景写作提示仍未完整吸收所有新增原语规则，扣子项目内前端源码也尚未同步本轮版本门。因此不能把“本地可渲染”或一次真实成功误写成“任意实时主题已经稳定生成”。

## 4. 为什么不让模型直接生成整张网页

生成入口先做精确主题路由。命中已登记的本地精品路由（当前新增的是拉格朗日乘数法）时直接返回确定性场景；其余目标才进入扣子通用工作流：

```text
学习目标 / 教材
        ├── 精确命中拉格朗日精品主题 → 本地确定性场景（即时、0 扣子积分）
        └── 其他主题
                    ↓
扣子学习路径工作流
        ↓
JSON scene_spec（正文、公式、演示参数）
        ↓
Axiom 后端校验类型、数量、引用、LaTeX 与安全表达式
        ↓
确定性通用白板渲染器
```

模型不得输出 HTML、JavaScript、CSS、SVG path、URL 或布局坐标。文字始终按学习路径竖向排列，演示只通过章节 ID 锚定左右位置。豆包 2.0 Lite 只负责精简路径规划，GLM-4.7 负责完整场景写作；Axiom 的确定性校验负责结构与执行安全，并在不破坏正文的前提下丢弃单个无效演示。它不能替代学科正确性评测。
