# 专题四：战略前瞻与机会发现

> 核心命题：Axiom 不应预测一个确定未来，而应持续辨认结构变化、维护多种情景，并发现与用户独特能力相匹配的可逆不对称行动。

## 0. 产品结论

“分析社会局势、发现机会”最容易退化成三个低质量产品：新闻摘要、趋势榜单和自信预测。Axiom 应做的是：

```text
从信号中识别驱动力
→ 从驱动力构造多种相容未来
→ 找出情景之间共同稳健与分歧最大的部分
→ 与用户能力、约束、价值和时间窗口相交
→ 形成可小步验证的机会论文
```

它不是替用户下注，而是提高“看见变化、保留选择、及时更新”的能力。

## 1. 社会局势应被建模为多尺度耦合

至少同时观察：

- 技术能力与成本曲线。
- 资本、产业链与商业激励。
- 法律、制度与治理能力。
- 人口、教育与劳动力结构。
- 文化叙事、信任与群体行为。
- 基础设施、能源与生态约束。
- 地缘关系与供应安全。
- 用户所在地区、行业与个人网络。

任何单尺度解释都容易过度外推。例如技术可行不等于制度采用，舆论热度不等于付费需求，资本涌入也不等于长期价值。

## 2. 从信号到驱动力

### 2.1 信号

局部观察：政策文本、成本变化、人才流动、用户行为、研究突破、失败案例。

### 2.2 趋势

一段时间内方向相对稳定的变化。

### 2.3 驱动力

能持续塑造多个趋势的机制，如成本下降、激励重排、约束解除或资源短缺。

### 2.4 结构变化

驱动力之间的关系改变，导致旧规则不再有效。

Axiom 必须清楚标注当前处于哪一层。把单条新闻直接升级成时代转折，是机会系统最危险的叙事跳跃。

## 3. 情景不是预测的委婉说法

每个重要议题应维持一个小型情景集合：

```text
基线延续：主要驱动力按当前方向发展
加速转变：关键约束解除或正反馈形成
受阻转变：制度、成本或信任阻断扩散
反向变化：竞争技术、危机或价值反弹改变方向
结构外事件：低概率但高影响的断裂
```

每个情景包含：

- 关键假设。
- 可观测前兆。
- 发生概率区间而非单点精确数。
- 失效条件。
- 对用户的机会与风险。
- 无论哪个情景发生都值得做的稳健准备。
- 只在某情景概率上升后才值得做的条件行动。

## 4. 机会是用户与世界之间的不对称

机会不等于增长最快的领域。它至少由六个部分共同定义：

| 维度 | 问题 |
| --- | --- |
| 世界变化 | 哪个约束、成本或需求正在改变？ |
| 用户优势 | 用户拥有何种稀缺经验、关系、位置或耐心？ |
| 可进入性 | 能否以当前资源开始？ |
| 可逆性 | 错了以后能否低成本退出？ |
| 学习价值 | 即使失败，会获得什么独特信息或能力？ |
| 时间窗口 | 为什么是现在，什么事件会关闭窗口？ |

高价值早期行动通常不是“大举投入”，而是获得选择权：建立联系、做小原型、进入真实场景、积累难复制数据或训练关键能力。

## 5. 机会论文

Axiom 提出重要机会时，应形成一份简洁但可审理的论文：

1. **核心变化**：哪种结构正在改变。
2. **机制**：为什么可能持续。
3. **非共识点**：多数人可能忽略什么。
4. **用户匹配**：为什么这对该用户而非任何人有意义。
5. **竞争解释**：为什么它可能只是噪声或暂时现象。
6. **关键未知**：当前最脆弱的假设。
7. **领先信号**：之后看什么才算情景增强。
8. **最小行动**：如何用低代价获得独特信息。
9. **退出条件**：看到什么应停止。
10. **预测台账**：概率、时间范围和更新历史。

“开天辟地的建议”只有在能承担这些约束时才有价值。

## 6. 日常环境与 Atlas

### 6.1 日常环境

不展示趋势仪表盘。只在某个变化与用户长期方向产生高价值交叉时，出现“机会邀请”或“风险转折”。

### 6.2 Atlas

Atlas 可显示：

- 世界驱动力与个人能力之间的新桥梁。
- 某个机会依赖的关键假设。
- 情景分歧在哪里。
- 新证据如何移动机会位置与显著性。
- 哪些用户承诺暴露于同一结构风险。

机会不能因潜在收益高就成为视觉中心；显著性必须同时考虑证据、可逆性和个人价值。

### 6.3 白板

白板用于构造情景、拆解机会论文、比较行动路径和做预演。AI 应主动扮演反方、竞争者、监管者、失败后的未来自己等不同视角。

## 7. 预测台账

所有可检验的外部判断必须记录：

- 作出预测的时间。
- 当时可见的信息。
- 概率与时间窗。
- 关键理由。
- 之后是否修改，以及修改是否发生在结果已显露之后。
- 最终结果与校准误差。

没有台账的“我早就看出来了”不属于知识资产。

## 8. 人与中枢的边界

Axiom 可以自主：

- 扫描弱信号与驱动力。
- 维护情景与概率。
- 找用户能力与世界变化的交叉。
- 设计低成本探索。
- 追踪预测并复盘。

人必须决定：

- 哪种未来值得共同创造。
- 愿意承担何种道德和现实代价。
- 是否公开、投资、迁移、建立关系或改变身份承诺。
- 哪些机会即使高收益也不符合自己的生活。

## 9. 失败模式

- 热点即趋势。
- 趋势即命运。
- 用一条故事串起所有信号。
- 因用户喜欢而提高概率。
- 只呈现上行空间，隐藏退出成本。
- 用“未来可能”制造持续焦虑。
- 概率在结果出现后被悄悄改写。
- 把用户的短期资源误认为长期优势。
- 宏观判断越自信，证据越稀薄。

## 10. 评价标准

- 概率校准与预测分辨率。
- 情景集合是否包含机制不同的未来。
- 领先信号能否在结果前改变判断。
- 最小行动是否真的获得新信息。
- 机会建议的可逆性与下行保护。
- 用户独特匹配是否有证据，而非个性化修辞。
- 被放弃机会的退出是否及时。
- 系统是否记录并学习系统性偏差。
