# 专题一：观察场与问题议程

> 核心命题：自主发现的起点不是“回答得更聪明”，而是比人更早注意到值得追问的变化，并有节制地决定什么暂时不追。

## 0. 产品结论

Axiom 不应把互联网、个人记录和传感数据汇成一条更长的信息流。真正缺少的不是信息，而是：

- 哪些变化破坏了旧解释。
- 哪些反常只是噪声。
- 哪些相距很远的信号可能属于同一机制。
- 哪个未知一旦被减少，会改变很多后续判断。
- 哪些问题现在还不值得占用人的注意。

因此该板块应由两个相互制衡的器官构成：

```text
观察场 Observatory：持续形成“世界有什么变化”的候选
问题议程 Question Agenda：持续决定“什么值得成为研究对象”
```

观察场扩张视野，问题议程约束注意；没有前者，Axiom 只会被动；没有后者，Axiom 会成为噪声制造器。

## 1. 观察不是抓取，而是与模型比较

单纯抓取新内容只能回答“出现了什么新文本”。观察必须把新信息与既有模型比较：

```text
新观察
  × 世界模型：是否违背已知机制？
  × 人的模型：是否影响用户的能力、约束或长期方向？
  × 时间模型：是短时波动、趋势、周期还是结构突变？
  × 来源模型：信息是否独立、可靠、受激励扭曲？
  × 未知前沿：它是否填补或扩大了关键空白？
```

观察对象不等于一篇文章。它可以是：

- 一个数值偏离长期基线。
- 两个此前独立领域开始出现相同关系结构。
- 某个预测连续失准。
- 用户反复说要做，却总在同一阶段中断。
- 现有理论无法同时解释的两组事实。
- 一个长期没有新证据却被系统持续高置信维持的主张。
- 社会制度、成本曲线、技术能力或群体行为之间的耦合变化。

## 2. 六类值得进入观察场的信号

### 2.1 异常

偏离预期，但未必重要。异常只意味着“旧模型没料到”，不意味着发现。

### 2.2 转折

变化的方向、速度或波动结构发生改变。转折比单点异常更可能意味着机制变化。

### 2.3 矛盾

两个可信来源、两个个人行为或两个模型预测不能同时成立。矛盾是高价值问题源，因为它天然要求区分解释。

### 2.4 空白

为了作出重要判断，某个变量长期缺失。空白不是“没有内容”，而是模型中明确可指认的未知。

### 2.5 重现

同一种关系形状在多个领域反复出现，例如阈值、反馈、拥挤、选择偏差或延迟效应。重现可能触发跨域规律搜索。

### 2.6 弱信号组合

每个信号单独都不够强，但它们在时间、机制或激励结构上共同指向某种新状态。Axiom 的优势之一正是长期保存并重新组合这类微弱证据。

## 3. 问题不是搜索词，而是可生长的认识对象

每个正式问题至少包含：

| 组成 | 说明 |
| --- | --- |
| 问题本身 | 当前真正不知道什么 |
| 为什么现在 | 哪个变化令它获得时效性 |
| 冲突模型 | 哪些解释不能同时成立 |
| 影响范围 | 答案会改变哪些认识或行动 |
| 信息价值 | 哪条新信息最可能改变判断 |
| 可观测量 | 现实中应看什么 |
| 停止条件 | 何时暂时不再投入 |
| 再唤醒条件 | 什么新证据出现时重启 |
| 人的关联 | 它与用户能力、价值和风险的关系 |

问题应有生命周期：

```text
萌芽 → 候选 → 活跃探索 → 暂停 → 已回答 / 被替换 / 被证明不值得
```

“被证明不值得”也是重要成果，它保护未来注意力。

## 4. 问题议程如何选择

不能只按“与用户当前目标的相关性”排序，否则系统会被困在已知目标里。建议维持一个组合，而非单榜单：

### 4.1 近身问题

直接影响当前承诺、健康、学习、工程和关系。

### 4.2 杠杆问题

一旦回答，可以同时改变多个判断或行动。

### 4.3 反常问题

现象与旧模型冲突，可能揭示模型缺陷。

### 4.4 远域问题

短期看与用户无关，但可能扩展世界模型和类比能力。

### 4.5 自我反证问题

专门检验 Axiom 长期相信的核心主张。

### 4.6 空白保护位

议程中始终保留一部分资源给尚未被现有分类覆盖的东西，防止系统只会优化既有框架。

问题的优先级应综合：影响、可解性、信息价值、时效、独特性、成本和探索多样性；但这些分数只服务于中枢选择，不应成为日常界面的排名表。

## 5. 自主性的层级

### 5.1 被动观察

用户提出主题，Axiom 收集材料。只是工具能力。

### 5.2 持续观察

Axiom根据既有问题跟踪变化。属于监测能力。

### 5.3 自主选题

Axiom 可以从异常、矛盾和结构迁移中提出用户未要求的问题。

### 5.4 自主争取注意

Axiom 判断某问题价值足够高，向用户说明“为什么现在值得看”，但不能以频繁通知强迫注意。

### 5.5 自主放弃

Axiom 会因证据贫乏、信息价值下降或机会窗口消失而暂停问题。这是成熟自主性的重要标志。

## 6. 日常环境中的产品形态

用户不应看到“观察中心”仪表盘。日常只出现三种形态：

### 6.1 边缘信号

不要求立即处理，只在“此刻”的背景中留下轻微存在，说明某个长期主题有变化。

### 6.2 发现邀请

当多个证据形成明确张力时，Axiom 用一段短叙述提出：

```text
我注意到什么
它与原先认识冲突在哪里
为什么可能重要
现在最值得追的一个问题
```

用户可以忽略、延后、进入 Atlas 或开启白板。

### 6.3 关键转折

只有当风险、机会或核心模型发生足够大变化时，才进入注意中心。其表达必须包含不确定性和不行动的后果，而不是警报式夸张。

## 7. Foundry 中的产品形态

Foundry 才呈现完整的观察覆盖与问题组合：

- 哪些领域长期过度观察或观察不足。
- 哪些问题来自用户、外部变化或系统自我反证。
- 哪些来源相互依赖，造成伪共识。
- 哪些议题持续消耗资源却没有信息增益。
- 问题议程在探索与利用之间是否失衡。
- 哪些被忽略的问题后来被证明重要。

Foundry 的目的不是手工管理订阅源，而是审查 Axiom 的注意力政治。

## 8. 人与中枢的边界

中枢可以自主提出、追踪、暂停问题；人保留：

- 让某领域永久不被观察的权利。
- 知道为什么某问题进入注意的权利。
- 把问题标记为“对我有意义，但暂不需要证明”的权利。
- 拒绝把某个个人目标作为长期优化方向的权利。
- 要求 Axiom 主动寻找相反证据的权利。

## 9. 主要失败模式

### 9.1 新奇性成瘾

系统持续偏爱新话题，忽略缓慢但重要的积累。

### 9.2 个性化牢笼

所有观察都围绕用户已表达兴趣，远域发现消失。

### 9.3 新闻化

把发生频率误作重要性，把舆论热度误作结构变化。

### 9.4 异常崇拜

看见偏离就讲故事，没有基线、机制和复现。

### 9.5 注意力殖民

Axiom 用“可能很重要”不断打断人，最终让自主发现变成新的信息焦虑。

### 9.6 目标迎合

系统只提出能强化用户现有方向的问题，从不挑战目标本身。

## 10. 评价标准

观察场不按抓取量评价，而按：

- 重要变化被发现的提前量。
- 假阳性造成的注意成本。
- 议程中解释与领域的多样性。
- 问题被后续证据显著改写的比例。
- 被暂停问题重新唤醒的准确性。
- 用户认为“本来不会想到，但值得追”的问题比例。
- 发现对后续模型、实验或行动产生的真实影响。

## 11. 研究依据

- Pirolli 与 Card 的 sensemaking 模型把信息觅食与结构化解释视为往返循环，说明观察不能与假说建构割裂。
  <https://research.google/pubs/sensemaking/>
- Bayesian surprise 研究为“新信息改变既有信念的程度”提供了比新颖性更合适的形式基础。
  <https://pmc.ncbi.nlm.nih.gov/articles/PMC2860069/>
- 主动学习关注选择最有信息价值的下一次查询，这支持问题议程围绕“减少哪个未知最有价值”组织。
  <https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005466>
- OECD 将 horizon scanning 与战略前瞻用于识别新兴变化和构造多种未来，而不是预测单一结局。
  <https://www.oecd.org/en/about/programmes/strategic-foresight.html>
- 平静技术强调让信息在注意中心与边缘之间移动，为 Axiom 的低打断观察提供设计基础。
  <https://calmtech.com/papers/coming-age-calm-technology>
