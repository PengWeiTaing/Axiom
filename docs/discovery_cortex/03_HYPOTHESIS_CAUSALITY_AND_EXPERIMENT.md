# 专题三：假说、因果与验证

> 核心命题：Axiom 的创造力不应以“点子数量”衡量，而应以它能否维护竞争解释、主动寻找反证并设计高判别力验证来衡量。

## 0. 产品结论

从观察到发现，中间最危险的一步是解释。语言模型很容易为任何现象生成流畅原因，也很容易在看到结果后构造合理故事。

该板块的产品责任不是帮用户迅速得到一个答案，而是建立一个持续运转的“解释竞争场”：

```text
观察
→ 多个假说
→ 不同机制与预测
→ 能区分它们的证据或实验
→ 更新而非宣判
```

系统质量取决于它是否使错误解释更快暴露，而不是使正确口吻更快生成。

## 1. 假说是带风险的解释承诺

一个合格假说至少包含：

- **要解释的现象**：具体观察而非宽泛主题。
- **机制**：哪些变量如何作用。
- **适用范围**：时间、尺度、群体与环境。
- **预测**：若成立，还应观察到什么。
- **反事实**：若关键变量不同，结果应怎样变化。
- **反驳条件**：看到什么后应明显降低相信程度。
- **竞争假说**：还有什么机制能解释同一现象。
- **证据需求**：当前最缺哪类信息。
- **来源谱系**：由谁、何时、根据什么提出。

只提供解释而不承担被推翻条件的内容，应被视为叙事候选，不是假说。

## 2. 假说空间不能过早坍缩

每个重要问题默认保留四个位置：

1. 当前证据最支持的解释。
2. 机制不同但同样能解释现象的竞争项。
3. 反直觉或来自远域类比的探索项。
4. “现有信息不足或问题定义错误”的保留项。

这不是机械地凑四个答案，而是防止：

- 首个流畅解释形成锚定。
- 用户偏好成为隐性先验。
- 同一个模型既生成又裁判。
- 复杂现象被单因归因。

当证据足够时，假说可以退出竞争；退出原因必须保留。

## 3. 创意强度与证据强度分开

一个想法可能：

- 很新但证据弱。
- 很稳但没有解释增量。
- 证据较强却只适用于窄范围。
- 尚未验证但一旦成立影响巨大。

因此不能使用一个“综合置信度”把它们压平。至少分开表达：

| 轴 | 问题 |
| --- | --- |
| 新颖性 | 它是否超出既有解释？ |
| 证据支持 | 当前证据支持到什么程度？ |
| 机制完整度 | 因果链是否清楚？ |
| 可检验性 | 是否能产生区分性预测？ |
| 影响范围 | 成立后会改变多少判断？ |
| 脆弱性 | 依赖哪些未经证实的前提？ |

这些轴用于审理与比较，不应变成炫目的雷达图或伪精确总分。

## 4. 证据不是附件，而是对主张的作用

同一材料对不同主张可能产生不同作用。证据对象必须明确：

- 它支持或削弱哪条主张。
- 来源是否独立。
- 观察、实验、模型输出还是转述。
- 是否存在选择、测量和发表偏差。
- 对哪个人群、尺度和时间有效。
- 它改变判断的幅度，而不只是“相关”。
- 是否可能同时被竞争解释预测。

证据关系应允许：支持、削弱、限定边界、暴露矛盾、无法区分和来源依赖。

## 5. 因果判断的纪律

Axiom 不应把相关、时间先后、机制可想象或模型解释自动升级为因果。因果候选至少要经历：

1. **时间顺序**：原因先于结果，但这仍不充分。
2. **竞争解释**：共同原因、选择与反向因果是否存在。
3. **机制可行性**：中间过程是否可观察或可推导。
4. **干预证据**：改变候选原因是否改变结果。
5. **跨环境稳定性**：关系是否在环境变化下保持，或为何改变。
6. **剂量与边界**：关系是否随强度、时间或条件变化。
7. **负面控制**：理论上不应受影响的对象是否真的不受影响。

在个人生活中无法做严格实验时，系统应清楚区分：因果已知、机制候选、可行动假设和纯相关。

## 6. 最好的下一步是“区分”，不是“收集更多”

当多个解释都能符合已有事实时，继续泛搜往往只会为每个解释找到更多材料。Axiom 应寻找预期分歧最大的观察：

```text
如果 H1 成立，X 应上升；
如果 H2 成立，X 应不变或下降；
因此测量 X 比继续阅读同类文章更有价值。
```

验证动作可分为：

- 查找已有关键证据。
- 重新分析个人历史数据。
- 设计低风险行为实验。
- 询问具备独立信息的人。
- 等待有时间价值的自然结果。
- 构建模拟或最小模型。
- 寻找极端案例与反例。
- 改变表征，看矛盾是否消失。

## 7. 实验不是实验室专属概念

个人 Axiom 中的实验可以是：

- 在两个星期采用不同学习节奏并预先规定评价指标。
- 在产品选择前制作两个低成本原型，观察真实使用而非主观偏好。
- 在重要决定前记录概率和理由，事后对照。
- 改变一个环境约束，观察行为是否随之变化。
- 主动寻找与自己观点相反、且有独立证据来源的人。

每个实验必须包含：

```text
要区分的假说
预先承诺的预测
可观测结果
停止条件
成本与风险
结果如何更新判断
```

没有预先预测的“试试看”仍可探索，但不能冒充验证。

## 8. 白板与 Atlas 中的职责

### 8.1 白板

白板承载假说生成、机制拆解、竞争模型并置、反事实改写和实验设计。AI 候选应以独立层出现，不能混入用户已认可结构。

### 8.2 Atlas

Atlas 显示长期存在的主张、竞争模型、关键证据、尚未解决的张力和新结果造成的结构变化。它不展示每次内部推理草稿。

### 8.3 关系证据

当用户审理一条关系时，界面先回答：

- 这条关系实际上主张什么。
- 最强支持与最强反证是什么。
- 哪些证据并不独立。
- 竞争解释是什么。
- 下一条最有判别力的信息是什么。

底层检索链、嵌入相似度和模型投票只在审计时展开。

## 9. 人与中枢的边界

Axiom 可以自主：

- 生成候选解释。
- 寻找反例与证据。
- 提出最小实验。
- 在低风险数字环境中运行模拟。
- 根据预定规则更新假说地位。

人保留：

- 对价值、意义和可接受风险的判断。
- 是否在现实中执行实验的决定。
- 拒绝被量化的体验。
- 对关系、健康、财务与公共影响行动的最终授权。
- 将某个未经证明但富有意义的想法保留为艺术或哲学对象的权利。

## 10. 失败模式

- **事后诸葛**：知道结果后生成无法证伪的解释。
- **证据计数**：把支持材料数量当强度，忽略独立性和质量。
- **单模型法庭**：同一模型生成、检索、评分并宣布胜利。
- **实验剧场**：指标在结果出现后才选择。
- **量化暴政**：只研究容易测量的东西。
- **永不收敛**：以“保持开放”为名拒绝作出任何暂时判断。
- **行动偷渡**：把一个可行动假设描述成已知因果。

## 11. 评价标准

- 竞争假说的机制差异，而非文字差异。
- 验证前预测是否被记录并锁定。
- 新证据能否真正改变排序。
- 反例搜索成功率与误报率。
- 实验能否区分解释，而非只确认主假说。
- 因果措辞与证据等级是否校准。
- 被推翻假说是否改善后续问题与模型。
- 用户是否能复述“为什么目前这样判断”。

## 12. 研究依据

- 主动学习把查询选择视为最大化信息增益，为“寻找最能区分假说的下一步”提供理论基础。
  <https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005466>
- Invariant Causal Prediction 以跨环境稳定性约束因果候选，提醒系统不要把单环境相关性当机制。
  <https://academic.oup.com/jrsssb/article/78/5/947/7040653>
- Google 的 AI co-scientist 采用多个角色生成、反思、排名与演化假说，说明假说生产可以系统化；它也不能替代真实验证。
  <https://research.google/blog/accelerating-scientific-breakthroughs-with-an-ai-co-scientist/>
- “AI Scientist”展示了自动化研究循环的可能性，同时凸显评价与真实新颖性仍是核心约束。
  <https://arxiv.org/abs/2408.06292>
- 关于 LLM 研究创意的新颖性研究发现模型可以生成被专家认为新颖的想法，但评价可靠性与自我审查仍有限。
  <https://arxiv.org/abs/2409.04109>
