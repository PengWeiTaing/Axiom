# 专题二：规律库与跨域发现

> 核心命题：Axiom 不应收藏“有道理的话”，而应积累能解释现象、产生预测、暴露边界并迁移到新领域的关系结构。

## 0. 产品结论

用户所说的“道”，不应被产品化成玄学标签，也不能被压缩成一组数学公式。它指向的是一种更高阶能力：

```text
从不同现象中识别共同结构，
把直觉变成变量与机制，
知道该结构何时成立、何时失效，
并用它产生此前没有的解释、预测和行动选择。
```

渗流、贝叶斯更新、复利、临界转变、网络级联、边际效应和选择偏差都只是样本。规律库必须能够继续生长，不能预设一个有限的“世界规律清单”。

## 1. 四种经常被混淆的东西

### 1.1 事实

在特定时间、来源和条件下的观察。

### 1.2 经验法则

在若干情境中有效，但机制和边界未必清楚的压缩。

### 1.3 机制

变量之间如何相互作用并产生结果的解释。

### 1.4 规律族

一组跨领域反复出现、可用共同关系结构描述的机制，例如：

- 阈值与相变。
- 正负反馈。
- 累积优势与路径依赖。
- 局部互动导致的全局涌现。
- 选择、观测与幸存偏差。
- 时滞、过冲与振荡。
- 拥挤、容量和边际回报。
- 探索与利用。
- 冗余、韧性和脆弱性。
- 信号、噪声与可辨识性。

产品要明确这四层，否则一句“量变引起质变”会同时被当作哲学、统计结论、物理机制和人生建议，最终什么也无法检验。

## 2. 一条规律的完整形态

规律对象至少包含：

| 组成 | 作用 |
| --- | --- |
| 关系形状 | 单调、U 型、阈值、滞后、循环、幂律等 |
| 变量角色 | 状态、流量、控制量、约束、扰动、观察量 |
| 机制叙述 | 为什么会出现这种关系 |
| 形式表达 | 方程、概率图、仿真规则或定性结构 |
| 适用条件 | 哪些前提必须成立 |
| 失效边界 | 在什么尺度或情境下不成立 |
| 可观测信号 | 现实中怎样识别它 |
| 可区分预测 | 它与竞争机制会产生哪些不同结果 |
| 来源谱系 | 理论、实验、案例和引用 |
| 迁移记录 | 在哪些新领域被尝试过 |
| 失败记录 | 哪些类比曾经诱人但错误 |
| 个人关联 | 它如何改变用户的理解或选择 |

规律不是静态卡片，而是一个能接受新证据、运行推演和产生问题的理论对象。

## 3. 每条规律有三个面向

### 3.1 形式面

供计算、仿真和严格比较使用。它回答“关系到底是什么”。

### 3.2 结构面

用角色、反馈、阈值和约束表达，便于跨学科迁移。它回答“哪些部分在发挥同一种作用”。

### 3.3 人类面

用可感知的情境解释，但必须同时带上边界和误用警告。它回答“这与我的现实有什么关系”。

Axiom 的价值在于让三个面向互相校验：哲学直觉推动结构搜索，形式模型阻止空泛，现实案例暴露边界。

## 4. 从“隐约知道”到可检验关系

当用户表达“事情积累到某个程度突然变了”时，Axiom 不应立刻贴上“渗流”或“相变”。正确的推进顺序是：

1. **保留原始直觉**：不急于替用户改写。
2. **找关系形状**：连续积累、突变、回滞，还是观测尺度造成的错觉？
3. **识别变量角色**：什么在积累，什么是连接，什么是容量，什么是结果？
4. **提出竞争机制**：阈值、网络连通、反馈放大、选择效应或制度切换？
5. **寻找判别信号**：不同机制在临界点前后会留下什么不同迹象？
6. **构造最小模型**：先用最少变量表达，不追求完整世界。
7. **回到现实检验**：寻找反例、边界和可观测数据。
8. **决定地位**：灵感、类比候选、经验关系、机制候选或已验证规律。

这一过程把“哲学与科学相连”变成可执行认识活动，而不是给哲学语言加科学名词。

## 5. 跨域类比的正确单位是关系，不是名词

好的类比不是“A 像 B”，而是：

```text
A 中的角色关系 R
与
B 中的角色关系 R'
在关键约束下保持结构对应
```

每次迁移都要通过五道检查：

### 5.1 角色对应

源领域与目标领域中的元素分别扮演什么功能？

### 5.2 关系对应

对应的是因果、约束、竞争、扩散、选择还是反馈？

### 5.3 尺度对应

个体、群体、组织和社会层级能否直接类比？

### 5.4 守恒与边界

源机制依赖的资源、空间、时间与随机性在目标领域是否存在？

### 5.5 新预测

类比是否产生了此前不知道、可以被现实反驳的新预期？如果没有，它更可能只是修辞。

## 6. 规律库的生长方式

### 6.1 自上而下

从科学理论、数学模型和已验证机制进入。

### 6.2 自下而上

从用户经历、长期数据和反复模式中归纳候选关系。

### 6.3 横向迁移

从一个成熟领域迁移结构到另一个尚缺解释的领域。

### 6.4 反例驱动

规律因失效而分裂出边界条件、子类型或竞争模型。

### 6.5 组合发现

两条已知规律在共同约束下产生新的复合机制。例如反馈与时滞结合可能产生振荡，网络阈值与异质性结合可能改变扩散路径。

## 7. 规律的认识地位

规律不应只有“有/无”。建议使用可理解的成熟度：

```text
哲学直觉
→ 结构类比
→ 经验关系
→ 机制候选
→ 可预测模型
→ 多环境验证
→ 稳定理论
→ 边界修订或被替代
```

成熟度与个人价值是两条轴。一条尚未验证的类比可能极有启发，一条高度验证的规律也可能与用户当下无关。

## 8. 在 Atlas 与白板中的不同存在

### 8.1 Atlas 中

规律表现为跨领域的稳定桥梁、解释多个现象的结构核心以及正在受到新证据挑战的理论区域。用户看见的是它连接了什么、解释了什么、哪里失效，而不是一张“公式库”列表。

### 8.2 白板中

规律是可拆解的模型：变量、反馈、边界、反例和映射关系都可被移动、替换与比较。白板允许用户把一个熟悉机制投影到新问题上，并要求 Axiom生成竞争类比。

## 9. Axiom 应主动做什么

- 在长期记录中发现反复关系形状。
- 搜索不同领域的结构相似性。
- 主动提出边界条件与反例。
- 把定性直觉转成最小变量模型。
- 生成可区分的预测，而不是只生成解释。
- 记录类比迁移的成败。
- 在新证据出现时重新评估旧规律。
- 主动发现规律库中长期没有被反证审查的核心结构。

## 10. Axiom 不应做什么

- 用科学术语装饰人生感悟。
- 因为两个领域共享关键词就建立类比。
- 把相关性自动命名为机制。
- 把一次成功案例升级成普遍规律。
- 隐藏类比失败史。
- 用一个优雅公式压平制度、价值和权力差异。
- 让用户因“模型看起来精确”而忘记数据质量和适用边界。

## 11. 复利资产

规律库真正积累的是：

- 可迁移的关系形状。
- 成功与失败的角色映射。
- 每种机制的识别信号。
- 典型边界条件。
- 最有判别力的问题。
- 在用户生活中有效或无效的历史。
- 多种规律组合后的涌现结果。

这样下一次遇到新现象时，Axiom 不只是检索相似文本，而是拥有更好的解释起点。

## 12. 评价标准

- 类比是否产生可反驳的新预测。
- 迁移后是否比目标领域原有解释更有区分力。
- 边界和失败是否被清楚记录。
- 独立来源能否支持机制，而非只支持现象。
- 规律对问题选择、实验设计和行动是否产生实际增益。
- 系统是否能发现自己曾经错误迁移的模式。
- 规律库是否持续出现新的关系族，而不是围绕少数流行概念自我重复。

## 13. 研究依据

- Gentner 的结构映射理论强调类比的核心是关系结构和系统性对应，而非对象表面相似。
  <https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0702_3>
- Swanson 的文献发现工作展示了分离文献之间的隐含连接如何形成可检验的新假说。
  <https://pmc.ncbi.nlm.nih.gov/articles/PMC4031661/>
- AI Feynman 展示了在可形式化数据中结合结构先验与符号搜索发现方程的可能性，也反向说明现实社会问题不能直接照搬这一条件。
  <https://pmc.ncbi.nlm.nih.gov/articles/PMC7159912/>
- Watts 的级联模型与 Centola 的社会临界实验说明“阈值”在不同系统中可能有共同结构，但具体机制、网络和群体条件决定结果。
  <https://pmc.ncbi.nlm.nih.gov/articles/PMC122850/>
  <https://pubmed.ncbi.nlm.nih.gov/29880688/>
- Scheffer 等人的临界转变预警研究表明，接近阈值时可能出现可观测信号，但这些信号有适用前提，不能泛化成万能预言。
  <https://doi.org/10.1038/nature08227>
