# Axiom 发现中枢专题研究地图

> 状态：产品研究基线，不是当前实现说明
> 上位文档：`docs/AXIOM_DISCOVERY_CORTEX_RESEARCH_V2.md`
> 目的：把总纲拆成可独立审查、又能互相闭环的认知器官研究

## 0. 为什么要拆成专题

`AXIOM_DISCOVERY_CORTEX_RESEARCH_V2.md` 已经回答了 Axiom 应成为怎样的系统：它不只记住、整理和建议，还要主动观察世界、发现规律、形成竞争性假说、设计验证并积累可迁移的理论。

但总纲仍不足以直接约束产品。若不继续拆解，很容易出现三种退化：

1. 把“自主发现”实现成后台多跑几个 Agent。
2. 把 Atlas 实现成数据库关系的漂亮投影。
3. 把白板实现成有 AI 按钮的无限画布。

专题研究要回答更具体的问题：

- 每个认知器官究竟消除哪一种认知瓶颈？
- 人、Axiom 中枢与界面各自拥有何种权力？
- 什么进入人的意识，什么只留在机器推理与审计层？
- 产物如何从含混直觉逐渐成为可验证理论？
- 系统怎样避免越聪明，越把用户带入单一叙事？

## 1. 总体产品不是模块集合，而是一条认识运动

```text
世界与个人经历
    ↓
观察场：发现变化、异常、空白与冲突
    ↓
问题议程：决定什么值得追问
    ↓
规律与类比：寻找可迁移机制
    ↓
假说竞争：保留多种解释
    ↓
验证与实验：寻找能区分解释的证据
    ↓
机会与行动：把认识转成可逆选择
    ↓
结果与反事实：检验判断
    ↓
复利记忆：更新人的模型、世界模型和发现模型
```

Atlas 与白板不是这条链上的两个普通步骤：

- **Atlas** 是整条认识运动在人眼前形成的稳定地形，负责定向、回忆、发现结构变化与进入问题。
- **白板** 是认识结构可以被拆开、重排、比较、反驳和重建的工作场，负责把尚未成形的理解推进成可检验模型。

因此二者分别对应：

```text
Atlas：我的认识世界现在长什么样？
白板：它还可能怎样被重新理解？
```

## 2. 专题文档组

### 2.1 观察与问题议程

文档：`01_OBSERVATORY_AND_QUESTION_AGENDA.md`

研究对象：

- Axiom 如何主动观察，而不是等待用户提问。
- 如何区分噪声、变化、异常、矛盾和真正的认知机会。
- 如何维护一组问题，而不是持续生产提醒。
- 如何保护自由探索，避免个性化把世界越看越窄。

### 2.2 规律库与跨域发现

文档：`02_LAW_LIBRARY_AND_CROSS_DOMAIN_DISCOVERY.md`

研究对象：

- “规律”怎样从名言或知识点升级为可运行的解释结构。
- 如何连接哲学直觉、科学机制、概率结构和个人处境。
- 如何做结构类比，而不是表面比喻。
- 如何记录规律的边界、失败和迁移史。

### 2.3 假说、因果与验证

文档：`03_HYPOTHESIS_CAUSALITY_AND_EXPERIMENT.md`

研究对象：

- 如何维持竞争性解释，避免快速收敛。
- 如何把直觉推进到变量、机制、预测与可区分实验。
- 如何管理证据、反证、因果强度与未知。
- 人何时需要介入判断。

### 2.4 战略前瞻与机会

文档：`04_STRATEGIC_FORESIGHT_AND_OPPORTUNITY.md`

研究对象：

- 如何从新闻摘要升级为结构变化识别。
- 如何维护多种情景、概率和失效条件。
- 如何把“风口”改写成与用户能力、时机和风险相匹配的不对称机会。
- 如何避免宏大叙事诱导行动。

### 2.5 日常认知环境

文档：`05_DAILY_COGNITIVE_ENVIRONMENT.md`

研究对象：

- Axiom 如何在日常中保持低摩擦和安静。
- 哪些发现值得进入人的注意力。
- 日常环境如何容纳记录、回忆、选择与偶发洞见，而不退回功能工作台。
- 如何让人的时间与意图成为界面中心。

### 2.6 Foundry 与认知复利

文档：`06_FOUNDRY_AND_COMPOUNDING.md`

研究对象：

- 工程维护环境为什么同时也是认知生产环境。
- Axiom 可以自主改进什么，哪些必须由人批准。
- 如何让失败的类比、预测和实验也成为资产。
- 如何验证系统真的越来越会发现，而不只是越来越会生成。

### 2.7 Atlas：发现地形

文档：`07_ATLAS_DISCOVERY_LANDSCAPE.md`

核心问题：

- Atlas 如何成为“人的认知界面”，而不是“中枢数据库界面”。
- 3D 全局、连续下潜、2D 聚焦与证据审理如何成为一段连续体验。
- 空间、颜色、亮度、运动和留白怎样改变人的注意与判断。
- 如何显示未知、争议、竞争性模型、时间变化与机会，而不制造视觉伪真理。
- 如何达到具有艺术人格、但不牺牲认识论诚实的视觉效果。

### 2.8 白板：共同发现环境

文档：`08_WHITEBOARD_CO_DISCOVERY_ENVIRONMENT.md`

核心问题：

- 白板如何从通用画布升级为人与 Axiom 共同建模的认知场。
- 如何允许含混空间组织，再逐步形式化。
- AI 何时旁观、何时提问、何时提出另一种表征、何时建立候选分支。
- 如何减少生成式 AI 带来的固着、同质化和所有权丧失。
- 如何把移动、分组、留白、画线等操作本身变成思考。

### 2.9 Atlas 与白板连续体

文档：`09_ATLAS_WHITEBOARD_CONTINUUM.md`

研究对象：

- 从 Atlas 进入白板时保留什么上下文。
- 白板中的草图、候选关系和新模型何时能返回 Atlas。
- 如何防止未经验证的 AI 草稿污染长期世界模型。
- 两者在日常环境和 Foundry 中分别如何出现。

## 3. 人与 Axiom 中枢的根本区分

这组文档共同遵守一个宪法：

### 3.1 中枢拥有模型，人拥有生活

Axiom 中枢可以：

- 观察更广的信息范围。
- 计算更长的关系链。
- 保存竞争性解释。
- 主动寻找反证和跨域结构。
- 对预测、类比与实验长期记分。

但中枢没有：

- 对用户意义的最终解释权。
- 把概率升级成事实的权力。
- 把关注升级成用户目标的权力。
- 在高影响现实中替用户承担价值后果的能力。

### 3.2 人看到的是认知投影，不是机器内部结构

内部可以存在数千种对象类型、关系分数、检索链、模型意见与不确定性来源；人的界面不应直接暴露这些工程结构。

人需要看到的是：

- 现在发生了什么。
- 为什么值得注意。
- 哪些解释正在竞争。
- 哪些证据真正改变了判断。
- 下一步怎样以最低代价减少关键未知。
- 这与自己的长期方向有什么关系。

### 3.3 界面是翻译层，也是权力边界

界面不只是把后端数据画出来。它决定：

- 哪些内容会进入人的注意。
- 哪些关系看起来更真实。
- 哪些问题被认为值得追。
- 人是在审视 Axiom，还是被 Axiom 的叙事带着走。

所以 Atlas 与白板的设计同时属于产品、认知科学和认识论治理。

## 4. 共用对象不是数据库类型，而是认识状态

所有专题使用一组面向人的认识对象：

| 对象 | 它回答的问题 |
| --- | --- |
| 观察 | 发生了什么？ |
| 问题 | 哪个未知值得追？ |
| 主张 | 当前在说什么？ |
| 模型 | 它如何解释现象？ |
| 规律 | 哪种关系可能跨情境成立？ |
| 假说 | 哪个尚未证实的解释值得检验？ |
| 证据 | 什么支持或削弱该主张？ |
| 反例 | 在什么情况下它不成立？ |
| 预测 | 如果模型成立，之后应看到什么？ |
| 实验 | 什么行动能区分不同解释？ |
| 机会 | 哪个可逆行动拥有不对称收益？ |
| 承诺 | 人决定承担什么？ |
| 未知 | 我们明确知道自己还不知道什么？ |

这些是界面语言。中枢仍可拥有更复杂的内部表示，但不能要求人先理解其本体才能思考。

## 5. 共用设计原则

### 5.1 先允许含混，再逐步精确

人形成新理解时，空间相邻、反复摆放和模糊分组往往先于正式关系。白板尤其必须允许“不知道这是什么，但先放在这里”。只有当结构开始稳定时，Axiom 才建议形式化。

### 5.2 多解释先于单答案

任何重要问题默认保留：

- 至少一个主解释。
- 至少一个竞争解释。
- 一个“信息不足”的保留项。
- 能区分它们的下一条证据。

### 5.3 不确定性必须可见，但不能成为视觉噪声

不能用一串置信度数字淹没人，也不能让漂亮、明亮、居中的对象看起来天然更真。默认以可理解的状态表达：已观察、推断中、有争议、缺证据、已反驳；数值与推理细节按需展开。

### 5.4 动效必须有认知含义

运动只表示：

- 新证据进入。
- 模型发生变化。
- 注意路径被主动追踪。
- 时间正在回放。
- 一个候选正在被比较。

不允许全局常驻动画替代美感。

### 5.5 低摩擦不是减少能力，而是推迟不必要决定

用户不应在表达前选择对象类型、关系类型、工作流模板和 AI 模式。系统先接受自然输入，随后在恰当时刻提供可逆的结构化建议。

### 5.6 美感必须服务于辨别力

视觉艺术不只是装饰。它应使人：

- 更愿意停留和凝视。
- 更容易感到结构而不是噪声。
- 能同时保持整体感与局部精确。
- 能区分事实、推断、未知和诱人的幻觉。

## 6. 竞赛白板与 Axiom 白板的边界

火山杯白板可以提供：

- 画布交互经验。
- 多媒体对象承载。
- 空间组织、缩放、连线与持久化基础。
- 某些结构化学习场景的验证。

但不能直接决定：

- Axiom 白板的对象本体。
- AI 的主动性和权限。
- 白板与 Atlas、中枢和长期理论库的关系。
- 日常使用入口。
- 视觉人格。

比赛要求与 Axiom 最佳产品形态冲突时，Axiom 以本研究为准；可复用的是能力，不是比赛的信息架构。

## 7. 研究依据的共同启示

- Kirsh 与 Maglio 区分了实用行动与认识行动：人在外部移动、旋转和重排对象，可以直接降低脑内计算成本。这构成白板交互的认知依据。
  <https://doi.org/10.1207/s15516709cog1804_1>
- 空间超文本研究表明，人在正式关系之前会用邻近、对齐和视觉属性表达隐含结构；过早强制形式化会破坏探索。
  <https://people.engr.tamu.edu/shipman/viki/papers/vkat-papers.html>
- 混合主动界面需要同时考虑用户意图的不确定性、打断成本、自动行动的收益与可撤销性。
  <https://www.microsoft.com/en-us/research/publication/principles-mixed-initiative-user-interfaces/>
- 生成式 AI 可以提高个体作品的平均表现，却可能降低不同作品之间的多样性；Axiom 需要主动防止 AI 锚定与思路同质化。
  <https://doi.org/10.1126/sciadv.adn5290>
- 图谱表示应匹配任务。节点连线、矩阵、文本与空间布局各有认知适配，不应把所有问题都压成一种图。
  <https://doi.org/10.1016/j.socnet.2018.01.005>
- 动态图的“位置完全不动”并不普遍提高理解；对定向任务有价值的是地标、区域与对象连续性。
  <https://doi.org/10.1016/j.ijhcs.2013.08.004>
- 可视化中的显著性与不确定性表达会影响信任；Atlas 必须把视觉选择视为认识论干预。
  <https://pubmed.ncbi.nlm.nih.gov/31425093/>
- 平静技术强调让信息在注意中心与边缘之间自然移动；这为日常环境“少打断、按价值进入意识”提供基础。
  <https://calmtech.com/papers/coming-age-calm-technology>

## 8. 本轮研究不做什么

这组专题现在不决定：

- Vue 组件怎样拆。
- Three.js、Canvas、WebGL 或某个白板 SDK 的选择。
- 数据表与 API 的具体字段。
- 现有页面保留多少代码。
- 动画参数、节点像素和最终色值。

这些应在产品研究稳定后，通过交互原型和真实任务实验决定。现在先锁定产品形态、认识逻辑、注意力伦理和环境边界。

## 9. 最终验收问题

未来任何设计提案都必须回答：

1. 它是在帮助人形成判断，还是展示机器做了很多计算？
2. 它降低了表达摩擦，还是要求人先学习系统本体？
3. 它保护了多种解释，还是漂亮地放大了一个答案？
4. 它把不确定性变得可思考，还是用视觉权威掩盖不确定性？
5. 它产生了可验证的新理解，还是只产生更多内容？
6. 它在积累未来的发现能力，还是只完成当前一次任务？
