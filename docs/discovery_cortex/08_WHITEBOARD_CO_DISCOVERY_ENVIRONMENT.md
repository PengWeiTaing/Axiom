# 专题八：白板作为 Axiom 的认知展演面

> 状态：下一代产品研究基线，不是当前实现说明
> 核心命题：白板不是让用户替 Axiom 整理信息的画布，而是 Axiom 围绕一个问题主动生成的高带宽认知展演。中枢负责搜集、计算、比较、编排和更新；人负责观看、追问、质疑、改变尺度与作出判断。

## 0. 重新定义白板

过去的定义把白板理解成“人与 Axiom 共同建模的无限画布”。这仍然默认用户要创建节点、移动材料、画线、分组并维护空间结构。它虽然比普通白板更聪明，却没有减少认知劳动，只是把建模软件的操作转移给用户。

Axiom 的白板应回答另一类问题：

```text
围绕我正在面对的问题，
Axiom 能否选择最合适的视觉语言，
把分散材料、机制、证据、反例、公式、时间与可能性，
编排成一场我可以理解、质疑和继续推进的认知展演？
```

因此它不是：

- 空白创作工具。
- AI 辅助便签墙。
- 自动生成的思维导图。
- Atlas 的编辑模式。
- 中枢内部推理链的可视化。
- 一份加了动画的答案。

它更接近一张会随提问重构的数字手卷、一次有证据约束的展陈，以及一个让规律与系统行为变得可感的动态解释媒介。

## 1. 白板消除的真正瓶颈

文字对线性论证有效，但难以同时承载：

- 多个时间尺度。
- 循环因果与反馈。
- 阈值、相变和非线性。
- 多个竞争解释。
- 跨领域结构同构。
- 证据与反证的空间关系。
- 情景分叉与机会窗口。
- 个人处境与宏观结构的连接。

Atlas 又承担长期定向，必须压缩、稳定、克制，不能为每个问题临时变成一张复杂说明图。

白板存在的理由，就是让中枢在短时间内获得更大的表达带宽。它不要求用户先把问题想清楚；它通过组织材料帮助用户看见问题究竟由什么构成。

## 2. 人、中枢与界面的权力边界

### 2.1 Axiom 中枢负责

- 从长期记忆、当前语境和外部世界收集相关材料。
- 识别关键变量、时间尺度、机制、争议和未知。
- 保留竞争解释，并主动寻找强反证。
- 选择适合当前问题的表示方式。
- 决定首屏只呈现什么，什么延后，什么只留在审计层。
- 生成多个可竞争的构图，而不是把第一种解释包装成唯一答案。
- 根据新问题、新证据和人的判断重新编排。

### 2.2 人负责

- 决定是否进入某个发现。
- 判断这个问题对自己的意义。
- 追问“为什么”“凭什么”“还漏了什么”。
- 要求显示最强反证、替代机制或更长时间尺度。
- 指出个人语境、价值和现实约束中的错误。
- 决定是否把认识转成承诺或行动。

### 2.3 界面负责

- 把机器规模的复杂性翻译成当前可理解的认知段落。
- 区分事实、推断、争议、未知和反事实。
- 让视觉显著性表达注意，而不是冒充真理。
- 让每个重要主张都能抵达来源、边界与反证。
- 保留来路，让人知道白板为什么在此刻出现。

白板不能要求人先理解对象类型、关系类型、Agent 分工或检索链。那些属于中枢与 Foundry。

## 3. 白板如何出现

白板不是一级入口，也没有“新建白板”主页。它从一个具体认知需要中展开。

典型入口包括：

- 此刻出现一项值得理解的变化。
- Atlas 中某个地标形成新的桥梁、张力或前沿。
- 用户对一个主张追问“它是怎么发生的”。
- Axiom 发现某个规律可能跨领域迁移。
- 一个决定需要比较情景、概率和后果。
- 一个机会需要理解结构窗口与个人适配。

入口文案表达意图，而不表达工具：

- 看它为什么会发生
- 展开这个规律
- 比较三种解释
- 看最强反证
- 推演两年后的分叉
- 把它放回我的处境

进入后，用户面对的不是空白，而是一幅已经有观点、有节奏、有证据边界的第一版展演。

## 4. 一次完整体验

### 4.1 邀请

Axiom 在注意边缘给出一句可忽略的邀请，说明发现内容和可能价值，不用红点和倒计时制造欠债。

### 4.2 开场

白板先给一个可理解的中心张力，而不是全量材料。用户首先知道：

- 现在讨论什么。
- 为什么它与自己有关。
- 当前最值得看的矛盾或机制是什么。
- 这只是当前解释，不是最终真相。

### 4.3 展开

用户沿材料、机制、时间或证据自然下潜。新内容从已有结构中显影，来路不消失。画面一次只增加一层复杂度。

### 4.4 质疑

用户可以随时发出高价值认知动作：

- 显示最强反证。
- 换一种机制解释。
- 把时间拉长到十年。
- 区分相关与因果。
- 展开这个公式里的变量。
- 显示与我无关的世界版本。
- 这条类比在哪失效。
- 哪条新证据会让结论翻转。

### 4.5 重构

Axiom 不弹出另一份答案，而是在原地保留参照地重构画面：旧解释退到一侧，新增材料进入，改变的关系明确显影。

### 4.6 返回

退出白板时，不要求用户保存、命名或整理文件。Axiom 只留下：

- 人作出的判断。
- 仍未解决的关键未知。
- 被接受或拒绝的解释。
- 可能值得继续观察的预测。
- 若用户明确选择，才出现的行动或承诺。

## 5. Axiom 的构图逻辑

白板不是把检索结果排得漂亮。每次展演都应经过六个认识决定。

### 5.1 确定中心问题

中心不是关键词，而是一个可区分的张力。例如不是“量变引起质变”，而是：

```text
为什么许多局部变化长期看似无效，
却会在跨过某个结构阈值后突然改变整体状态？
```

### 5.2 选择解释骨架

根据问题选择主要骨架：机制、比较、时间、空间、阈值、反馈、情景、论证或跨域映射。一个展演可以组合多种骨架，但必须有主次。

### 5.3 设定证据预算

首屏只保留能改变理解的材料。其余证据在需要时进入，不把“搜到了很多”伪装成“解释得很好”。

### 5.4 保留竞争结构

重要判断至少保留主解释、竞争解释和信息不足三种可能。它们不必同等显眼，但不能被主叙事吞没。

### 5.5 标记认识地位

每个关键元素必须能够说明自己是观察、主张、模型、证据、反例、预测、未知还是类比。界面用自然语言和视觉语法表达，不要求用户阅读内部 schema。

### 5.6 给出出口

展演最终不是总结，而是指出：下一条什么证据最有价值、哪个小试探最可逆、哪部分可以暂时不管。

## 6. 七种核心展演形态

白板不使用模板选择器，但 Axiom 可以根据问题生成以下形态或组合。

### 6.1 机制剖面

用于解释“为什么”。展示变量、方向、反馈、延迟、瓶颈与失效条件。关系线代表可表述的命题，不是数据库边。

### 6.2 阈值与相变

用于理解量变、临界点和非线性。把微观积累、连通结构、宏观跃迁、滞后与不可逆性放在同一视野中；允许比较渗流、网络效应、习惯形成或市场扩散的同构与差异。

### 6.3 假说剧场

用于多个解释竞争。每个解释拥有支持、反证、尚未解释之处和能区分它们的下一条证据。视觉不能让排在左侧或更亮的一方天然获胜。

### 6.4 时间长卷

用于看阶段、转折、延迟和路径依赖。不同时间尺度可以连续切换；局部事件不脱离长期结构，长期趋势也不吞掉个体经历。

### 6.5 情景分叉

用于战略和机会。展示关键变量如何把世界带向不同情景、哪些信号正在出现、哪些行动可逆、什么条件会关闭窗口。概率是可更新判断，不是视觉装饰。

### 6.6 跨域共振

用于规律迁移。并置不同领域中的结构角色、机制、边界和反例，帮助人判断是真正同构还是表面比喻。

### 6.7 个人位置图

用于回答“这与我有什么关系”。把用户能力、承诺、资源、偏好、风险承受和历史模式放入世界结构中，但明确区分已确认事实、推断和待用户纠正的部分。

## 7. 关系证据：什么给人看，什么留给中枢

### 7.1 默认给人看

- 当前主张及其自然语言含义。
- 一至三条真正改变判断的支持证据。
- 最强反证或竞争解释。
- 适用边界和已知失效条件。
- 来源、时间与材料语境。
- 哪条新证据会改变判断。
- 与用户现实选择相关的后果。

### 7.2 按需给人看

- 更完整证据列表。
- 定量假设与敏感性。
- 来源之间的分歧。
- 模型版本变化。
- 被省略的材料类别。
- Axiom 为什么选择当前构图。

### 7.3 默认只留在中枢

- embedding 相似度与检索分数。
- 海量弱候选关系。
- Agent 内部讨论和原始推理链。
- 去重、排序和聚类过程。
- 内部对象 ID、schema 与工具调用。
- 不足以形成可审理主张的噪声。

这些内容必要时进入 Foundry 审计，而不是污染日常白板。

## 8. 人的交互词汇

白板的主要交互不是“选择、拖动、连接、对齐”，而是：

```text
追问 / 质疑 / 比较 / 换尺度 / 看来源 / 看反证
重播 / 推演 / 联系自己 / 暂时搁置 / 作出判断
```

用户可以圈出、批注或纠正某一处，但这些是对 Axiom 的指示，不是用户承担版面维护。系统可以允许自由缩放和暂时移动以便阅读，却不能让拖动成为知识建模的必要步骤，也不能把空间移动自动解释为认可。

## 9. 认识论视觉语法

### 9.1 亮度

表示当前注意和可操作性，不表示真实性、重要性或置信度。

### 9.2 尺度

表示当前叙事层级和观看距离，不用大对象冒充重大结论。

### 9.3 边界

- 稳定边界：可追溯事实或已确认对象。
- 开放边界：推断或仍在形成的模型。
- 并置边界：竞争解释。
- 缺口：明确未知或缺失证据。

### 9.4 关系线

关系线必须可以翻译成句子。粗细、方向和运动只在确有因果、强弱、时间或传播含义时出现。禁止为了“图谱感”连接相似材料。

### 9.5 色彩

颜色只承担少量稳定语义，并在文字、形状或位置上有第二种线索。不能用一条彩虹同时表示领域、信心、时间和对象类型。

## 10. 美学人格：夜行长卷中的展演段

白板共享“夜行长卷”的暗场，但比日常界面拥有更高的空间自由和媒介密度。

- 背景是有深度的中性暗场，不是纯黑或蓝紫宇宙。
- 文字、图像、数据、音频、地图和公式直接进入构图，不先装进统一卡片。
- 视觉重心由明度、尺度、距离和节奏共同建立。
- 留白代表尚未解释、刻意停顿或真实结构距离。
- 光只在注意移动、新证据进入和模型变化时显影。
- 运动用于表现时间、因果、反馈、阈值与重构，不用于持续营造“活着”。
- 同一材料可在不同展演中拥有不同位置，但来源身份始终连续。

白板应像 Axiom 为一个问题策划的一次展览，而不是 AI 生成的一张信息海报。

## 11. 动态不是装饰，而是系统行为

白板允许四种有意义的运动：

- **连续运动**：从 Atlas 或此刻进入时保留对象身份和来路。
- **机制运动**：展示因果传播、反馈、延迟或积累。
- **变化运动**：新证据如何使关系增强、减弱、翻转或分叉。
- **比较运动**：切换解释或尺度时保留稳定参照，明确什么改变。

所有运动可暂停、重播，并在减少动态偏好下转换为分阶段静态状态。全场持续漂浮、粒子和呼吸不属于白板语言。

## 12. 桌面、平板与手机

### 12.1 桌面

承载完整展演、并置比较、精细来源和较长观看。它不是工具栏包围的画布，主要认知对象始终占据视觉中心。

### 12.2 平板

适合靠近材料、批注、语音追问和改变尺度，但不要求手写或手工整理才能完成工作。

### 12.3 手机

手机不压缩完整白板。它把同一展演转换成有方向的连续段落：一个机制、一组证据、一个反证、一个判断动作。用户能随时查看自己在整体中的位置，并在之后回到大屏继续。

## 13. 生命周期

白板不是传统文件，也不要求用户管理文件树。

一个展演可以：

- 只在一次问题中出现后休眠。
- 随新证据自动形成新版本。
- 被用户重新唤起并从上次判断继续。
- 与另一问题共享材料，但不共享私人语境。
- 产生预测、实验或观察项，等待现实反馈。

系统保存的是问题、构图版本、来源、人的判断与认识变化，不是用户必须维护的画布资产。

## 14. 与 Atlas 的边界

Atlas 回答“我的认识世界现在长什么样”，白板回答“围绕这个问题，Axiom 能怎样让我真正看懂”。

白板布局不会被直接写回 Atlas。空间位置是当次解释的一部分，不是长期世界模型。真正可能改变 Atlas 的是：

- 新证据改变了某个主张的认识地位。
- 一个竞争解释获得或失去支持。
- 一个未知成为长期问题。
- 一个跨域结构经过边界审理后成为规律候选。
- 人明确接受、拒绝或修正了与自己有关的判断。

详细通道见 `09_ATLAS_WHITEBOARD_CONTINUUM.md`。

## 15. 与火山杯 Learning Board 的边界

Learning Board 是独立竞赛项目。可借鉴的只有经过验证的基础能力，例如多媒体承载、缩放、持久化和结构化场景表达。

Axiom 白板不继承：

- 以用户创作为前提的产品定义。
- 空白画布和模板入口。
- 手工节点、连线和布局作为主工作流。
- 竞赛导航、对象本体和权限模型。
- 为展示功能而堆叠工具栏的视觉。

比赛交付与 Axiom 主线不互相定义；不兼容时以各自最优产品形态为准。

## 16. Foundry 中的白板审计

Foundry 可以检查：

- 本次展演使用了哪些来源和模型。
- 哪些候选关系被纳入、拒绝或隐藏。
- Axiom 为什么选择这一解释骨架。
- 用户在哪些位置追问、纠正或离开。
- 哪些预测后来兑现或失败。
- 哪种构图真正改善了理解，而不只是增加停留时长。

Foundry 看到工程过程；日常白板只看到足以判断的证据与边界。

## 17. 评价任务

白板不能用“创建了多少节点”“用户停留多久”评价。第一组真实任务是：

1. 用户能否在两分钟内说出当前中心机制，而不是复述摘要。
2. 用户能否指出至少一个竞争解释和一条关键反证。
3. 用户能否分辨哪些是事实、哪些是 Axiom 的推断。
4. 改变时间尺度或假设后，用户能否理解结论为何变化。
5. 用户是否无需拖动和整理就能完成完整认知过程。
6. 退出后是否只留下一个有价值的新判断，而不是新的信息负担。
7. 数周后，预测与现实反馈是否真正改善下一次展演。

## 18. 失败标准

- 打开后仍是一张空画布。
- 用户要手工摆放信息才能获得结构。
- Axiom 只生成一张静态思维导图或漂亮海报。
- 所有问题都被压成节点和连线。
- 证据数量取代证据质量。
- 主解释在视觉上天然压倒竞争解释。
- 中枢内部对象、分数和 Agent 日志直接泄漏给用户。
- 白板成为第四个常驻工作台。
- 手机只是完整画布的缩小版。
- Learning Board 的竞赛形态反向定义 Axiom。

- Heer 与 Robertson 的研究表明，经过设计的动画转换可以帮助人理解图形变化。
  <https://sites.stat.columbia.edu/gelman/communication/HeerRobertson2007.pdf>
- 混合主动界面研究提醒：自动行动必须同时考虑用户意图的不确定性、打断成本、收益与可撤回性。
  <https://www.microsoft.com/en-us/research/publication/principles-mixed-initiative-user-interfaces/>
- 生成式 AI 可提高单个作品表现，却可能降低总体多样性，因此白板必须主动保留竞争解释和非 AI 视角。
  <https://doi.org/10.1126/sciadv.adn5290>

## 20. 最终原则

1. 白板由 Axiom 生成，不由用户从空白开始维护。
2. Axiom 负责复杂性，人负责意义、质疑和决定。
3. 白板是高带宽认知展演，不是中枢内部结构可视化。
4. 表示方式跟随问题，不把所有问题做成图谱。
5. 默认显示最小充分证据、最强反证、边界和改变判断的条件。
6. 人的主要动作是追问、比较、换尺度与判断，不是拖动、连线和分类。
7. 动效只表现连续性、机制、变化和比较。
8. 白板布局不直接返回 Atlas；认识状态变化才可能更新长期地形。
9. 日常界面看结论与证据，Foundry 看检索、模型、候选和审计。
10. 艺术感来自构图、节奏、媒介与认识诚实，不来自装饰。
