# Axiom 美学方向（索引）

本文件原有“宏观界面 / 日常输入输出界面”讨论已合并进下一代统一研究，不再作为独立设计事实源。

请以以下文档为准：

- `docs/FRONTEND_ART_DIRECTION.md`：全前端审美体系“夜行长卷”、页面形态、字体、暗场、动效、可访问性与验收场景。
- `docs/discovery_cortex/05_DAILY_COGNITIVE_ENVIRONMENT.md`：日常低摩擦认知环境。
- `docs/discovery_cortex/06_FOUNDRY_AND_COMPOUNDING.md`：独立工程维护与认知生产环境。
- `docs/discovery_cortex/07_ATLAS_DISCOVERY_LANDSCAPE.md`：Atlas 长期认识地形。
- `docs/discovery_cortex/08_WHITEBOARD_CO_DISCOVERY_ENVIRONMENT.md`：Axiom 主动生成的认知展演面。
- `docs/discovery_cortex/09_ATLAS_WHITEBOARD_CONTINUUM.md`：3D、2D、白板与认识更新的连续关系。

仍然有效的核心原则：

```text
日常环境低摩擦，Foundry 承担工程复杂性；
Atlas 用于长期定向，白板用于深入理解；
人负责意义、质疑和决定，中枢负责计算、编排和复利；
艺术感来自认识结构、观看节奏与视觉诚实，不来自装饰。
```
