# 积分与几何面积的区别，现在可以在图上核对

2026-09-27，本地完成，未提交、推送或部署。本文接续《生成白板的积分练习》，记录三角函数与正负面积这一轮扩展。

## 用户能看到什么

以 `∫_0^{2π} sin(x) dx` 为例，曲线在横轴上方和下方各围出面积 2。定积分是 `2 − 2 = 0`，几何面积是 `2 + 2 = 4`。

- 预测题同时问定积分 I 和几何面积 A，答错后会指出是把面积当积分，还是误以为抵消后就没有面积。
- 图中分别标出横轴上方与下方区域，并配有正负文字说明，不只依赖颜色。
- 数值区同时显示定积分、几何面积和上下两部分面积。改变矩形数量时，矩形和会变化，原区间的精确积分与面积不变。
- 变式题保留函数、改变区间，重新计算 I 和 A；答案与解析由程序生成，不采用模型自行声明的“已核验答案”。
- 练习仍可跳过、查看提示或答案。只记录本页练习状态，不写长期掌握度，也不把首次答对当作已掌握。

## 这轮支持到哪里

支持 `sin(x)`、`−sin(x)`、`cos(x)`、`−cos(x)`。用户的目标与补充材料中必须只有一个可识别的显式定积分，端点明确写成 π/2 的整数倍，或零。端点绝对值不超过 8π，区间宽度不超过 8π；演示的函数、上下限、取样方式与初始分割数还要通过绑定检查。

写成 `3.14`，甚至写成与浮点 π 相同的小数，都不会被当作精确 π。带频率或平移的三角函数、`2*sin(x)`、π/4 端点、多重积分请求等，尚不附加这套精确练习。原来的有界多项式练习继续保留。不支持附加练习不等于拒绝整个白板，原演示仍需通过既有质量检查。

答案使用原函数在 π/2 整数倍处的精确值，并在每个 π/2 分段，覆盖所有过零点。独立数值积分只用于测试对照，不用于判定答案是否正确。

## 一起修掉的问题

负区间支持 Unicode 负号 `−`，不会把 `−π/2` 丢掉。刻度标签保留原请求中明确给出的 π 信息，不从小数猜测。

正文里的具体积分也会参与自动修复核对。可识别的正文公式若写的是 `[0, 2π]`，不能仅因包含“π”就把图修成 `[0, π]`；被积函数变号也不能混过去。同一演示段落里有多个不同的可识别积分时，暂不猜测哪个是主问题，交给后续生成修正。该检查只覆盖受限解析器能识别的具体公式，不代表已解决所有自然语言、推导或公式间的一致性问题。

浏览器计算正负抵消时可能留下约 `5×10⁻¹⁶` 的浮点残差。只有相对于总绝对贡献极小的残差才显示为“≈ 0”，内部数值不改，真正很小但同号的积分不会被一律抹成零。此规则仅用于显示。

图中的积分和面积仍明确标为“数值参考”。两种分辨率结果接近，不是积分存在性或误差上界的数学证明；练习上方的精确结论来自受限的独立计算。

浏览器测试拦截全部网络请求，使用真实后端组装结果和本地构建页面，没有真实模型调用。本轮没有重跑会调用外部模型的全站浏览器脚本，也没有测线上 Coze 生成成功率。前端构建已有的父级 Vue 配置和包体大小提示仍在。

这些结果验证的是受限条件下的答案与界面行为，不是学习效果实验，也不是通用生成全部稳定的证明。
