# P0 第一批修复与验证

日期：2026-09-27。状态：本地实现，未提交、未推送、未部署。没有调用真实扣子生成。

## 已实现

| 问题 | 现在的处理 |
|---|---|
| 答错却增加掌握度 | 明确错误计 0；未知正确性、跳过和非作答事件不记掌握证据。速度和自信不再加分 |
| 提示后完成与独立完成混在一起 | 独立首答正确记 1，辅助信息缺失、看过答案、使用提示或重试后答对记 0.5。这是产品规则，不是已校准的掌握概率 |
| 牛顿定律正反比写反 | 对“合外力不变但质量越大加速度越大”等明确断言拒收；引用误区、明确否定和询问正误不当作肯定结论 |
| 导数预测答案与演示不一致 | 明确的多项式取点问题从演示函数独立求导，比对题面函数、取点和数字选项；错误答案、题面错配和重复正确选项拒收 |
| 基准评分误认被否定的数字 | M02 积分值改成绑定明确结果的检查。否定/误区中的数字不算答案；互相矛盾的明确结果不能仅靠一个正确数字通过；近似矩形和与积分极限分开 |
| 旧质量缓存冒充新结果 | 质量版本升级为 1.8；前端与后端同步修改，网关默认缓存名称包含质量版本。部署时必须一同发布，不能单独更新前端 |

质量警告现在保留在返回结果中。无法通用核验的预测题，场景说明会注明核验范围；不会把安全解析当成一般性的学科正确性证明。

## 范围限制与下一步

1. 导数自动核验限于明确题面、数字选项、最高 12 次的受限多项式。三角函数、尖点、变量分母、含糊问法和一般开放题仍未覆盖；不会用差分估算把不存在的导数算成 0。
2. 物理文字检查是有限的高确定性规则，不是通用自然语言证明器。口语问题映射、完整事实合同和通用矛盾检查还未完成。
3. 旧数据库中的掌握度没有清空或自动重算，避免改动已有学习记录。后续应考虑带版本的学习证据，另行决定是否迁移历史数据。
4. 尚未把当前知识场景预测题接到旧 widget 的事件和复习接口。接入前仍需做服务端判分、事件去重、揭示状态追踪和题目版本绑定，不能直接信任客户端上报的正确性。
5. 下一批适合做积分的错因反馈与一道独立变式，再扩到其他学科；本轮没有把整个 P0 或学习闭环宣称完成。
