# 学习白板下一步怎么做

复核日期：2026-09-27。代码基线：`codex/learning-board-v1`，`d299a6b`。

后续实施：[P0 第一批修复与验证记录](P0第一批修复与验证-2026-09-27.md)。本文保留研究时的发现和结果，不能把下列 1.7 反例结果当成修复后的现状。

## 结论

白板已经能组织正文、推导和多种可操作的图，但“内容经过校验”还不能理解成“学科内容正确”，看完一张板也不能当成掌握了知识。

建议下一阶段围绕三个问题做：讲错了能不能发现；用户错在哪里能不能知道；换个条件后用户能不能自己解释。现有测验、事件回写和复习模块可以复用，不需要重新搭一套学习系统。

本轮完成了原始研究查阅、代码对照和离线反例测试。新增的是研究报告、可重复运行的探针和原始结果，**没有修复产品代码、部署服务、调用扣子或验证其余额**。

## 一、已有东西与实际缺口

| 环节 | 当前实现 | 下一步缺什么 |
|---|---|---|
| 生成前交流 | `App.tsx` 用关键词判断，最多两轮固定追问，再确认目标 | 识别“不会哪个前置概念”“卡在哪一步”，允许自然纠正目标；目前不能当作完整的自由辅导对话 |
| 内容与演示 | 有安全的结构化场景、公式、图像、参数联动和预测组件 | 一个核心关系在题目、公式、图、预测答案之间保持一致 |
| 内容校验 | 质量门 1.7 检查篇幅、主题词、演示类型，以及部分显式数学/物理条件 | 一般性的矛盾、否定、错误答案，以及口语问题与学科概念的对应 |
| 学习反馈 | 旧 widget 路线有 QuizCard、事件、掌握度和复习队列 | 当前 `PredictionFrame` 只有本地选项与揭示状态，没有事件回调；不能直接接收后续复习证据 |
| 掌握度 | 加权证据分数与移动平均已实现 | 自信、答得快不应在答错时被计为知识掌握；有帮助答对与独立答对要分开 |
| 效果验证 | 有 20 题目录、规则评分和若干历史生成报告 | 未见能支持“普遍稳定”和“学习效果提升”的完整对照证据 |

具体代码入口：`frontend/board/src/App.tsx` 的 `buildLearningContract/handleIntakeSubmit`；`knowledge-scene/SceneRuntime.tsx` 的 `PredictionFrame`；`BoardShell.tsx` 的 `postWidgetEvent`；`core/boards/mastery.py`、`writeback.py`、`review.py`。

这延续了《白板落地研究》的“练习—反馈—复习”方向，但需要修正其中简单加权掌握度的建议。工程上写出了一个分数，不代表这个分数已经有教育测量上的依据。

## 三、学习研究对设计有什么约束

| 原始研究 | 研究说了什么 | 对白板的启发与限制 |
|---|---|---|
| [Kestin 等，Scientific Reports，2025](https://www.nature.com/articles/s41598-025-97652-6) | 大学物理两节课、194 名纳入分析的学生，结构化 AI 辅导的即时测验表现更好。作者还报告，仅靠系统提示不能可靠组织多步骤问题，平台另行控制步骤 | 让程序保存当前问题、进度和可用提示。不能据此宣称任意模型、任意学科或长期学习都有效 |
| [Bastani 等，PNAS，2025](https://www.pnas.org/doi/10.1073/pnas.2422633122) | 近千名高中生的数学实验中，无护栏助手提高了练习表现，但撤掉工具后的考试表现下降；教师参与设计的提示护栏基本消除了负面效应，并未显示考试优势 | 需要“不看答案完成新题”的环节。解题时顺利、满意或自信，不能代替独立测验。该文后续[更正仅涉及作者单位](https://pmc.ncbi.nlm.nih.gov/articles/PMC12403119/) |
| [Roediger 与 Karpicke，2006](https://learninglab.psych.purdue.edu/downloads/2006/2006_Roediger_Karpicke_PsychSci.pdf) | 文章材料的两项实验中，重复阅读有即时优势，检索练习在延迟测验中更有利；重复阅读也会增加自信 | 给用户一个短的无提示回忆机会，并分开记录即时与延迟结果。这不是对当前数学动画或某种复习间隔的直接验证 |
| [PhET：指导方式对模拟探索的影响](https://phet.colorado.edu/publications/Paulson_etal_2009/Paulson_etal_2009.pdf) | 12 人的模拟操作访谈中，以少量核心问题驱动的探索，比细分指令式活动出现更多自主探索 | 保留“自由探索”和“跳过”。不要让每张图前面都弹出必答题；这是小样本探索行为证据，不能推出最少指导一定学得最好 |

综合判断：复杂解题可以有清晰步骤，图像探索可以有自由空间。两者不冲突。白板不宜统一成“从头答完一串选择题才能看内容”。

以下方案是基于上述证据和代码现状提出的产品假设，尚未证明能提升 Axiom 用户的学习效果。

## 四、值得新增的五个能力

### 1. 看得见的对应关系

点击正文里的一个量，图上对应对象、公式里的符号和推导中的这一步同时标亮。拖动一个参数时，其他表示只改变相关部分，颜色和名称保持一致。

已有 semantic IDs 和共享参数可复用。接下来需要的是一致性检查和缺失映射提示；不要仅因为三个视图都在动，就宣称它们解释的是同一件事。

验收例：积分的函数、上下限、取样方式与矩形和一致；把上限改动后，图形、数值和解释同步变化，不出现旧结论残留。

### 2. 根据具体错误给反馈

预测错误后显示一条对应错因，而不是所有选项共用一段解释。例如把“面积”和“带符号的积分”混为一谈，就请用户把区间拖过零点，观察负面积的贡献。

保留跳过和“不确定”。首次作答前不展示解答；揭示后的改答只算练习，不能再算独立首答。用户也可选择直接查阅结论，不因此得到负面学习标签。

### 3. 换条件，试试看是否还成立

一次学习只给一道短的变式，改变一个关键条件。答完后比较原题与新题的共同关系，避免只是换数字算一遍。

例：学会 `∫₀^π sin(x)dx=2` 后，问 `∫₀^{2π}sin(x)dx` 和几何面积是否仍相同。前者为 0，后者为 4；检查的是带符号累积的理解，不是背原题。

### 4. 分级提示与局部补讲

提示分成“看哪一个条件”“用哪条关系”“关键一步”三个层次，用户按需展开。不理解哪一段就补讲哪一段，保留其他正文、笔记和参数状态。正文继续保留结论，完整推导放在旁边。

重生成范围必须有明确 section ID 和 revision，失败不替换原板。不能为了修一句解释整板刷新，丢掉用户正在比较的对象。

### 5. 短复习与材料证据

用户选择加入复习后，下次从一个简短问题开始，而不是直接重播长讲解。独立回答后再展示原白板对应段落。

材料类白板同时增加“这句话来自哪里”：链接到原文片段，区分材料直接陈述、模型推断和外部补充。人文问题允许不同解释，不套用只有一个答案的物理题评分。

## 五、怎样扩展到不同学科

| 内容类型 | 用户真正要做的动作 | 可以复用的底座 | 不该省略的边界 |
|---|---|---|---|
| 数学 | 改区间、找反例、解释不变量 | 黎曼和、函数图、极限显微镜、约束几何 | 定义域、极限条件、有符号量与几何量区别 |
| 物理 | 改一个条件，判断方向和守恒关系 | 受力图、场实验、共享参数 | 单位、正方向、适用模型；不能任意混用摩擦模型 |
| 化学 | 改反应物的量，找限制反应物 | 柱形图、过程图、数量表 | 配平、物质的量、守恒；反应速率不等于平衡位置 |
| 生物 | 追踪物质或信息经过哪些步骤 | 过程图、概念图、对照面板 | 空间位置、方向、必要条件；图示不是全部真实机制 |
| 计算机 | 输入边界数据，预测下一步状态 | 有向关系、时间步骤、受控状态表 | 执行轨迹来自已校验逻辑，不让模型随意画一个“运行结果” |
| 人文与材料阅读 | 比较证据、条件与不同解释 | 对照表、时间线、证据链接 | 标出出处与解释分歧；箭头不等于已证明因果 |

目标是覆盖不同学习动作，不是声称三张演示或若干图形组件已经覆盖所有场景。

## 六、实施顺序与验收

### P0：让“通过”更可信

1. 将目标拆成独立字段：知识问题、题目条件、材料、呈现偏好。不要全部拼成字符串再用词面相似度判断。
2. 对可计算结论建立受限的事实检查：值、单位、方向、表达式、有效条件。正文、预测和演示引用同一事实 ID，但事实本身仍需独立验证；自洽不等于真实。
3. 预测题用结构化判定条件关联演示，计算能够验证的答案。不支持的开放式问题明确标注“未自动核验”，保留人工复核或模型辅助检查，不能强行给 approved。
4. 把本轮反例、正确改写、否定和引用错误答案的表达加入回归；迁移 M02 等仍只匹配数字的评分项。不得通过放宽门槛来提高成功率。

验收：错误结论与错误预测必须被阻断或明确降级；正常对照不能误杀；口语问法能映射到正确概念但不悄悄更换问题。先有限领域做对，再增加检查覆盖面。

### P1：接通一次完整学习过程

从积分做一条小范围试点：解释 → 可选预测 → 操作 → 按错因反馈 → 一道独立变式 → 自愿加入复习。完成后再试物理和材料阅读。

复用旧事件接口前需要确认：服务端根据题目版本核对答案，不直接信任客户端传来的 `correct`；事件有唯一 ID，重复提交不重复计分；揭示、提示、跳过与独立作答分开。`PredictionFrame` 只传递事件，不自行决定掌握度。

掌握度先用可解释状态：“尚无独立证据 / 有提示完成 / 独立完成 / 延迟复测通过”。信心用于识别“很有把握但答错”等情况，不直接奖励知识掌握；速度暂不参与跨题比较。上述状态仍是产品记录，不应包装成已经校准的心理测量。

验收：答错不会提高独立掌握证据；慢但正确不因读题时间吃亏；跳过不等于答错；重复事件和重开页面不会刷出掌握；旧板与笔记在补讲失败时保持不变。

### P2：验证是否真的比纯文本好

先冻结评估材料，再做有限真实生成与用户试用，避免边改题边报告分数。

- 生成评估：20 个固定题目另配 20 个事先保留的条件变式。先按 6 个学科各跑 1 个真实生成探针，确认服务、流程版本与计费后再展开。没有完成的轮次不能算入结果。
- 单独记录远程首轮通过、修复后通过、缓存命中和离线演示。冷生成样本不能混入 `provider=demo`；离线重评分不能算一次新生成。
- 记录模型/工作流/质量规则版本、条件保持、正文—图形—答案一致性、耗时和服务端可得用量。P95 需要足够样本才有参考意义；无法取得真实积分消耗就记未知，不凭 token 猜额度。
- 学习试验：同一知识目标、同一内容质量，比较文字、静态图文、交互图文；控制时间或明确把自选用时视为研究条件。采用随机分配或不同主题间的平衡安排，不让同一人反复做同一题造成练习偏差。
- 主要看无辅助的变式题与延迟测验；满意度、点击次数、播放完成率只作辅助。小规模试用适合发现使用障碍，不能直接宣布统计显著；正式样本量需要预先做功效设计。
- 学习记录默认本地最小化保存；跨会话复习与研究数据收集分别征求同意。记录题目版本、尝试与提示情况即可，不必保存姓名、学校或完整聊天原文。研究导出需检查自由文本中的身份信息。

暂不优先：新增大量动画类别、自由代码执行、排行榜、未经验证的“学习风格”自动画像。当前已有组件够做上述试点，先把一条学习过程做得可信更有价值。
