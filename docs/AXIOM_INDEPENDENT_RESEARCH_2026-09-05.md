# 第一部分：独立研究

## 1. Axiom 应积累什么

**提案：Axiom 的长期产出应是逐渐增长的判断与行动能力。** 可检索记录、较好的答案、漂亮的信息空间都可以服务于它，但不能分别充当成功的充分条件。

人的完整过程包括：遇到问题、形成暂时理解、发现盲区、选择行动、看到后果、重新理解。产品需要让这条过程跨天、跨主题持续，而不能把一次提问的结束当成事情的结束。

Engelbart 的研究把人的能力放在人、工具、语言、方法和训练的整体中讨论。这提供了一个起点：评价单位应包含人在系统中怎样工作，不能只计算模型生成了多少内容。[原始报告，1962](https://www.dougengelbart.org/content/view/138/)

建议以五个可观察结果判断 Axiom 的价值：

1. 更早注意到值得思考的问题，包括此前没有主动搜索过的问题。
2. 能理解一个解释，也能指出它在哪些条件下不成立。
3. 能以较小代价试探机会，而非仅收集令人兴奋的建议。
4. 暂停之后能恢复思路，不必从长聊天里重建背景。
5. 过去的经验能改变下一次判断，错误经验也能被撤销和修正。

点击率、停留时长、生成数、节点数、用户赞同率都不宜作为最高目标。用户快速理解并离开，也可能是成功。

## 2. 人与中枢：分清职责，同时保留认识上的主动权

**证据：人机组合不自动产生协同优势。** 一项纳入 106 项实验、370 个效应量的元分析发现，组合平均优于人单独完成，却低于人或 AI 中表现较好的一方。研究覆盖的是 2020 至 2023 年发表的实验，不能直接预测今天某个模型的表现；它否定的是“组合天然更好”这种默认假设。[Vaccaro 等，2024](https://www.nature.com/articles/s41562-024-02024-1)

**推导：劳动分工、决策权限、可见信息要分别设计。** 人不需要监控中枢的任务队列，但需要知道会影响判断的假设与证据缺口。

| 内容 | 中枢承担 | 人日常看到什么 |
| --- | --- | --- |
| 搜集、抽取、去重、排序 | 自动执行并记录来源 | 与当前问题有关的材料；必要时查原文 |
| 形成主题、关联、候选解释 | 持续探索，可保留多种竞争解释 | 为什么值得关注；另一种解释是什么 |
| 事实与个人偏好 | 保存来源、时间、冲突、修订 | “当时如此”和“现在如此”可以区分 |
| 实验与预测 | 设计、模拟、跟踪、比较结果 | 想检验什么、代价是什么、结果改变了什么 |
| 价值取舍与承诺 | 明确约束并辅助比较 | 人可改目标、拒绝结论、撤销授权 |
| 调度、索引、模型调用、内部评分 | 工程环境管理 | 日常仅在故障或限制影响结果时出现 |

不需要展示模型的私有思维链。应提供可核验的简明说明：用了哪些材料、采用什么假设、哪些替代解释仍成立、哪些观察会改变判断。

一项 319 位知识工作者的调查发现，对生成式 AI 的信心与较低的自报思考投入相关。它不是长期能力退化的因果证明，但提醒我们不能只优化“让人更快接受”。[Lee 等，CHI 2025](https://www.microsoft.com/en-us/research/publication/the-impact-of-generative-ai-on-critical-thinking-self-reported-reductions-in-cognitive-effort-and-confidence-effects-from-a-survey-of-knowledge-workers/)

人的主动权不应被还原为大量确认按钮。更重要的动作是：指出错误、替换假设、比较另一种解释、把话题带到新的方向。简单查询可以直接给答案，不应强迫每次使用都变成批判性思维练习。

## 3. 自主发现：允许中枢提出原本没人问的问题

### 3.1 自主性应扩展到议题和方法

**提案：中枢应能自主发现值得研究的问题，形成研究计划，并在许可范围内自己推进。** 触发源可以是个人目标与现实变化的错位、反复失败、不同领域的机制对应、公开资料中的异常、新工具造成的成本变化。不能仅限于提醒待办、整理记忆和维护数据库。

用户只需定义长期意图、禁区、资源上限和打扰偏好，不需要逐条指派研究题目。中枢应保留探索余地：有些问题短期不能映射到已有目标，但可能扩展人的选择空间。

把自主性拆成独立授权的能力：自行选题、自行寻找证据、自行构造模型、自行运行可逆实验、自行呈现发现、自行改进研究方法。最后一项可以在工程实验环境中运行候选方法、对照评测并保留版本，不能悄悄改变个人事实、价值目标或生产权限。

### 3.2 最新证据支持什么

Co-Scientist 展示了生成、批评、改进假设并与实验衔接的可能性。其 203 个目标上的自动评估与三个生物医学方向的实验验证不是同一种证据；后者包含专家参与。可借鉴外部验证闭环，不能据此声称通用自主创新已经解决。[Nature，2026-05-19](https://www.nature.com/articles/s41586-026-10644-y)

AI Scientist 已能完成计算研究流程；论文报告的三份入选投稿中，一份达到工作坊评审门槛，且存在人工筛选与方法、实现、引用错误。说明值得大胆试验自动研究，同时需要区别“写成论文”“通过评审”“发现可靠知识”。[Nature，2026-03-25](https://www.nature.com/articles/s41586-026-10265-5)

### 3.3 “公式”应成为可迁移的解释工具

对于用户所说的跨领域规律，中枢应保存四种不同东西：

- 数学定理：结论在明确假设下成立。
- 经验规律：特定测量、群体与环境中得到支持。
- 机制模型：描述某种生成过程，参数与结构可以错。
- 启发性类比：帮助提出问题，还不能直接推出事实。

把四者混用，容易得到很有感染力但无法检验的“道理”。渗流是一个例子，不应成为所有社会现象的默认模板。

因果迁移研究说明，跨环境使用因果结果需要表达环境之间的差异和共同假设。这里可借鉴的是检查迁移条件的方法，不是宣称一个形式体系能证明任意哲学类比。[Pearl 与 Bareinboim，2014](https://ftp.cs.ucla.edu/pub/stat_ser/r400.pdf)

**提案：每个跨领域发现都经过一条可追问的过程：** 原领域机制是什么；新问题中的变量能否对应；哪些条件明显不同；存在什么更简单的解释；能提出什么区分这些解释的观察或小实验。没有可测量变量时，明确停留在启发阶段。

### 3.4 机会发现的产品形态

中枢可以发现“某种需求正在变得更迫切，而实现成本正在下降”之类的候选机会，主动寻找需求方、替代方案、失败记录和时间窗口。展示时应分清：观察到了什么、预测什么、可以尝试什么。

一份有价值的机会呈现应带有：最强依据、最危险假设、已有竞争解释、最小验证动作、时间范围、失败后仍能得到的知识。真正的结果由后续观察决定，不能用人的兴奋或模型互评代替。

对外发布、花费、修改真实系统等行为按既定权限执行；低风险检索、计算和隔离实验可以自行推进。边界应限制行为影响，而不是限制思考的新颖程度。

## 4. 复利与可迭代性：保留能改变下一次行为的经验

**提案：复利至少有四个来源。** 世界知识更准确；个人情境更连贯；研究方法更有效；人与 Axiom 形成更省力的共同表达方式。资料总量增长不能替代这四件事。

建议长期保留：

- 判断的版本、适用时间和来源，避免旧事实被当成现在的事实。
- 预测及其到期结果，包括错得很自信的预测。
- 实验失败的具体条件，避免同一坏建议换个说法重复出现。
- 用户明确纠正的事实和偏好，以及允许遗忘的边界。
- 曾被忽略但后来有用的少数派线索，避免只复用高频知识。

LongMemEval 将时间推理、知识更新、跨会话推理和应当拒答等能力纳入测试，说明“能召回一段话”不足以衡量长期记忆。其结果来自特定基准，不应外推成 Axiom 的准确率。[ICLR 2025 论文](https://arxiv.org/abs/2410.10813)

复利也可能倒转：错误摘要反复被检索，会逐渐成为看似有许多支持的事实。因此，衍生内容不能增加独立证据数量；撤销源材料时，应能追踪影响到的判断。用户删除应覆盖适用范围内的索引、摘要与派生记忆，保留策略需透明。

一项基于 4130 万篇自然科学论文的观察研究报告了 AI 使用与研究关注面收窄的关联；本文仅核验了公开摘要与可用资料，不将其视为生成式个人助理的因果结论。它提供一个有价值的反向问题：更高效率会不会把探索集中到资料最多、最容易被评分的区域？[Nature，2026-01-14](https://www.nature.com/articles/s41586-025-09922-y)

**提案：为陌生领域、反证、低频但高影响的候选方向保留研究预算。** 预算比例应根据实际收益调整，不能把一个漂亮百分比写成普遍规律。

## 5. 前端总体形态：持续中的事情是人的入口

### 5.1 日常主画面

**提案：首屏围绕一个正在继续的事情组织。** 上方保留轻量、稳定的定位与搜索入口；主体恢复上次阅读或思考位置；有实质新进展时就地标明变化；旁边或下方提供少量可进入的其他事项。用户也能直接放入文本、文件或语音。

首次使用没有历史时，输入或导入就是实际体验，不构造虚假的知识宇宙。没有重要发现时，保留安静状态，不为填满页面制造建议。用户只想查找原始记录时，结果列表应直接可达，不强制进入 AI 故事。

导航按人的目的组织，例如继续某件事、查找材料、探索相关方向；具体入口数与名字在原型中验证。禁止从数据库表或内部模块名直接生成日常一级导航，但不因此消灭稳定导航。

### 5.2 低摩擦的完整定义

这里用一个设计检查表，不声称是实证公式：

`使用负担 = 表达 + 选择 + 导航 + 核验 + 恢复 + 纠错`

少一个按钮但需要重新描述上下文，未必更低摩擦。自动推断错了且不好改，也可能比一个小选项更费力。保留显式命令、可发现的操作和自然语言，两者不互斥。

人机交互指南强调预期管理、纠错、控制与随时间适应。它支持这种评估维度，不能推出“全部交给聊天”或“完全无界面”。[Amershi 等，CHI 2019](https://www.microsoft.com/en-us/research/publication/guidelines-for-human-ai-interaction/)

### 5.3 连续性

同一个问题可以经历材料阅读、Atlas 定位、白板解释、方案比较和行动跟踪。转换表现形式时，问题、选中对象、来源和返回路径不能丢失。用户不需要重新选择“模块”来搬运上下文。

人的输入记录与 Axiom 的解释要视觉可辨；旧版本可以回看。新资料到来时先提示差异，不在阅读过程中把整个空间重新洗牌。

## 6. Atlas：关于某件事的空间认识

### 6.1 先确定可完成的问题

Atlas 应帮助人判断：这件事与哪些经历或知识有关；已知解释聚集在哪里；有哪些桥接关系值得看；我的理解最近怎样改变；下一步深入哪个方向。

它不必显示机器知道的全部对象。没有人的任务含义的节点即便结构正确，也可能不值得出现在日常图面。

可视化的嵌套模型要求依次检验领域任务、数据抽象、视觉编码、算法；上层判断错误会传递到下层。对 Axiom 的推导是：先验证人通过 Atlas 获得什么，再选择维度和布局。[Munzner，2009](https://www.cs.ubc.ca/labs/imager/tr/2009/NestedModel/)

### 6.2 推荐先验证的默认形式

**提案：以稳定的二维语义地图作为桌面和手机的共同基线，允许局部空间深度；3D 保留为需证明收益的候选。** 理由是阅读、定位、比较和触控的共同成本，而非二维具有普遍优越性。

地图由有意义的区域标题、少量代表对象、正在关注的局部关系组成。多数情况下，文字、真实材料缩略图和区域组织承担信息；点与线辅助定位。用户关注对象时，其周围可以展开不同种类的关系，不能把每件事压成相同的小点。

这是反过来检验点线图的适用范围，并非建议首页密铺大卡片。记录可以是标记，主题可以是文字区域，文献可以呈现实际页面；显示形式要让人知道自己在看什么。

节点连线与邻接矩阵的实验展示了任务依赖：路径与密集连接的读取需求不同。早期研究使用随机图及特定布局，其节点数量阈值不能直接作为 Axiom 上限。[Ghoniem 等，2004](https://aviz.fr/wiki/uploads/Teaching/MatrixVsNodeLink.pdf)

Ware 实验室的三维网络研究包含立体显示与运动线索。由这些条件得到的收益，不能直接搬到普通笔记本和手机。Axiom 的 3D 原型必须在目标设备上与二维基线比较后再决定是否成为默认。[UNH 原作者实验室](https://vislab-ccom.unh.edu/projects/networks/)

### 6.3 视觉含义必须写清

| 视觉属性 | 建议承载 | 必须避免的误读 |
| --- | --- | --- |
| 位置与区域 | 当前问题下的组织关系、稳定地标 | 机器聚类就是真实世界分类 |
| 距离 | 有限的局部邻近提示 | 任意两点距离都是精确关联强度 |
| 尺寸 | 当前层级与交互层级 | 大就是重要、真实或有价值 |
| 亮度 | 当前注意对象与阅读层次 | 亮就是证据充分 |
| 连线 | 能用简短句子解释的关系 | 同时出现、相似、因果是一回事 |
| 空白 | 排版余地、当前没有展示 | 已经确认这里是未知领域 |

t-SNE 的实例研究展示了簇面积与跨簇距离的误读风险。不能把这份研究泛化成所有布局都无用；它要求我们核验具体表示能保留什么，再承诺视觉含义。[Wattenberg 等，2016](https://distill.pub/2016/misread-tsne/)

同一张图里，“A 与 B 语义相似”“B 是 C 的来源”“C 反驳 A”不共享同一种强度尺度。减少到中心的距离，不足以表达这些关系。必要时用关系句、局部路径或并列对照，不强求全局几何自洽。

### 6.4 未知、变化与不同观点

未知需要有来源：尚未回答的问题、缺少某类测量、两组材料冲突，或用户主动提出的探索方向。AI 无法从嵌入空间的一块空白直接读出“值得发现的新知识”。

地图应允许围绕不同问题形成不同视角，保留人工命名的稳定地标。方向改变时解释重组原因；时间变化应有前后对照。初期不用五个抽象标签充当人的探索任务。

常规边可以安静；与当前判断相关的反例不能因为“弱相关”被自动抹掉。显示预算要包含反证价值与任务必要性，不能只按语义相似度排名。

## 7. 白板：Axiom 组织信息，人可以改变解释

### 7.1 它呈现的是一个可以被追问的理解过程

**提案：白板由 Axiom 主动编排，用户无需摆卡片、连线或学习画布工具。** 中枢根据问题选择材料、布局和适合观察的交互；用户可以暂停、展开、改参数、比较、质疑、返回。

采用“解释场景”作为研发中的暂用称呼，不急于变成界面品牌。一个场景回答一个主问题，具有稳定标题、关键观察、解释对象、适用边界与下一步；材料复杂时分层进入，不用无限横向画布把整理劳动转交给人。

叙事可视化研究讨论了作者引导与读者探索之间的张力。对 Axiom 的推导是：可以提供建议阅读顺序，但必须允许跳读、岔路和反向检查。[Segel 与 Heer，2010](https://idl.uw.edu/papers/narrative)

### 7.2 不同内容应有不同构图

| 人的需要 | 合适的主要表达 | 必须随表达出现 |
| --- | --- | --- |
| 理解一个机制 | 分步示意、可控模拟、变量联动 | 假设、变量单位、模拟与观测的区别 |
| 比较两个选择 | 同尺度并列、差异定位、情境切换 | 缺失项、权衡、结果敏感性 |
| 理解变化 | 对齐时间线、前后版本、事件与趋势 | 时间范围、测量变化、不能归因之处 |
| 检查一项主张 | 主张与关键支持、反证就地对应 | 原始出处、独立性、争议状态 |
| 探索未知方向 | 竞争假设、开放问题、最小试验 | “尚无结果”与“已有否定证据”的区别 |

不要对所有问题生成同一种图谱，也不要把完整报告切成十几个等价卡片。一句话能直接回答的问题无需生成白板。

### 7.3 生成自由与交互稳定

生成式界面研究表明，任务化视觉组织有吸引力。但其真实用户查询子研究中，76 人的 380 个问题呈现的是 50.8% 胜、41.1% 负、8.2% 平；不能用摘要中最强的偏好数字替代所有场景。论文也观察到专业外观带来的可信感，尚不能据此断言判断更准确或长期学习更好。[Chen 等，ACL 2026 Findings，全文](https://arxiv.org/html/2508.19227v3)

**推导：允许内容和构图生成，保持操作语法稳定。** 来源入口、返回、比较、暂停、参数修改在不同场景中遵守相同逻辑。中枢可以选择适合问题的呈现，但不能每次重新发明按钮含义与导航习惯。

动态界面的可实现性已有官方原型与协议探索；这是工程可行性线索，不是效果保证。后续需要隔离不可信内容，确保生成的显示不能获得额外数据或执行权限。[Google Research，Generative UI](https://research.google/blog/generative-ui-a-rich-custom-visual-interactive-user-experience-for-any-prompt/)，[A2UI 官方介绍](https://developers.googleblog.com/introducing-a2ui-an-open-project-for-agent-driven-interfaces/)

### 7.4 内容可信度不能交给气氛表达

高亮可以引导注意，但不应让人自动把最亮的一句当成定论。关键限制直接靠近结论；材料出处可按需展开；内部调度日志留在工程环境。

如果展示概率，必须有明确事件、时间范围和估计依据；未校准的模型自评分不以精确百分数冒充可信度。有关联并不等于因果；多个转载不等于多份独立支持。

生成中的状态应真实呈现已找到的材料与正在等待的部分。查不到时允许有限答案和明确空缺；不能用完整漂亮的场景遮住检索失败。

## 8. 美学研究：让组织信息本身具备表现力

### 8.1 所需气质

**提案：暗色、清晰、有分量、细部精确，能长时间停留。** 真正的个性来自字体比例、材料呈现、空间关系和操作节奏。大面积黑色、发光节点、细线网格或一个诗意名称，都不足以构成艺术方向。

美学需要检验两种状态：停下来凝视时是否值得看；每天快速使用时是否仍然省力。只适合第一屏截图的设计不能通过。

### 8.2 从具体典范提取方法

以下是根据原作者或收藏机构资料提出的转译方向，不声称完成了作品现场考察、完整图像分析或用户审美验证。

| 参考 | 值得转译的方法 | Axiom 的具体尝试 | 不能照搬 |
| --- | --- | --- | --- |
| Eames，Mathematica | 同一概念通过图形、装置与时间展开，允许不同深度进入 | 一个机制既可看摘要，也可观察变量变化和解释细节 | 展馆的全部装饰与持续运动 |
| Marie Neurath，Isotype | 从资料到图示需要编辑、选择和转换的职责 | 先检查图到底解释了什么，再选择视觉符号 | 图标数量越多就越易懂 |
| Carlo Scarpa，Castelvecchio | 展示支撑、光线与间隔共同定义作品间关系 | 原始材料有清楚边界，批注与主体精确对位，留白有具体用途 | 把建筑纹理贴成网页背景 |
| Muriel Cooper，Information Landscapes | 文字、信息尺度与运动可形成连续的信息空间 | 层级转换时保留对象身份，让文字参与空间组织 | 长文在三维空间里翻飞，或用表演替代阅读 |

参考出处：[Eames Office](https://www.eamesoffice.com/the-work/mathematica/)，[Reading 大学 Marie Neurath 收藏](https://collections.reading.ac.uk/special-collections/collections/marie-neurath-collection/)，[Castelvecchio 雕塑馆说明](https://museodicastelvecchio.comune.verona.it/nqcontent.cfm?a_id=43070)，[MIT 的 Cooper 资料](https://www.media.mit.edu/posts/muriel-cooper-lasting-imprint/)。其中 Castelvecchio 全页本次抓取失败，使用官方搜索摘要，后续视觉阶段需补看原页与作品图像。

### 8.3 字体、密度与颜色

中文是主阅读语言。先比较中文正文、标题、数字与拉丁词混排的实际样张，再决定字体组合。选择指标包括笔画重量、字面大小、标点、长文密度、屏幕渲染和授权；不从“像某官网”直接推断具体字体。全局超细会失去力量，全局加粗也会消灭层次。

暗色底上，正文保持足够亮度；不以低对比灰字制造高级感。功能层级依靠位置、字重和间距共同表达。背景维持中性，材料自身的色彩、少量有语义的强调色与图表色共存，避免全站只有一组蓝紫或棕橙变体。

WCAG 2.2 为普通文字提供 4.5:1 的对比要求，大文字为 3:1，并规定非文本对比、可见焦点等要求。点击目标的 AA 最小标准是 24 CSS 像素并含例外，项目可以设更高的触控目标；不能把可见小点的直径直接当作命中区域。减少动效也应可用。[W3C 标准](https://www.w3.org/TR/WCAG22/)

### 8.4 动效与密度

运动承担明确工作：显示来源去向、揭示变化、维持层级转场连续性、反馈操作。阅读时保持稳定。延迟不应被不可跳过的入场动画放大，关闭动效后信息仍完整。

图面密度随任务和尺度改变。稀疏不天然高雅，密集不天然高效；一眼能抓住重点、继续看能发现次层，才是要验证的效果。重要内容应能占据足够面积，不平均铺成相同容器。

### 8.5 三个待比较的构图方向

1. **页式**：强排版、正文与材料批注对应，局部插入互动图；适合解释与回看。风险是过于像文档。
2. **地图式**：稳定区域、局部展开、关系与原始材料共同出现；适合探索与定位。风险是空间导航负担。
3. **展陈式**：同一问题的证据、机制与替代解释在视野中有主次地并置；适合发现与比较。风险是占屏和表演化。

初步倾向：稳定的日常框架，按任务使用这三种构图，而非把它们变成三个强制模式或整站风格。必须用同一份有真实信息负担的材料比较，不能一版有精心内容、另一版只放占位。

## 9. 两个环境：日常使用与工程维护

**提案：分离的是职责与风险面。** 日常使用允许中枢很主动；工程环境负责让这种主动可理解、可测试、可撤回。

日常环境围绕事情、材料、理解、选择和后续结果。用户能查看“为什么出现这项建议”和相关权限，但不用阅读任务图、模型调度或数据库结构。

工程环境围绕研究运行、失败、费用、数据权限、候选方法、对照实验、版本与回滚。它应是清晰的工作工具，不需要继承日常环境的艺术化构图。

两者共享可追溯结果，不共享默认执行权限。测试使用隔离资料与工具权限；个人真实内容最小化进入实验，公开演示使用明确标记的合成或授权数据。研究方法更新需要在未参与调优的案例上评测；不能只证明新方法在自己写的例子上更好。

“两套环境”不等于复制所有产品功能。用户目标、资料权属、产出来源应保持一致，而权限、数据集、发布节奏明确分开。

## 10. 用一个贯穿场景检验产品

以下是假设场景，不是对用户现状的推断，也不是现实机会建议。

某人持续收集有关小型工具与某职业工作变化的材料，但没有给中枢指定研究题目。Axiom 从多个独立来源注意到一种重复劳动发生变化，提出一个候选问题。

1. 日常界面只呈现值得查看的一句发现、其新意和一个关键不确定点，不推送一篇长报告。
2. 打开后，白板并列呈现需求证据、成本变化、反对解释；真实材料可直接定位。
3. 用户问“是否只是近期报道变多了？”场景增加观测偏差解释与时间对照，原结论不被静默覆盖。
4. Atlas 显示这一问题与既往经历、相关机制、相反案例的关系，允许进入陌生方向，而不是展示全部知识库。
5. 中枢提出一个低成本验证方法；授权范围内可以自行做公开资料检索和隔离模拟，涉及真实外部行动时遵守行为权限。
6. 一周后回到同一问题，页面恢复当时位置，并展示新增证据如何改变候选解释。
7. 结果不支持最初机会时，Axiom 保存失败条件，修正同类建议；不能把失败包装成新灵感继续重复。

这段过程同时检验自主性、人的主动权、Atlas、白板、低摩擦、时间连续性与复利。

## 11. 验证计划：先证实产品判断，再承诺形态

本轮没有运行用户实验，以下都是待执行计划。

| 需要验证 | 比较方式 | 主要观察 |
| --- | --- | --- |
| 哪种组织方式有效 | 同材料的短文、页式、地图式、展陈式 | 理解正确性、比较成功率、主观喜欢 |
| 艺术化是否诱发误信 | 明确标记的测试任务中放入已知错误与反证 | 是否能发现错误，是否因视觉强势忽略弱势证据 |
| 3D 是否值得 | 同内容与同任务的 2D/3D，桌面与手机分开测 | 定位、路径理解、重返位置、晕动与操作成本 |
| 低摩擦是否真实 | 记录、查询、纠错、恢复等日常任务 | 完成动作、重新解释次数、失败后的恢复 |
| 长期是否有复利 | 连续数周跟踪同类任务并保留旧版对照 | 复用收益、重复错误、预测改进、撤销传播 |
| 自主发现是否有效 | 与普通检索/单次回答及过去版本对照 | 新颖但可测的假设、外部验证、机会成本、多样性 |

先做单用户连续试用，发现交互缺陷；再扩展到相似目标用户。个人试用不产生群体统计结论。理解测试不应被强塞进普通日常流程；只有明确研究环节才使用测试材料。

首次可交付原型必须包含：空资料、长中文标题、慢网络、检索失败、相互矛盾的来源、撤销、手机窄屏和重新进入。漂亮截图不能替代这些状态。

## 12. 独立研究结论与下一步

**优先保留的产品目标：** 人与中枢分工；中枢主动提出新问题；AI 编排白板；日常与工程分环境；低摩擦、暗色、精细的视觉体验。

**优先试验的形态：** 以正在继续的事情为入口；稳定框架中的生成式解释；二维 Atlas 基线与可选空间深度；原始材料、关系句、竞争解释共同构成信息空间。

**不应先写死的选择：** 导航必须为零、必须固定几个入口、3D 必须为默认、所有对象必须为点、所有证据只能藏在抽屉、空白代表未知、某个艺术隐喻统治全站。

**最重要的新验收问题：** 用户是否能低成本理解并改变 Axiom 给出的解释；中枢是否能在无需逐条指派的情况下产生经外界检验的有用新发现。

下一步应先对照旧研究，随后以一份贯穿材料制作少量可交互的构图原型。先选产品与视觉方向，再转换为实现规格；本报告本身不授权删除旧功能或重写生产代码。

| 距离与解释关联 | Atlas §3.3、§6.1 用“共同改变判断”“解释关联”组织距离，且已声明不精确编码分数 | 方向合理，但这些关系的操作定义仍不足。不同证据角色未必共享可度量的距离，不能只换一个名称代替相似度 | 使用相似、因果、来源、反驳混合案例，验证布局是否误导 |
| 场景数量与节奏 | Atlas 默认 5 至 9 个领域；白板一次增加一层复杂度 | 作为初始预算可以尝试，不能写成通用认知容量。对比任务可能需要同步看到两侧，查找任务可能需要较高密度 | 按任务测不同密度和并列/逐步展示，避免强迫串行 |
| 重要问题的竞争解释 | 专题地图 §5.2、白板 §5.4 规定主解释、竞争解释与信息不足 | 保留真实异议与不确定性，但不能为齐全而生成虚假的对立面。无实质争议时说明边界即可；微弱观点不因占一栏而获得与强证据相同地位 | 用有争议与无争议两类材料检查假平衡和信息负担 |

这些是研究建议，不是本轮自动替换产品规范的决议。旧界面也没有因这些建议而被更改。

## 16. 本轮增加的证据与评估精度

### 16.1 不用“偏好提升”替代判断改进

旧文档已经防范视觉权威。本轮通过生成式界面的实际实验补充了更具体的区分：受控问题集与真实用户查询的偏好结果不相同；专业感提升也不等于事实判断提升。后续评估要分别测喜欢程度、正确理解、识别错误、恢复上下文，不能把它们压成一个总分。

### 16.2 更清楚地标注模型能力证据

本轮补充核验了 2026 年 Co-Scientist 与 AI Scientist 正式发表的研究。其价值在于证明可以积极尝试新的研究闭环；其范围不覆盖“任意社会机会都可可靠自动发现”。应分别记录自动评估、专家偏好、实验结果和后续实际效益，避免拿其中一个代替其他三个。

### 16.3 让复利资产能够被修正

旧研究对历史与失败已有充分重视。本轮增加的执行性检查是：同一来源的衍生内容不重复算证据；资料撤回能沿派生链传播；过时事实能与新事实区分；方法评测使用未参与调优的案例。这些是对既有原则的具体化，仍需在实现阶段建立测试。

### 16.4 把美学决定从文献结论中分出来

研究可以解释可读性、编码、偏好和交互成本，不能证明某种暗色气质、艺术谱系或构图就是 Axiom 的最佳人格。旧美学顶部对“未批准风格”的说明是正确的；后续应让正文中的强制句与这个状态一致。

## 17. 合并后的推荐方向

1. **中枢继续大胆探索。** 保留旧研究的自主选题、目的候选、理论生长与发现方法进化；用独立证据和现实结果区分创新与伪发现。
2. **日常入口围绕持续中的事情。** “此刻”可以保留，但其内容既可以是待行动，也可以是未解问题、阅读、观察或不急于优化的经历。不要让任务排序成为整个外脑的默认解释框架。
3. **Atlas 承担长期定向，维度先不定案。** 比较稳定二维地图、局部空间深度与完整三维候选；保留地标、桥梁、张力和时间变化等已成熟的语义。
4. **白板继续由 Axiom 编排。** 把稳定、直接的追问与改假设动作做出来，让人能走自己的阅读路径；图文、模拟、时间与比较按问题组合。
5. **连续性以人的恢复能力验收。** 对象、问题、来源和判断历史要连续；镜头运动与渐进展开是可选手段。
6. **两环境继续分离。** Foundry 既包含研究实验也包含系统进化，不能缩回维护日志；日常不承担工程管理，但关键依据不能被藏到 Foundry 才看得到。
7. **艺术方向留到实物选择。** 原方案与新提案均使用同一贯穿材料做实际构图；不再用代号、参考名单或生成图片的第一眼代替完整设计验证。

## 18. 下一阶段的最小决策包

不是立即批量改页面，也不再拆一轮泛泛研究文档。建议形成一个集中展示的交互样本包：

- 一份贯穿材料，包含真实来源、时间变化、竞争解释和失败情况；个人资料先确认使用范围，演示内容清楚标记。
- 三种构图使用同一材料：页式、地图式、展陈式；先把中文样张、信息密度、材料呈现和关键操作放在一起看。
- Atlas 的二维与三维只比较其适合的定向任务，不把白板的精读表现算进 3D 的成绩。
- 五个必走动作：恢复问题、查原文、找反证、改假设、离开后重新进入。桌面和手机都走一遍。
- 记录喜欢与不喜欢的具体部位，同时记录误解和操作阻力。通过这一轮，再修订产品模型与最终视觉规范。

尚未完成：作品图像的系统视觉审读、交互样本、中文字体样张、目标设备实验、长期复利测试，以及现有代码与新形态之间的实现差距审计。本报告不把这些工作记为完成。

# 第三部分：作品视觉审读与 Atlas 具体形态提案

## 19. 研究范围与本轮修正

本部分回应用户对“夜行长卷”模拟效果的否定，以及进一步研究美学、具体解释 Atlas 形态的要求。它是待验证的设计提案，不自动替换产品规范，不改现有前端。

上一轮的不足是：艺术参考和认识论原则尚未落实为可检查的构图、文字尺度、内容密度与材料关系。概念名可以说明意图，不能保证画面成立。本轮没有重新取得被否决的原图，因此不虚构对该图某个像素、字体或布局的诊断。

本次使用官方机构资料和浏览器实际图像观察：Eames 数学展陈入口与概率装置照片、纽约地铁图、MASP 开放画廊、Albers 图册与教学页色纸样本、Klee《主路与支路》，以及 David Small 论文第 32 页的信息空间图版。它是定向作品研究，不是完整艺术史调查，也不是用户实验。

访问限制：MoMA 的 Cooper 展览页在浏览器触发安全验证，因此改用 MIT 作者论文研究相关设计；SFMOMA 的 Mehretu 作品图像加载失败，仅读到机构文字，不纳入已完成的图像分析。未观看完整作品视频，不能声称验证了其动效体验。未把第三方作品图片下载或加入产品资产。

## 20. 从作品中提取什么，又明确不照搬什么

### 20.1 Eames：不同阅读距离的内容各司其职

实际观察的概率展陈照片中，实物机制、醒目的纵向文字、较小的图文说明和远处展墙并置；入口照片则用整体标题和展柜建立方向。信息不少，但不是同一种尺寸、同一种载体。[Eames Office：Mathematica](https://www.eamesoffice.com/the-work/mathematica/)

**对 Atlas 的转译：** 远处先认出问题领域，中距离辨认少量具体认识，近处看到原始材料。不是把全部资料缩成小字，也不是把所有资料都做成同样的卡片。

**不照搬：** 展厅动线、展柜造型、纵向拆碎单词。实物可绕行，不代表屏幕上的文字也应该让人绕行。

### 20.2 纽约地铁图：美感可以来自关系的纪律

图面中可见大量节点和线路，但重复的方向、受控的转折和相对安静的底图建立了秩序。作品由 Vignelli、主设计师 Joan Charysyn、Bob Noorda 和 Unimark 团队共同完成；MoMA 同时记录了当时的使用争议和 1979 年的替换，不能只引用其经典地位。[MoMA：New York Subway Map](https://www.moma.org/collection/works/89300)

**对 Atlas 的转译：** 少量一致的连线规则，比每条线各自弯曲更容易形成整体。选中的联系有明确起止点；交叉但无关系的线不能画出假交点；关系文字不会骑在线上绕弯。

**不照搬：** 所有边强制 45 度、彩虹线路、地理隐喻。图面简化必须保住实际理解，构图漂亮不能证明导航正确。

### 20.3 MASP：让材料自身成为主角

开放画廊照片中，各种尺寸、色彩和画框并未被抹平成同一种展示组件，重复的支架与通透空间维持了共同秩序。馆方说明，Lina Bo Bardi 的玻璃画架允许多条观看路径，作品说明放在背后。[MASP：Picture Gallery in Transformation](https://masp.org.br/en/exhibitions/picture-gallery-in-transformation-2020)

**对 Atlas 的转译：** 一张照片保留照片的比例，一段个人原话保留文字的直接性，一张研究图保留可辨认的形状。统一它们的对齐、题注和交互，而非给它们套同样的外框。

**不照搬：** 毛玻璃卡片、漂浮画廊、遮挡与绕到背后读字。Axiom 的关键假设与来源应当就近可读，不能以“先感受”为由隐藏。

### 20.4 Klee：密而不板，来自重复中的变化

《主路与支路》的图像中，一条较宽的连续方向与两侧更碎的分区形成对照；横向色带重复，但宽窄和局部节奏并不相同。ZDF 的 Museum Ludwig 专题也说明了主路与支路不同的构造方式。[ZDF / Museum Ludwig：Hauptweg und Nebenwege](https://geheimnis-der-bilder.zdf.de/museum-ludwig/paul-klee-hauptweg-und-nebenwege.html)

**对 Atlas 的转译：** 全图不等距撒点，也不对称排成几圈。局部有密集的认识组，组间留出可识别的间隔；少量连续路径穿过它们。变化来自材料和关系，而非随机抖动。

**不照搬：** 仿绘画色块、龟裂纹理、假道路或假地形。作品的中心路径也不能变成“AI 规定的人生主路”。

### 20.5 Albers：暗色设计要研究相邻关系

基金会教学资料强调颜色随周围环境改变观感；本轮实际查看了图册外观、内页和教学页色纸样本，没有进行显示器校色或完整实验复现。[Interaction of Color](https://www.albersfoundation.org/alberses/teaching/interaction-of-color)、[One Color Becomes Two](https://www.albersfoundation.org/learning/workshops/one-color-becomes-two)

**对 Atlas 的转译：** 先在真实照片、中文、细线并存的画面里判断明暗，而不是先定几枚色值后假定它们处处有效。重点对象可以靠清楚的边缘和相邻反差出现，不必加一圈发光。

**不照搬：** 满屏色块、方中套方，或用审美上的鲜明程度冒充证据强度。

### 20.6 信息空间实验：文字本身可以组织空间，但也会失去可读性

David Small 的《Rethinking the Book》第 32 页将整部戏剧的文字结构缩放呈现；第 34 至 39 页讨论透视、尺寸、留白与缩放带来的辨认问题。这比把 Cooper 的工作概括成“炫目的三维文字”更有用。本轮直接看到了第 32 页图版，没有完成其运行原型体验。[MIT：Rethinking the Book](https://acg.media.mit.edu/projects/thesis/DSThesis.pdf)

**对 Atlas 的转译：** 标题、段落轮廓和图像可以共同成为地标；缩放改变展示的内容层级。对象可以变化，阅读中的文字保持正向清楚。

**不照搬：** 透视文字柱、镜头飞行、把长文缩成无法阅读的纹理后仍算作“已展示”。

## 21. 新美学主张：构图先于皮肤，内容先于隐喻

我目前最推荐的方向是：**暗底、清晰排印、内容材料与精密关系线共同构成的开放图面。** 不再给它先起一个诗意代号，也不把某件艺术品当成全站皮肤。

画面的独特性应来自四件同时成立的事：

1. **文字具有构图力量。** 领域名称、问题原句、局部注释不是同等灰度的小标签；不同层级有足够明显的视觉区别，但没有占满半屏的宣传标题。
2. **疏密有层次。** 信息在局部形成紧凑组团，画面整体相连；既不是均匀网格，也不是围绕中心的辐射圆环。留白用于分隔，不伪称那里存在未知知识。
3. **真实材料带来差异。** 少量图像、原话、图表成为能够记住的地点，色彩主要来自这些内容。不能为了漂亮由 AI 给每个话题生成一张装饰封面。
4. **互动使关系被看见。** 安静时构图稳定；选择一条认识后，相关材料明确显现，路径和阅读位置可追踪。生命感来自回应，而不是全图一直活动。

暗色不等于低对比：背景以中性近黑为主，阅读文字明亮而不刺目，次要文字仍可读。色彩不能退化成单一蓝灰；内容可保留真实的鲜明颜色，界面自身只使用少量明确的强调。暂不重新发布一套未经画面验证的色板。

“精细”要落实在长短中文标题的断行、图片边缘、题注基线、转折处、选中状态与空白比例上。即使关闭所有动画、不给它贴艺术风格名，画面也应成立。

## 22. Atlas 打开时具体是什么

### 22.1 它不是数据库全量展示

Atlas 是人回看与探索自身认识的地方：我持续在理解什么，哪些事情彼此有关，某个判断怎样改变，还有什么值得探究。它并不负责显示中枢所有知识，也不是人生绩效仪表盘。

地图上的主要单位应当是可读懂的**问题、认识、经历和线索**，而不是 `memory/task/decision/item`。一句认识可能由多份资料支撑；同一资料也可以进入多个问题，不能强迫它只住在一个分类文件夹。

例如显示“什么时候该减少同时推进的事情”，而不只显示“效率”；显示“这次理解为何发生变化”，而不只显示“记忆节点 37”。名称需要能被用户纠正，不能被当成 AI 对人的定论。

### 22.2 首屏的构图

桌面打开后，主体是一整片无装饰外框的图面。边缘保留少量稳定入口，包括回到日常、查找和回到全图；具体放置仍需样张验证，不能只在鼠标靠近时出现。

图面有若干可读的领域名称和紧凑的认识组，不等大、不等距，不以“我”或 Axiom 为巨大的中心根节点。人的身份也不应该被画成中心权重。

当前回访的问题附近稍清晰，周围领域仍能辨认；第一次进入没有历史焦点时，给出平衡的全图，而不编造“你现在最重要的事”。AI 提出的新联系作为可忽略的具体提示出现，不占据强制中心。

远景只出现足够帮助认路的标题、少量小点和代表材料。不会把每篇文章的缩略图都铺出来。资料更多时，局部概括增加，不让画面无限变黑、文字无限变小，也不按数据量直接扩大领域的重要性。

### 22.3 不存在总览、语义、标签、结构、关系五个机器 Tab

用户面对的是内容，而非数据处理方式。查找、回访、查看变化和调整密度可以有直接入口；对象类型过滤、关系生成参数、内部聚类诊断不成为日常主导航。

用户可以直接问“之前那条被否定的想法在哪里”，也可以从名称进入，没有必须先选对模式的门槛。自然语言不是唯一入口，常用操作仍有可见控件。

## 23. 从远看走到细看

### 23.1 小点是远景符号，不是全部视觉语言

保留小点的轻巧，但在有阅读空间时，让它成为“点 + 可读的短语”，而不是要求每次 hover 才知道是什么。点的点击区域可以大于视觉尺寸；触控操作不要求精确戳中几像素。

继续靠近时，短语附近出现一小段原话、时间或图像。图片保持自身比例，文字不必包进矩形底板。不同表达共享一致的定位、题注和选中方式，不新增六种需要学习的节点玩法。

### 23.2 聚焦不是以我为圆心重新排一次

选择一个认识后，保留其周围的来路与重要地标，局部为可阅读内容腾出空间。中心问题未必要在几何中心，更不必画一个放大球体。

相关对象按实际意义形成小组：来源可以靠近主张，竞争解释可以并列，一条时间变化可以有方向。外围高价值联系仍可见，但不把所有次联系铺出来。不是每个问题都强行拥有相同的左右栏目。

只是读一条记录时，局部展开就结束；需要深入理解时，再进入 Axiom 编排的白板。直接搜索或历史回访可以跳到那里，不补走完整缩放过程。

### 23.3 关于 3D 的明确倾向

**当前优先设计可直接阅读的二维主图；不再把自由旋转的三维宇宙设为必经首页。** 这是新的设计推荐，不是实验结论，也不表示把旧图直接压平。

真正需要三维解释的对象，例如空间机制或有真实第三维的数据，可以在局部获得三维表达。为了建立层次而使用的轻微深度也可测试，但旋转、遮挡和飞行不能成为找到内容的成本。

认知空间的“广阔”应来自能持续发现新的关系，不来自镜头能飞多远。全三维候选若在目标任务中实际胜出，仍可重新选择；不为了理论一致而拒绝证据。

## 24. 联系、证据和 AI 的边界

### 24.1 线条必须能变成一句话

常态下只显现有助于定向的少量联系，选中对象再展开局部路径。优先用清楚的直段；需要避让时有限转折，不画随机曲线、全局流光或普遍渐变。

用户选中联系时，读到的是“这条观察让原先的解释需要补一个条件”“这份材料来自同一原始研究”“两者可能共享某种机制，尚未验证”，而不是 `supports: 0.83`。

不同关系不共享一个神奇距离尺：主题接近不等于因果，来源相同不等于相互支持，反驳材料在阅读上反而应靠近被反驳的主张。全图位置是可解释的编排，不是世界客观坐标。

### 24.2 人需要看到的是可判断的依据

**直接呈现或就近可达：** 当前主张、对当下问题的意义、关键依据、会改变判断的反证、尚未验证的条件、资料时间。并非每条记录都附一套审查面板；只有相关时才出现这些内容。

**中枢或 Foundry 处理：** 候选边、向量距离、聚类参数、检索重排、中间 Agent 交接和工程日志。来源原文并不属于“只给 AI 看”的工程材料，不能藏到维护环境。

视觉上明确区分“你曾说过”“Axiom 推测”“外部研究给出的结果”。不用每个对象堆一排徽章，但不能让漂亮的同一字体把三者混成同一种事实。颜色和亮度不足以承担这个区分。

### 24.3 主动发现有入口，也有拒绝权

AI 可以自主找到新联系、建议新问题，甚至提出原本议程中没有的机会。人看到的是具体的发现及边界，而不是“中枢正在思考”的表演。

地图不能成为只展示顺耳观点的推荐流。与判断有关的反例和意外关联应能进入，但不凭新奇抢占全图。用户可以选择暂不关注、纠正联系、继续研究；浏览不视为赞同。

## 25. 白板与 Atlas 怎么接在一起

**Atlas 帮人找到值得理解的事情及其位置；白板把这件事情展开到足以理解、比较和质疑。** 两者是不同的信息尺度，不是两套互不相干的模块。

白板不会打开一张空白纸等用户摆节点。Axiom 根据问题组织文字、图片、图表、时间关系和必要的模拟；用户可以说“只看反例”“把这两种解释放在一起”“去掉这个假设会怎样”。

这种编排有稳定语法：比较对象并列，过程有可追踪方向，证据贴近它所支持或限制的主张。不是每次生成一套新菜单，也不是把所有问题写成演示文稿。阅读可停、可跳、可回访。

一个假设场景：用户长期在想“为什么不断增加投入，事情却没有更快结束”。Atlas 中可见这条问题，以及自己留下的几段经历。Axiom 发现“并行数量与等待”可能提供一种解释，将它作为待检验联系提出。进入白板后，同时看到相关记录、模型条件和不适用情况，而非直接宣布某条规律已经解释了用户生活。改变一个条件，受影响的解释局部更新；原材料不被改写。

若研究最终否定这条联系，Atlas 留下简短、可追溯的修正痕迹，而不是悄悄删除失败。也不把白板上的所有临时图形永久塞回图谱。长期保留的是认识的变化与材料来路。

## 26. 让画面可以每天使用

### 26.1 中文排印

不再把“换成某个知名字体”当成完整设计。暂以足够清晰的现代黑体作为地图文字方向，重点是字面、实际笔画、字号层级、中西文混排和句子断行。文字不能通过无限缩小来解决冲突，阅读态也不随窗口宽度连续变小。

下一次样张必须覆盖短领域名、二十余字的问题、两段中文、数字、括号、英文术语和真实来源标题。地图识别文字与近距离正文分别设定尺度，原型可先试 15 至 17px 标签、17 至 19px 阅读正文，再按实际屏幕修正；这些是起始试值，不是已验证规范。

W3C《中文排版需求》涉及行首行尾禁则、标点和混排问题，可以作为排版检查依据；它不能替我们决定某个字体的艺术气质，也不意味着把书籍两端对齐等做法机械移到短 UI 标签。[W3C：中文排版需求](https://www.w3.org/TR/clreq/)

### 26.2 动态、稳定与回访

静止画面必须成立。普通节点无须持续呼吸，文字不漂浮；一次选择可以有短促、可中断的局部响应，关闭动态仍能理解。

AI 更新数据时，正在阅读的位置不移动。长期领域尽量保留地标，新的排列通过可辨认的变更进入，而不是每日换一张地图。退出白板后回到原位置、原选择；次日也能找到未命名的那次探索。

手机保留相同问题与材料身份，但局部阅读优先，领域定位随时可回；不把桌面整图缩到一块小画布里。所有关键操作均有触控与键盘路径，不依赖 hover。

### 26.3 不通过艺术感制造权威

Atlas 的构图必然引导注意力，所以必须让这种引导可被纠正。最亮不等于最真，位置大不等于人生重要，区域远不等于没有价值，空白不等于真正无知。

理想的结果是人更能自己选择看什么、能理解不同解释，而不是越来越依赖 Axiom 给出的唯一叙事。这同时是产品要求和审美要求。

## 27. 下一步如何验证这版提案

本轮已经完成定向资料与图像审读，仍未完成新界面样张、字体试排、交互原型或使用验证。研究推荐已有方向，但不能声称新 Atlas 已经好看或更好用。

下一步先做一个集中样本，不继续增加泛泛专题：使用同一组明确标记的演示内容，包含文字、真实来源图、重复来源、强联系、弱类比、反证和一条被撤回的认识。主候选采用本部分的开放图面；与紧凑页式基线做对照，三维只在可能有实际收益的定向任务中加测。

样本展示全图、局部阅读、联系依据、白板、返回五个状态，先把桌面和手机的真实尺寸构图做精细，再增加必要动态。检查内容稀少和内容很多时是否仍然成立，不只挑一个完美数据集截图。

验收分开记录，不合并成“高级感”总分：是否愿意多看、是否认得出刚才的位置、是否能读懂一条联系、是否分得清推测与证据、是否方便纠正、是否容易隔天回来，以及动画关闭后的质量。涉及身体、现实行动或重要决定的建议还需要独立的内容验证，视觉通过不能替代它。

**本轮收束：Atlas 不应只是漂亮的关系图，也不应只是被空间化的文章列表；它应让问题、材料和认识的联系共同形成一张可读、可探索、可纠正的图面。艺术感来自这种关系被精确组织后的整体，而不是额外叠上的气氛。**

## 28. 首个交互样本（2026-09-06）

用户确认“做来看看”后，先做独立入口，不替换现行产品。样本位于 [AtlasStudy.vue](../frontend/src/atlas-study/AtlasStudy.vue)，可从地图中的“开始得更多，为何完成得更少？”进入局部阅读，再展开为一份可调条件的解释白板。

### 28.1 这次实际做了什么

- 深色开放图面，用不同分量的中文、少量小点、直线关系和一张真实来源图组织四组内容；不依赖持续发光、随机漂移或大球体来制造活力。
- 聚焦时区分当前内容、一跳联系和二跳语境；详情就近显示关系的自然语言主张、来源与限制，不展示向量距离或中枢调试参数。
- 白板不是空白编辑器。它已围绕具体问题编排模型、可调条件、反例与经历；返回保留地图平移/缩放与本次模型条件。
- 演示含 20 个片段、22 条联系。记录明确为虚构演示；MIT 的 Little 定律说明与 NASA/USGS 影像是外部材料。减少在途数量是否改善个人结果仍是待检验迁移，不包装成研究已经证明的建议。
- 手机采用按领域展开的局部阅读，不照搬桌面的整幅图。查找、最近看过、异议和留待验证都可操作；这些状态只保存在 `axiom.atlas-study.v1` 本地命名空间。

### 28.2 运行与检查

在 `frontend/` 中执行：

```powershell
npm run dev -- --host 127.0.0.1 --port 4317 --strictPort
# 打开 http://127.0.0.1:4317/atlas-study.html
npm run test:atlas-study
npm run build:atlas-study
```

浏览器回归：Playwright MCP 可加载 [atlas-study.browser.js](../frontend/tests/atlas-study.browser.js)；命令行可执行 `npm run test:atlas-study:browser`。后者默认使用本机 Chrome 与可解析的 `playwright`，也可将环境变量 `PLAYWRIGHT_MODULE` 指向已有 Playwright 的 `index.mjs`，无需修改应用依赖。`ATLAS_STUDY_URL` 可覆盖测试入口；`PLAYWRIGHT_CHANNEL` 可覆盖浏览器通道。

独立构建产物在 `frontend/dist/atlas-study/`，不会覆盖现行 Flask 使用的 `core/static/v2/`。这份样本不调用 Axiom API、不读取个人资料、不部署到服务器。外部影像联网加载，失败时退化为材料题名，原始来源仍可从详情打开。

### 28.3 已验证与仍待验证

已通过数据身份/关系端点与模型计算等 4 项单元测试、Vue 类型检查、独立构建，并在桌面与手机实际查看图面和白板截图。浏览器回归覆盖四种宽度的节点边界/横向溢出、查找和键盘、局部阅读、条件改变、判断持久化、回访和错误状态恢复。

这只是经过人工编排的单一样本，不是动态布局算法、自动生成白板或发现中枢的验收。还需用户判断整体观感，测试密集资料、重复来源呈现、长期回访、手机跨领域比较与紧凑页式对照；窄桌面下的全图文字尺度也需继续按实际阅读反馈调整。保留本研究先前正文，不因原型已经运行而把这些未验证项写成既定结论。

### 28.4 用户校正：三维是全貌，二维是阅读

用户反馈首版“还行，但只能作为 2D”，进一步明确三维的目的：形成总览感，先说明“有什么”，用节点关系作为排布依据，让人宏观感知整体规律，并给产品带来高级感；不需要在三维中塞入大量概念。

**本次反馈修正前文的“二维作为默认主图”推荐。后续不再用二维阅读能力取代三维总览。** 保留先前正文作为研究过程，而非继续执行的默认优先级。三层分工改为：

- 三维：先看内容的分布、聚散、主要连接与相对独立的部分。领域名是定位标识，不把解释段落和关系证据铺满空间。
- 二维：进入感兴趣的区域或内容，读具体问题、材料和联系依据；保留已经得到认可的阅读样本。
- 白板：围绕问题进一步解释、比较、调整条件与质疑，不替人创建一张需要维护的空白画布。

高级感的目标放在整体构形、点线精度、前后层次与受控运动中，不靠巨大球体、星空背景或伪造数据量。三维不是二维图面的倾斜贴片，也不必强制做成规则球壳。图面中的密集不等于重要，连接不等于赞同，布局中出现的结构也不自动构成科学规律。

### 28.5 三维样本实现与边界

独立入口 `/atlas-study.html` 现在默认打开三维；`?view=map` 可直接进入原二维，带 `focus` 的地址仍定位具体内容。领域和节点沿同一身份进入二维，返回保留观察方向。

布局使用 [d3-force-3d 的三维仿真](https://github.com/vasturiano/d3-force-3d)，只由当前联系与点间避让计算位置，不使用人工二维坐标或领域中心作为空间约束。现有数据没有经过标定的关系强度，所以当前采用等权连接；没有把 `context / hypothesis / limit` 偷换成强弱或可信度。领域名称仍来自演示分组，本轮没有宣称 AI 已完成自动社区发现。

三维呈现使用 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)，初次进入短暂转动，交互后稳定停留。采用 [按需渲染](https://threejs.org/manual/en/rendering-on-demand.html)；二维/白板打开、页面隐藏与减少动态偏好都有停止或抑制动画的处理。不新增装饰性假节点，不使用无依据的连线填补空白。

验证命令新增 `npm run test:atlas-study:spatial`，Playwright 配置沿用 28.2。三维回归在 `1440 / 390 / 320` 宽度下隐藏所有 DOM 标签后单独检查画布像素，确认主体非空、取景边界与旋转后的像素变化；同时验证拖拽、标签避让、节点/领域跳转、视角保留、静止节能和 GPU 失败时的二维退路。5 项单元测试另行检查非共面、关联距离与原数据不被仿真改写。二维与白板回归仍然保留。

**仍待验证：** 当前 20 个片段仅能示范分工与基本结构，不能代表大量内容形成的点群密度、宏观规律或最终高级感。下一轮需要更完整且有依据的演示集合，验证聚合层次、稠密关系可读性、自动分组和长期稳定性；不以重复假点替代内容规模，也不把本次空间坐标当作客观知识度量。
