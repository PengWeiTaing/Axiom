# Axiom 全前端美学研究：夜行长卷

更新时间：2026-09-05

> 状态：下一代产品形态、注意力伦理和视觉约束基线；具体艺术风格仍处于探索阶段，不是已批准的最终设计。
>
> 2026-09-05 交接说明：第一张按“夜行长卷”生成的暗色界面概念图已被用户明确否决，图片未进入仓库，不得作为实现参考。被保留的是本文对人和中枢的分工、空间连续性、认识论诚实、低摩擦、Atlas 与白板职责等研究结论；“夜行长卷”可以继续作为研究代号，但其构图、材质、字体、图谱形态和总体观感都允许重新推翻。

## 0. 结论先行

Axiom 的前端不应继续被理解成一组拥有统一主题的页面。它应是一种持续的认知媒介：人在其中恢复此刻、看见变化、进入问题、理解 Axiom 的发现，并在必要时检查证据。

下一代审美主线暂定为：

```text
夜行长卷
```

“夜行”不是黑色主题，而是低刺激环境中注意从边缘进入中心的过程；“长卷”不是水墨装饰，而是连续游观、局部显影、尺度变化和时间展开的空间逻辑。

它由五种传统共同构成：

1. 中国手卷的连续旅程、移动视点和留白。
2. Warburg《记忆女神图集》在黑色场域上的关系蒙太奇。
3. James Turrell 把光作为注意与知觉材料的方式。
4. Ryoji Ikeda 把不可见数据转为尺度、节奏与精度的方式。
5. Bret Victor 将文字、图像、变量和系统行为联结成可理解媒介的方式。

这不是上述作品的视觉拼贴。Axiom 要吸收它们背后的组织规律，形成自己的产品人格：

```text
安静，但不空洞；
精密，但不冷酷；
深邃，但不神秘化；
有生命，但不持续表演；
艺术化，但不制造视觉权威。
```

## 1. 为什么必须重构整个前端

### 1.1 当前版本不是失败，而是旧目标的完成形

当前前端已经解决了早期问题：

- 从浅色活页转为原生暗色。
- 把十三个工作台降级到“索引”。
- 建立“此刻 / 资料库 / Atlas / 记录”的主要节奏。
- 减少圆角卡片、玻璃拟态和霓虹装饰。
- 提高标题字重，并建立统一石墨色板。

但它仍然以“功能页面”为基本单位。固定顶栏、章节编号、英文眉题、矩形内容舞台、右侧抽屉和列表索引只是被重新排版，没有被新的认知模型取代。

### 1.2 2026-08-31 实页审计

本轮在 `1440 x 900` 桌面和 `390 x 844` 移动视口查看了实际 Vite 页面。

观察到：

- “此刻”仍由一个巨大矩形焦点区和多个传统页面章节组成，像精心排版的仪表页，而不是正在发生的认知场。
- “资料库”用巨型搜索框承担视觉中心，空状态仍像组件示例。
- “索引”虽然隐藏了旧模块，却仍把待整理、行动、记忆、决定、时间、回顾、结构校准、自动化和系统状态并列展示给人。
- Atlas 仍有“总览 / 语义 / 标签 / 结构 / 关系”机器分类 Tab，并以 Axiom 根节点作为中心。
- 移动端只是把同一骨架压缩到窄屏，尚未形成适合碎片时间、单手观看和渐进展开的独立叙事。
- 视觉语言依赖大量细线、低对比小字、编号和英文标签，容易显得像“设计系统作品”，而不是人的长期外脑。

代码也反映了同一问题：`frontend/src/` 当前约有 39 个 Vue 文件、26197 行源码和 40 个局部样式块；`AtlasView.vue`、`TodayView.vue`、`ObjectDrawer.vue` 等单文件达到一千至近三千行。页面形态、业务状态与视觉细节彼此缠绕，使整体审美只能通过局部补丁演化。

结论：继续改颜色、字号和卡片样式不会抵达新产品。需要从页面组织、注意路径、信息显影方式和空间连续性同时重构。

## 2. 美学首先是一种认识论治理

界面会改变人相信什么。

- 更亮的对象会显得更重要。
- 更大的对象会显得更确定。
- 位于中心的解释会显得更接近真相。
- 平滑的动画会掩盖模型重构中的断裂。
- 过度精密的图形会让候选推断看起来像测量事实。

因此 Axiom 的美感不能只追求“沉浸”或“高级”。每个视觉决定都要回答：

1. 它在引导注意，还是劫持注意？
2. 它在帮助区分事实、推断和未知，还是把它们统一美化？
3. 它在保留人的判断空间，还是把 Axiom 的叙事包装成结论？
4. 它是否让来源、反证和边界在需要时能够出现？

美学目标不是让 Axiom 显得无所不知，而是让复杂认识变得可感、可读、可质疑。

## 3. 参考谱系及其真正启示

### 3.1 中国手卷：连续游观，而非页面跳转

手卷不是同时铺开的全景。观看者沿卷逐段展开，在真实时间中经过远近、密疏、停顿和转折。画面可以使用移动视点，不必把所有对象压入单一透视中心。

对 Axiom 的启示：

- 日常、Atlas 聚焦和白板不应像三个互不相关的路由。
- 用户应沿当前对象连续下潜，保留来处、尺度和时间感。
- 留白不是空状态，而是尚未进入注意或尚无充分认识的空间。
- 一个视口不承担全部信息，只承担当前认知段落，并让下一段留下可感知的线索。
- 移动端不是桌面缩小版，而是一次只展开长卷的一段。

需要拒绝：水墨纹理、山峰剪影、仿古题跋等表面挪用。

### 3.2 Warburg《记忆女神图集》：关系来自编排

Warburg 在大型黑色面板上编排来自不同时代与媒介的图像。最终系列约含 971 幅图像，多个版本使用近似素材却通过不同顺序和构图形成不同解释。

对 Axiom 白板的启示：

- 白板是 Axiom 的认知编排面，不是用户从空白开始作图的工具。
- 相邻、间隔、尺度和序列可以形成解释，但必须区分“编排提出的关系”和“已证实的关系”。
- 同一材料可以被 Axiom 生成多个竞争构图，帮助人比较解释。
- 黑色场域适合让异质材料共存，但不能退化为图片墙和卡片瀑布流。
- 白板应像一次有观点、可审理的展陈，而不是机器把检索结果倾倒出来。

需要拒绝：把绳线侦探板、素材拼贴和复古档案感当成产品身份。

### 3.3 Agnes Martin：秩序中保留人的微差

Martin 的网格看似规则，却通过手工细微波动抵抗机械僵硬。

对 Axiom 的启示：

- 网格用于建立安静节奏，不用于把所有内容对齐成企业后台。
- 分隔、刻度和基线允许极轻微的视觉差异，让界面不显得由模板批量生成。
- 重复元素应有共享秩序，但不必拥有完全相同的容器和尺寸。

需要拒绝：把低对比细线铺满每个页面，造成“精致但看不清”。

### 3.4 James Turrell：光是注意，不是装饰

Turrell 的作品把光作为影响知觉的材料，并使观看者意识到自己正在观看。

对 Axiom 的启示：

- 光只出现在当前注意、真实变化和可操作边界上。
- 环境本身保持暗而有层次，焦点通过局部明度关系显影。
- halo 不能等同于真实性或置信度，只表达当前关注、变化或活动。
- 从边缘提示到中心发现，应像视觉逐渐适应暗室，而不是弹窗抢夺注意。

需要拒绝：渐变光斑、发光球、霓虹描边和全局柔焦。

### 3.5 Ryoji Ikeda：数据具有尺度与节奏

Ikeda 的 datamatics 让不可见数据成为高精度、跨尺度的视觉与声音体验。

对 Axiom 的启示：

- 数据不是统计卡片，而可成为时间、密度、节奏、分布和变化本身。
- Atlas 可以在宏观地形与微观证据之间连续变焦。
- Foundry 可以采用更高密度、更精密的仪器语言，与日常环境形成明确差异。
- 细小数据符号只有在整体节奏中承担真实信息时才成立。

需要拒绝：高频闪烁、二进制雨、全屏扫描线和“数据洪流”表演。

### 3.6 Giorgia Lupi：数据不是事实的同义词

Data Humanism 强调数据是人类经验的不完整抽象，包含主观性、偏差、含混和定性语境。

对 Axiom 的启示：

- 个人数据必须保留时间、来源、例外和人的语言。
- 图表旁要能容纳质性解释，而不是只给精确数字。
- 缺失、未知和数据生成方式都是信息，不是需要隐藏的瑕疵。
- 可视化可以具有个人痕迹，但不要求用户亲自绘制。

### 3.7 Bret Victor：媒介应让系统行为可见

Victor 主张文字、图像和行为紧密联结，同一系统通过多种同步表示帮助人形成直觉，而不是要求人在脑中模拟变化。

对 Axiom 的启示：

- 白板应把因果、概率、时间和情景变成可观察行为，而不只是静态关系线。
- 同一对象在文字、图表、时间线和 Atlas 中应可联动高亮。
- Axiom 选择表示方式的标准是“哪种最能让人理解当前机制”，不是“哪种组件已经存在”。
- 人可以调整时间尺度、问题边界或假设，看见所有相关表示如何共同变化。

### 3.8 Outer Wilds：以好奇心组织线索

Mobius Digital 通过测试发现，信息组织会直接影响玩家如何理解故事；Ship Computer 改为更视觉化的线索引导，同时也发现信息过度集中会使玩家难以消化。

对 Axiom 的启示：

- Atlas 与白板要帮助人知道“下一处值得看什么”，而不把探索变成任务清单。
- 信息显影需要节奏与停顿，不能一次交付所有推理。
- 视觉线索必须来自内容和世界本身，不依赖说明文案教用户使用系统。

需要拒绝：复制侦探板绳线、太空电脑材质和游戏化任务提示。

### 3.9 Obsidian：点线关系的直接性

Obsidian 的 Graph View 用圆点、直线、hover 邻域和局部深度表达关系，用户可以控制节点、连线和力导向参数。

对 Axiom 的启示：

- 普通节点保持点状，线保持直接，不为“艺术感”任意弯曲。
- 聚焦时强调有限邻域，其余退入背景。
- 全局和局部承担不同任务。

需要拒绝：把 Atlas 降回笔记链接图、把参数面板暴露给日常用户、依靠力导向随机布局表达认识。

### 3.10 OpenAI Sans：精密与人文温度的平衡

OpenAI 官方将 OpenAI Sans 描述为兼具几何精度、功能性、柔和曲线和可接近感的字体，并提供从 Light 到 Bold 的完整字重。

Axiom 需要借鉴的是：

- 以稳定、足量的字重建立信任，不用细字制造昂贵感。
- 几何骨架和柔和曲线共存。
- 正文、数字、标点和多语言在同一节奏中工作。

项目不能仅在 CSS 中写下不存在的 `OpenAI Sans SC`，也不能在没有合法授权时复制品牌字体。下一阶段应完成真实的中英文字体配对实验；OpenAI Sans 作为性格参照，候选字体必须在实际中文界面中比较字面大小、笔画密度、标点位置和多字重表现。

## 4. Axiom 的独立审美：夜行长卷

### 4.1 不是一种主题，而是一种观看运动

用户进入 Axiom 后经历：

```text
恢复方向
  → 看见一处变化
  → 沿变化进入关系地形
  → 让 Axiom 在更大载体上展开解释
  → 检查证据与边界
  → 带着一个新判断返回生活
```

每次空间变化都服务这条认识运动。全局壳不再像网站导航，页面也不再像模块切换。

### 4.2 情绪曲线

- 进入：安定，迅速恢复上下文。
- 发现：轻微异样，让人愿意靠近。
- 下潜：空间展开，复杂度逐步增加。
- 审理：画面稳定，证据清晰，装饰退场。
- 返回：只留下变化后的方向，不制造“还有很多没处理”的欠债感。

### 4.3 视觉重心

一个视口最多拥有一个主要重心、两到五个次要锚点和一层边缘信息。

禁止：

- 每块内容都有边框和标题。
- 所有数据并列争夺首屏。
- 一个巨大口号占满视口却不提供继续前进的线索。
- 空状态用假内容、说明卡或装饰图填满。

### 4.4 留白

留白有四种含义：

- 注意尚未抵达。
- 认识尚未形成。
- 两种结构之间存在真实距离。
- 系统主动为人保留消化时间。

留白不能只是固定大边距，也不能让主体漂在屏幕角落。它必须与内容密度和观看方向共同构图。

## 5. 两个环境必须拥有不同人格

### 5.1 日常环境：人的夜间书房

日常环境面向生活，不展示系统能力。

视觉特点：

- 温暖但中性的暗场。
- 内容比控件先出现。
- 重要文字具有足够尺寸和重量。
- 当前问题、近期痕迹和边缘回响自然相接。
- 记录入口随时可达，但不成为永远发亮的中心按钮。
- 导航退化为少量稳定地标，通常不占据完整顶部横栏。

### 5.2 Foundry：中枢的仪器室

Foundry 面向工程维护、评估和认知生产治理。

视觉特点：

- 更冷、更密、更精确。
- 使用真实表格、时间序列、差异、谱系和日志。
- 允许工具栏、筛选和分栏，但不伪装成日常界面。
- 明确显示模型版本、来源、失败、回滚点和实验状态。
- 与日常环境使用相关但不同的字体、色温和网格密度。

Foundry 不能藏在“索引”底部。它应是独立入口、独立路由空间，必要时甚至是独立窗口。

## 6. 全局空间架构

### 6.1 取消永久网站顶栏

当前固定顶栏强化了“几个页面平级切换”的感受。下一代桌面端改为三类稳定地标：

- 左上或边缘的 Axiom 返回锚点。
- 当前空间名称与来路。
- 记录、找回和进入 Atlas 的上下文动作。

这些地标可以在静止时退入边缘，在指针靠近、键盘调用或上下文需要时显影。

### 6.2 取消十三项索引

行动、记忆、决定、时间、回顾和待整理不再作为用户选择的页面。它们由当前对象和当前问题自然投影：

- 需要承担后果时出现行动。
- 需要恢复过往时出现记忆。
- 需要比较路径时出现决定。
- 需要理解变化时出现时间。
- 需要修正模型时出现回顾。

结构校准、自动化和系统状态迁入 Foundry。

### 6.3 记录不是中央品牌按钮

记录应像随时可唤出的空白行、边缘缝隙或系统级快捷动作。它优先接住内容，不要求用户进入模态表单完成一套流程。

### 6.4 空间连续

- 从“此刻”进入记录：当前语境不消失，只向一侧让出表达面。
- 从“此刻”进入资料库：当前问题成为默认检索上下文。
- 从“此刻”进入 Atlas：相关地标从背景显影并扩展成地形。
- 从 Atlas 进入聚焦：对象身份和相邻地标保持连续。
- 从 Atlas 或发现邀请进入白板：同一对象成为展示构图的起点，而不是打开空画布。

## 7. 核心页面的产品形态与美学

### 7.1 私有入口

入口不是封面加登录卡，也不需要宣告 `PRIVATE EDITION / PERSONAL CORTEX`。

目标形态：

- 一个安静、可信的识别面。
- Axiom 名称、当前连接状态和唯一访问动作。
- 成功后像门缝打开，原地进入最近语境。
- 错误说明具体发生了什么，不用技术编号装饰。

### 7.2 此刻

“此刻”不是日程仪表盘，而是一段由时间和注意组织的场景。

首屏可能同时包含：

- 当前正在延续的一件事。
- 一处值得注意的变化。
- 一条可以放心不管的信息。
- 最近留下的半句话或材料痕迹。

它们不必进入统一矩形。主焦点可以是一段有重量的文字、一条正在发生的轨迹或一组彼此靠近的材料。页面随着真实内容变化构图，但保留稳定阅读方向。

### 7.3 流入与记录

记录面是一段暂时打开的表达空间：

- 默认只有光标和当前时间语境。
- 文本、图片、文件、语音和链接可以直接进入。
- Axiom 的解析和分类在保存后发生，不在输入前要求决定。
- 保存成功后表达面自然收回，只留下可找回痕迹。

### 7.4 资料库

资料库不是巨型搜索框加结果列表，而是一座可沿线索生长的档案空间。

- 没有查询时，展示最近进入、最近重新获得意义和长期未触及但与当前有关的材料。
- 输入查询后，结果不是统一行项目；正文片段、图像、文件、旧判断和相关时间可以采用不同但协调的展示尺度。
- 精确匹配、语义邻近和 Axiom 推断必须可区分。
- 选中结果时，来源在原位置展开，不把用户送入通用抽屉。

### 7.5 对象与证据页

对象页不是所有类型共享的一张表单。

- 记录以原文与来源为中心。
- 主张以支持、反证、竞争解释和边界为中心。
- 决定以当时信息、未选路径和结果为中心。
- 规律以机制、跨域映射、失效条件和迁移史为中心。
- 机会以情景、个人适配、窗口和可逆试探为中心。

页面共享排版和来源语法，不共享僵硬字段布局。

### 7.6 Atlas 全局

Atlas 是夜行长卷中空间最深的一段。

- 3D 只用于整体方向、遮挡关系、远近和区域变化，不用于炫技。
- 没有中心 Axiom 根节点，也没有“总览 / 语义 / 标签 / 结构 / 关系”Tab。
- 地域、地标、桥梁、张力和前沿通过形态与空间组织出现。
- 普通对象是微小点标；重要性不单靠尺寸和光亮表示。
- 线条直接、克制，并以命题而非数据库 relation type 获得意义。
- 用户不调力导向参数，不管理图谱显示设置。

### 7.7 Atlas 聚焦

聚焦不是固定局部图。Axiom 根据对象和问题选择平面：

- 问题：竞争假说与区分证据。
- 主张：支持、反证和适用边界。
- 规律：机制、映射与失效条件。
- 事件：时间、因果和转折。
- 机会：情景、概率与个人优势。

从 3D 到 2D 的运动必须保持对象身份和方向参照；必要时使用分阶段动画帮助感知结构变化，而不是整页淡出。

### 7.8 白板：Axiom 的认知展演面

白板不是用户创作工具。它是 Axiom 围绕一个问题主动编排信息的更大、更自由载体。

白板可以同时容纳：

- 原始材料和关键摘录。
- 因果机制与反馈回路。
- 时间线与结构转折。
- 公式、概率和敏感性。
- 图像、声音、地图与人物关系。
- 支持证据、反证和竞争解释。
- 跨领域映射、边界与反例。
- 情景、预测和机会窗口。

Axiom 决定构图，人不负责拖动节点完成整理。人的动作是追问、质疑、改变尺度、比较解释、显示反证、纠正个人语境和固定值得追踪的发现。

白板视觉更接近一场可操作的研究展陈：材料可以裸露存在，图、文、数字和媒体不必装进同尺寸卡片；画面可随追问重新编排，但原始来源和已确认事实保持可追踪。

### 7.9 移动端

移动端不是桌面功能压缩，而是日常伴随面：

- 捕获。
- 恢复当前方向。
- 接收一条真正值得注意的发现邀请。
- 查看白板或 Atlas 的导览版本。
- 对主张作确认、质疑或稍后处理。

完整 Atlas 旋转、复杂白板全景和 Foundry 仪器不应硬塞进手机。手机用段落式镜头、局部导航和连续缩放呈现同一内容。

## 8. 排版研究

### 8.1 字体人格

Axiom 的字体需要：

- 比当前 Inter + Noto Sans SC 更有字面分量。
- 中文与拉丁字母拥有接近的视觉高度和重心。
- Regular 也能在暗场上稳定，不依赖 Semibold 修补可读性。
- Bold 能承担地标，而不显得像营销标题。
- 数字和公式清晰，但不把所有元数据变成等宽代码风。

下一阶段字体实验至少比较三组合法可部署方案，并在中文长标题、正文、数字、英文术语和混排标点中实测。不得继续依赖不存在的字体家族名。

### 8.2 层级

- 主标题具有重量，但只在真正的空间入口出现。
- 页面内部不使用巨大 Hero 字号。
- 正文以舒适阅读为准，不以灰和小制造层级。
- 眉题只在确有语境作用时出现，不用 `01 / NOW`、全大写英文和装饰编号占据注意。
- 元数据可以较小，但关键来源、时间和认识状态必须可读。
- 字距恒为零。

### 8.3 中文优先

英文只保留不可替代的名称、模型或引用。界面人格不能依赖英文术语、斜杠和编号制造“研究机构感”。

## 9. 色彩与材料

### 9.1 暗场

当前底色偏绿黑，容易联想到终端、军用设备或生物科技。下一代使用更中性的碳黑和墨蓝黑，通过材质与局部色温建立层次。

建议研究区间，不是最终 token：

- 深层环境：`#090A0B` 到 `#0D0F12`。
- 阅读表面：`#121417` 到 `#181B1F`。
- 温白正文：`#E9E7E1` 到 `#F4F1E9`。
- 次级文字：保持可读，不低于实际验收对比度。

### 9.2 矿物色不是主题色

使用多源但低占比的颜色，避免单一绿色或紫蓝控制整套界面：

- 朱砂：人的意图、现实承诺、警觉。
- 石青：空间、远端关系、可探索入口。
- 铜绿：连续性、恢复、生命信号。
- 黄铜：时间、预测、边界条件。
- 灰紫：张力、竞争解释、未决判断。

颜色必须同时配合文字、形态或纹理，不能独立承载状态。

### 9.3 材料

- 背景可以有极轻的颗粒、纸纤维或扫描噪声，但必须使用真实位图纹理或程序噪声，不做渐变光球。
- 前景通过明度、锐度、遮挡和局部边缘形成，不堆阴影卡片。
- 媒体保持原始质感；来源图像不统一套暗色滤镜。
- 线条具有不同认识角色，但不模拟手绘抖动制造假人味。

## 10. 动效：只让认识变化运动

动效分四类：

### 10.1 连续动效

保持对象从此刻、Atlas、聚焦到白板的身份连续。它帮助人理解“我还在看同一件事”。

### 10.2 证据动效

表现新证据进入、旧主张降级、竞争解释增强或预测兑现。运动必须有来源和结果。

### 10.3 注意动效

边缘信息只在与当前语境相关时轻微显影。它不持续呼吸，不循环发光。

### 10.4 行为动效

在白板中展示因果传播、时间演化、概率敏感性和情景分叉。此类动效应可暂停、重播、改变尺度。

通用页面切换只使用极短显隐。大范围空间移动必须提供稳定参照。`prefers-reduced-motion` 下改为分阶段静态状态，不丢失任何信息。

研究表明，设计得当的动画转换可以改善图形理解，但动态关系图的“所有位置尽量不变”并非普遍有效。Axiom 应根据任务保护对象身份、地标与来路，而不是冻结整张图。

## 11. 不确定性与视觉诚实

### 11.1 不用亮度表示真理

亮度优先表示当前注意和可操作性。认识状态通过组合语言表达：

- 事实：稳定边界与来源。
- 推断：开放轮廓或未闭合结构。
- 争议：并置的竞争解释。
- 未知：明确空白、问号位置或缺失说明。
- 已反驳：保留历史但退出主叙事。

### 11.2 不展示伪精度

默认不把模型置信度显示为小数。需要量化时同时显示：

- 数字代表什么。
- 来源和样本。
- 对结论敏感的变量。
- 哪种变化会使判断翻转。

研究显示，不确定性视觉会影响人的信任与决定，而且更多提示不一定带来更好的行为校准。Axiom 应针对具体判断任务测试表示，而不是叠加透明度、颜色、措辞和百分比制造“透明感”。

## 12. 组件不再主导页面

可以保留的基础元素：

- 裸文字。
- 图像、音视频和文档片段。
- 细线、轴、刻度和区域。
- 点标、地标和来源标记。
- 图表、时间线、因果图和情景结构。
- 图标按钮、菜单、分段控制和必要表单。

卡片仅用于真正独立、可重复的对象或确认边界。禁止：

- 页面章节全部浮成卡片。
- 卡片嵌套卡片。
- 所有对象共享同一矩形模板。
- 用圆角、阴影和渐变替代构图。
- 通过组件数量证明系统能力。

## 13. 可访问性不是后期修补

- 正文和背景满足 WCAG 2.2 AA 的实际对比度要求。
- 颜色之外必须有第二种状态线索。
- 所有核心动作支持键盘和明确焦点。
- 文字在桌面和移动视口不截断、不重叠。
- 动效不是唯一信息来源，并支持系统减少动态偏好。
- Atlas 和白板必须提供可阅读的线性替代结构，让屏幕阅读器和不适合空间导航的用户仍能理解内容。
- 高密度 Foundry 允许提高对比、放大字体和关闭环境纹理。

## 14. 第一组真实验收场景

### 14.1 恢复此刻

离开两个月后打开 Axiom，五秒内理解：上次停在哪里、现在什么改变了、什么可以暂时不管。

### 14.2 低摩擦捕获

在手机上记录一段含混想法，不选择类型、不填写标题，保存后立即回到原语境。

### 14.3 发现邀请

Axiom 发现一个跨域规律，只在边缘形成可忽略提示；用户靠近后才看到为什么值得注意。

### 14.4 Atlas 定向

用户能说出当前主要认识领域、最近形成的桥梁、仍未解决的张力和一个前沿，而不需要理解图谱类型。

### 14.5 白板展演

围绕“量变如何产生质变”，Axiom 在一张动态展演面上联结渗流、网络效应、习惯形成与产品扩散，同时呈现公式、证据、反例、边界和与用户处境的关系；用户无需手工排版。

### 14.6 质疑 Axiom

用户要求“显示最强反证”和“换一个机制解释”，白板原地重组，且清楚保留旧解释、来源和变化。

### 14.7 Foundry 审计

工程环境能追踪这次发现使用的模型、检索、候选、被拒关系、反馈和后续预测表现，而这些内容不泄漏到日常界面。

## 15. 失败标准

出现以下任一情况，下一代前端方向即失败：

- 只是把现有页面做得更暗、更大或更有动画。
- 仍以固定导航和模块列表解释 Axiom。
- 白板仍要求用户创建、摆放和整理信息。
- Atlas 仍从数据库对象和 relation type 出发。
- 视觉像通用 AI 产品：紫蓝渐变、玻璃、光球、漂浮卡片、无意义粒子。
- 视觉像时尚杂志：大标题和留白漂亮，但信息贫乏。
- 视觉像工程仪表盘：精确而密集，却不帮助人形成判断。
- 重要性、可信度和当前注意共用同一套亮度或尺寸语言。
- 移动端只能浏览缩小后的桌面。
- Foundry 和日常界面重新混在一个索引中。

## 16. 研发顺序

1. 先以三个真实问题建立无代码或低代码视觉场景，验证注意路径和审美人格。
2. 第一条完整体验只做“此刻 → Atlas → 白板 → 质疑 → 返回”。
3. 在这条体验中建立字体、暗场、信息层次、关系线、动效和来源语法。
4. 通过真实内容测试后，再迁移资料库、记录和对象页。
5. 日常环境稳定后，独立设计 Foundry。
6. 旧页面只维持必要兼容，不在旧骨架上继续扩展视觉功能。
