# Axiom 前端艺术方向：夜间认知场

更新时间：2026-08-27

这份文档定义 Axiom 的产品感知、排版分量与交互秩序。它不是一套可替换主题，也不是把旧页面反转成深色。

## 核心判断

```text
Axiom 不是装着功能的后台。
Axiom 是一张始终打开、能接住注意力的私人认知场。
```

旧版“活页”建立了连续阅读和边注秩序，但浅色纸面、纤细字体与大面积留白让界面显得小气，也让暗色 Atlas 像另一个产品。把纸白机械反转为黑色仍然保留旧骨架，同样不能成立。

新方向从暗环境原生设计：石墨黑承担安静背景，近白文字形成稳定重心，少量矿物色只在真实状态发生时出现。空间不是由卡片和阴影堆出，而由亮度、距离、分隔与内容密度形成。

## 低摩擦原则

### 打开即进入当前问题

默认落在“此刻”。首屏只保留一个当前焦点、一个完成动作，并露出下一层可选行动。用户不先选择任务、记忆或决定工作台。

### 输入先被接住

全局记录是一张直接获得焦点的暗色写作面。文字、链接与文件先进入外脑，分类和理解随后发生。

### 找回先于筛选

资料库首先是一条宽阔搜索面。短查询形成后自动找回，精确与相近含义只是轻量模式；复杂条件默认收起。

### 结果留在当前语境

记录与认知对象在右侧暗色上下文页展开，用户关闭后回到原位置。Atlas 从全局 3D 原地收束成 2D 局部语境。

### 次级能力只在需要时出现

行动、记忆、决定、时间、回顾与待整理属于索引，不是平级工作台。结构、自动化和系统状态进一步降级为治理层。火山杯 Learning Board 与 MemoryGuard 维持独立项目边界；未来 Axiom 白板从当前问题按需展开，不成为一级入口，也不继承竞赛白板的视觉与产品本体。

## 视觉语法

### 原生暗色

- 主底色是近黑石墨，不使用纯黑，也不沿用浅色纸张的色值关系。
- 主内容面通过极小明度差分层，不依赖浮卡、阴影墙或玻璃拟态。
- 大区块是连续台面，内容以分隔线、列宽和留白组织。
- 顶部导航像仪器刻度，始终安静；当前章节只用一条明确基线确认。
- 背景只保留静态纤维、校准线和极淡结构弧，不出现渐变光斑、装饰圆球或持续动画。

### 色彩角色

- 石墨黑：环境与深度。
- 温白：当前内容和主要文字。
- 朱红：意图、记录入口、期限和正在发生的动作。
- 苔绿：连续性、确认与完成。
- 钴蓝：找回、空间与远端关系。
- 灰紫与黄铜：判断、张力和少量辅助信号。

颜色不能替代层级，也不能为了“高级感”扩大面积。

### 字体与分量

- 拉丁字母、数字和界面标签使用自托管 `Inter Variable`；简体中文使用 `Noto Sans SC Variable`。
- 字体栈保留 `OpenAI Sans` 名称作为用户本机合法安装时的优先项，但项目不复制或冒充 OpenAI 品牌字体。
- 正文以 `15px`、约 `450` 字重为基准；主要标题使用 `560` 到 `650`，不再依赖细字与过量空白制造精致感。
- 可见界面文字原则上不低于 `11px`。极密图谱标签也必须在实际设备上可读。
- 字距恒为零。层级依靠字号、字重、行高和位置建立，不使用稀疏全大写标题装饰页面。

### 信息密度

- 首屏必须同时给出当前重心和继续前进的线索，不能被一个巨大舞台完全占满。
- 数据概览是连续刻度带，不是统计卡片阵列。
- 列表是可扫描的连续索引，hover 只改变局部明度或侧边状态线。
- 空页面依然保留结构和下一动作，不用卡片填满空间。

### 动效

- 页面切换只使用短距离位移和显隐。
- 常态界面不持续呼吸、漂浮、发光或播放粒子。
- 记录面、索引和上下文页的进入动作必须快速、可预测。
- Atlas 只激活焦点区域的 halo 与轻微能量变化；全图节点和关系不同时动画。
- `prefers-reduced-motion` 下移除全部非必要运动。

## 核心产品空间

### 全局壳

桌面只有“此刻 / 资料库 / 记录 / Atlas”构成主要节奏，找回与索引停留在右侧工具区。移动端保留同样的五个拇指可达动作。对象类型永远不回到一级导航。

### 此刻

“此刻”是一块被局部照亮的行动台面：当前焦点占据主体，右侧只保留完成动作；台面高度必须让下一层行动在常见首屏中露出。推荐依据、所属承诺和可回看线索保持可见但不抢标题。

### 资料库

资料库是一册暗色生长索引。搜索面是首要视觉对象，最近记录和结果章节沿同一纵向秩序展开。项目脉络是同一资料库的另一种编排，不增加新工作台。

### 次级索引

行动、记忆和决定使用相同的账册结构：数量是横向刻度，新建默认折叠，当前事项与历史连续排列。近况、时间、待整理、自动化和系统治理也使用连续台面，不再恢复卡片仪表盘。

### 上下文页

原始记录、行动、记忆、决定和目标从右侧进入同一类暗色上下文页。标题有足够分量；来源、状态和技术元数据按需展开；主要动作固定在最容易找到的位置。

### Atlas

Atlas 与全局壳共享石墨环境，但拥有更深的空间层次：

- 全局 3D 以小型点标、稳定领域、少量地标、桥梁、张力与前沿表达长期认识，不再使用根节点居中的球壳与语义扇区。
- 全局只承担定向和变化感知；标签严格收束，普通记录与弱关系留在中枢。
- 关系使用精细、低对比的线描语法；通用灰红到雾蓝方向渐变退出目标形态，颜色只在有明确认识含义时出现。
- 当前焦点与 hover 节点可以有克制 halo，普通节点不常驻发光，大小与亮度不冒充真实性。
- 聚焦后保持对象与地标连续，按主张、问题、规律、事件或机会展开相应的 2D 认识平面，不固定为一跳/二跳局部图。
- 工具像图注一样贴边，图谱始终是视觉主体。

白板与 Atlas 共享暗色材质，但更像一张可变的数字手稿：裸文字、细线、媒体和极淡区域优先，不把每个想法变成卡片。AI 候选与用户结构有克制但明确的材质差异，大规模重排只在分支预演。完整目标以 `docs/discovery_cortex/07_ATLAS_DISCOVERY_LANDSCAPE.md` 与 `08_WHITEBOARD_CO_DISCOVERY_ENVIRONMENT.md` 为准；当前 Atlas v1 仍按现有视觉契约维护，直到下一代原型通过认识任务验证。

### 私有入口

入口是一道安静的访问界面，不是居中登录卡。品牌与访问区组成两块连续暗面，访问线和单一进入动作足够完成任务，不展示营销卖点。

## 必须避免

- 把浅色页面机械反转成深色。
- 蓝紫霓虹、渐变光斑、玻璃拟态和通用 AI 科技风。
- 卡片墙、卡片套卡片、统计仪表盘和十三个平级工作台。
- 纤细小字、低对比正文、过量英文眉题和装饰性编号。
- 巨大首屏把下一步完全推到视口之外。
- 用介绍文案解释界面如何使用。
- 为填满 Atlas 伪造关系、随机撒点或让所有节点持续表演。
- 为艺术感牺牲真实操作、移动端可达性或阅读速度。

## 验收问题

1. 用户打开页面后，是否能在一次视线移动内找到当前焦点和下一步。
2. 去掉颜色后，字号、字重、位置和明度是否仍然形成清楚层级。
3. 页面是在呈现真实内容，还是在展示组件和功能数量。
4. 记录、找回和完成动作是否始终比管理能力更容易触达。
5. 桌面与 `390 x 844` 移动视口是否无横向溢出、遮挡和小于可读下限的文字。
6. Atlas 画布是否非空、取景正确、节点可辨，并能从全局 3D 平滑进入局部 2D。

## 参考精神

- OpenAI 产品页面的宽阔人文无衬线、稳定字重和克制控制密度。
- 瑞士国际主义排版的对齐、尺度和信息纪律。
- James Turrell 对暗环境、边界和局部光感的控制。
- 日本建筑中的间、静默材料和连续空间。
- Obsidian 图谱的点线直接性，以及 Outer Wilds Ship Log 的线索语境。
