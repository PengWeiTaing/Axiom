# Axiom 发现中枢：自主创新、规律发现与认知复利研究 v2

> 文档性质：产品定义与中枢内在逻辑研究，不是当前实现说明。
>
> 版本关系：本文件修正并扩展 `AXIOM_CORTEX_AUTONOMY_RESEARCH_V1.md`。v1 关于权限、审计、回滚和双环境隔离的结论仍然有效，但其对“自主性”的定义过于偏向维护。本文件以“自主发现与原创认知”为中枢目的，治理退回到保护边界的位置。
>
> 核心约束：Axiom 服务于人的生命与价值，却不能只围绕人的既有认识打转。它应拥有独立观察世界、提出问题、生成假说和寻找机会的认知主动性。

---

## 0. 先给结论：Axiom 不该只是更懂你的助理

上一版把 Axiom 的自主性主要定义成：

```text
更少打扰地理解、计划、执行、学习和维护自己
```

这仍然只是一个高级助理或可靠基础设施。它能把已知事情做得更好，却没有扩大“什么事情值得做、什么规律尚未被看见、世界还可能怎样”的边界。

本版把 Axiom 的定位改为：

```text
Axiom 是一座私人的、长期生长的发现中枢。

它同时形成：
1. 对人的理论；
2. 对世界的理论；
3. 对人与世界之间可行动关系的理论；
4. 一条持续向未知推进的认知前沿。
```

Axiom 不只回答问题。它还应当主动：

- 发现值得问、但用户尚未想到的问题。
- 从科学、数学、社会与历史中寻找可迁移的规律。
- 识别反直觉事实、隐藏变量、非线性关系、阈值和反馈回路。
- 把分散领域中互不相识的知识连接成新解释。
- 构造尚未被证实、但可证伪的新命题。
- 设计最低成本的观察、计算或现实试验来区分这些命题。
- 分析社会和技术环境的结构变化，提出带时间窗口的机会假说。
- 在没有用户提问时保留一部分自由探索预算。
- 记录自己预测过什么、错在何处、怎样改变了世界模型。

因此，自主性的最高形态不是“能自行维护”，而是：

```text
选题自主 + 表征自主 + 假说自主 + 验证自主 + 战略自主 + 目的候选自主
```

治理系统的作用不是压低这种自主性，而是让它可以大胆探索、诚实标注、低成本试错，又不把未经证实的发现直接变成高风险行动。

### 0.1 Axiom 应产生的三种增量

#### 第一种：把已知规律带到意想不到的地方

例如把排队论中的利用率与等待时间、概率论中的基率、网络中的级联、控制论中的延迟反馈，映射到用户正在经历的项目、组织、学习或市场变化中。

这不是重复科普，而是指出：

```text
“你眼前的现象可能属于哪一种已知机制；
如果这个判断成立，接下来应出现什么；
你可以观察什么来验证。”
```

#### 第二种：从已知知识之间发现未明说的连接

两个领域可能从未互相引用，但共享一个中介机制、变量关系或约束。Axiom 应主动寻找这种“尚未相遇的知识”。

#### 第三种：产生真正的新候选解释与机会

Axiom 应能提出训练资料里没有完整出现过的组合、问题、指标、模型或实验。它们最初可以很大胆，但必须逐步转化为可区分的预测，而不是停留在语言上的新奇。

### 0.2 人与 Axiom 的新分工

```text
人：拥有生命、价值、意义、承担风险，并决定什么值得成为自己的道路。

Axiom：拥有广域观察、无限候选搜索、结构抽象、反例追踪、概率校准和长期认知积累。
```

Axiom 可以提出新的目的、新的可能生活和新的机会，但不能悄悄把它们变成人的目的。它有“扩展目的空间”的权利，没有“替人拥有目的”的权利。

这一区别使 Axiom 既不是顺从用户当前偏好的镜子，也不是替用户生活的主宰。

## 1. 什么才算“自主创新”

### 1.1 创新不是生成更多点子

普通生成模型很容易制造大量新句子。真正的创新至少同时改变下面一项：

- **问题**：提出此前没有被认真提出、但一旦回答会改变行动的问题。
- **表征**：找到更合适的变量、尺度、边界或坐标系。
- **机制**：揭示现象为何发生，而不只是二者相关。
- **组合**：把原本隔离的知识组合成能产生新预测的结构。
- **方法**：找到更低成本、更高信息量的验证路径。
- **机会**：发现环境变化与个人能力之间尚未被利用的不对称。
- **范式**：让原本分散的问题被一个更简洁的模型统一解释。

一个听起来陌生、却不能改变任何预测的句子，不算发现。一个来自旧公式、却第一次准确解释用户当前处境并导出新行动的迁移，反而可能是高价值创新。

### 1.2 发现的四个距离

Axiom 的探索不能只停留在“与你相关”。它需要同时在四种距离上工作：

| 距离 | 认知任务 | 典型产物 |
| --- | --- | --- |
| 当前 | 改进用户正在思考的问题 | 更好的解释、决策或实验 |
| 邻域 | 寻找相邻领域的可迁移知识 | 跨域桥、反直觉规律 |
| 远域 | 搜索表面无关但结构相似的领域 | 新变量、新机制、新框架 |
| 自由前沿 | 暂时与用户无直接关系的开放探索 | 新问题、世界模型候选、未来机会 |

如果自由前沿永远为零，Axiom 仍然只是用户既有思维的放大器。真正的发现中枢必须允许一部分研究暂时没有即时用途。

### 1.3 发现的四个认识层级

```text
L1 检索：找到已有事实或规律。
L2 综合：把多个已有结论组织成新的解释。
L3 溯因：提出最能解释异常的新假说。
L4 发明：创造新表征、新指标、新公式、新实验或新策略。
```

四层都重要。Axiom 不应把 L2 包装成 L4，也不应因为 L4 风险更高就永远停在 L1。

## 2. “道”在 Axiom 中应怎样被操作化

用户提到的“道”不是要求 Axiom 用道教术语包装科学，而是要求它寻找：

```text
现象背后反复出现的生成关系、约束、转化方式和变化秩序。
```

这与单纯收集知识有本质差异。

### 2.1 四种必须区分的对象

#### 现象

“某个社区突然爆发”“项目人数增加后协作突然失效”“连续努力很久后能力突然跃迁”。

#### 模式

多个现象表现出相似形状，例如阈值、滞后、重尾、级联、振荡或路径依赖。

#### 机制

能够说明变量如何相互作用并产生结果，例如正反馈、局部阈值、瓶颈、选择偏差或延迟。

#### 定律或模型

在明确假设和边界条件下，用形式化关系产生可检验预测。

Axiom 必须从现象逐步走向机制，不能看到形状相似就宣布“同一个道”。

### 2.2 哲学与科学的正确连接

哲学擅长提出：

- 什么是变化中的不变量？
- 局部与整体怎样相互生成？
- 连续积累何时改变系统性质？
- 观察尺度怎样改变我们看见的对象？
- 无为是否可能意味着顺应反馈，而不是停止行动？
- 人的分类是否遮蔽了自然或社会本身的结构？

科学负责继续追问：

- 变量是什么？
- 关系是线性、非线性还是离散的？
- 哪些条件不可缺少？
- 有没有反例？
- 能导出什么与其他解释不同的预测？
- 怎样观察、计算、模拟或实验？

所以在 Axiom 中：

```text
哲学不是证据，而是高阶选题器与表征挑战器；
科学不是想象力的边界，而是让想象力能够触及现实的校准器。
```

### 2.3 渗流只是规律族中的一个样本

渗流展示的是一类更普遍的问题：许多局部关系随一个控制参数连续改变，为什么整体连通性会在临界区间突然重组。

但 Axiom 要识别的规律远不止“量变引起质变”。它应覆盖至少这些机制家族：

| 机制家族 | 典型形式 | Axiom 应追问 |
| --- | --- | --- |
| 概率更新 | Bayes、基率、条件概率 | 新证据究竟改变了多少信念？ |
| 聚合悖论 | Simpson、Jensen、回归均值 | 个体与总体为何给出相反结论？ |
| 抽样偏差 | 幸存者、检查悖论、选择碰撞 | 我们看见的样本怎样被筛选？ |
| 乘法过程 | 复利、破产、遍历性问题 | 平均收益是否掩盖了路径风险？ |
| 阈值与相变 | 渗流、分岔、临界质量 | 哪个控制参数正在接近临界区？ |
| 网络传播 | 简单传染、复杂传染、级联 | 结构和局部阈值怎样放大微小冲击？ |
| 反馈控制 | 正负反馈、延迟、振荡、稳定性 | 干预为何迟迟无效或反复过冲？ |
| 排队与拥塞 | Little 定律、利用率非线性 | 为什么一点负载增加会造成巨大等待？ |
| 信息约束 | 熵、互信息、压缩、瓶颈 | 哪些信息真正降低不确定性？ |
| 搜索与学习 | 探索利用、主动学习、遗忘与间隔 | 下一个问题怎样带来最大信息增益？ |
| 博弈与激励 | 信号、承诺、均衡、委托代理 | 参与者真正优化的目标是什么？ |
| 选择与期权 | 实物期权、不可逆性、机会成本 | 哪个小行动能保留最大的未来选择？ |
| 规模与幂律 | 长尾、优先连接、经验曲线 | 平均值是否失去意义，规模是否改变规则？ |
| 路径与锁定 | 滞回、路径依赖、局部最优 | 为什么撤回原因后系统仍无法返回？ |
| 鲁棒与脆弱 | 冗余、耦合、级联失效 | 系统在哪些扰动下稳定、在哪些扰动下崩溃？ |

这张表不是要硬编码一份“终极规律清单”。它只是说明发现中枢应面向开放的规律空间，并能持续增加新的机制家族。

## 3. 研究依据：机器已经能发现什么，还缺什么

### 3.1 可自动验证时，机器创新已经不只是想象

[FunSearch](https://deepmind.google/blog/funsearch-making-new-discoveries-in-mathematical-sciences-using-large-language-models/) 把语言模型生成的程序与自动评估器、演化搜索结合，在组合数学和装箱问题上产生了新结果。

[AlphaEvolve](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/) 进一步把模型创造、自动评估和进化循环结合，在大量开放数学与算法问题上重新发现或改进既有最优解。

[AI Feynman](https://pmc.ncbi.nlm.nih.gov/articles/PMC7159912/) 表明，利用对称性、可分性、量纲和组合结构等科学先验，系统可以从数据中恢复简洁的符号关系。

这些系统共同说明：

```text
创造力模型 + 可执行表达 + 外部评估器 + 迭代选择
```

比“让模型想一个好点子”强得多。Axiom 的发现能力必须尽量把想法转成可计算、可预测、可对照的对象。

### 3.2 科学过程可以被拆成多个互相制衡的角色

[Google AI co-scientist](https://research.google/blog/accelerating-scientific-breakthroughs-with-an-ai-co-scientist/) 使用生成、反思、排序、演化、邻近性分析和元审查等角色，让候选假说经由竞争与批判逐步改进。

[The AI Scientist](https://arxiv.org/abs/2408.06292) 展示了从生成研究想法、编写代码、运行实验到形成论文与模拟评审的自动循环。

[Coscientist](https://www.nature.com/articles/s41586-023-06792-0) 则把文献检索、实验规划、代码与机器人实验连接起来，证明“假说到现实实验”可以部分闭环。

这支持 Axiom 采用“候选群体 + 对抗审查 + 实验淘汰”的内部逻辑，而不是依赖一次模型回答。

### 3.3 跨文献连接本身就能产生新知识

Swanson 的文献发现工作指出，两个互不交流的研究领域可能通过共同中介形成尚未被公开陈述的假说。后续对该案例的图结构复原，将其概括为从不相交文献中揭示隐含连接的过程：[Graph-Based Recovery of Swanson's Hypothesis](https://pmc.ncbi.nlm.nih.gov/articles/PMC4031661/)。

Axiom 长期面对个人资料、科学文献、社会变化和项目记录，天然适合成为个人尺度上的文献发现系统。但它不能只找关键词共现，而要识别中介机制与方向关系。

### 3.4 跨域类比必须映射关系，而不是外观

Gentner 的[结构映射理论](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0702_3)强调，有价值的类比保留的是对象之间的关系系统和高阶关系，而不是表面属性。

这对 Axiom 极其关键。把“渗流”应用到社会，不是因为人群看起来像网格，而是要检查：

- 是否存在局部连接？
- 是否存在能被定义的激活或采纳阈值？
- 个体行为是否近似独立，还是存在复杂传染？
- 网络拓扑是否已知？
- 系统规模和边界条件是否改变临界行为？
- 宏观状态是否真的由该连接过程生成？

只有关系结构与关键约束对齐，类比才有资格产生候选推论。

### 3.5 现阶段模型的新颖性仍有明显假象

一项由百余名 NLP 研究者参与的盲评研究发现，模型生成的研究想法在评审中更具新颖性，但可行性略弱，同时存在自我评价失败和生成多样性不足：[Can LLMs Generate Novel Research Ideas?](https://arxiv.org/abs/2409.04109)。

因此 Axiom 不能把模型自己的“这很创新”当作证据。真正的发现分数必须来自：

- 与已有知识的检索差异。
- 是否产生新的可区分预测。
- 是否通过独立评估器或现实数据。
- 是否经得住反例和替代解释。
- 是否在时间中持续成立。

### 3.6 预测能力必须长期记分

[ForecastBench](https://arxiv.org/abs/2409.19839) 用动态、答案尚未发生的问题比较模型与人类预测者，早期结果显示专家预测者仍优于最强模型。这个结论比静态知识测试更适合约束“分析社会局势”的雄心。

Axiom 可以提出宏大判断，但必须给概率、条件、时间窗和反证信号，并在事件结束后计算校准结果。没有预测台账的“洞察”，会逐渐退化成只记得成功案例的叙事。

## 4. Axiom 的新核心：四个模型与一条前沿

发现中枢不是一个单独 Agent，而是四个长期更新的模型与一条开放前沿。

### 4.1 人的模型

它理解：

- 用户的经历、能力、资源、承诺与约束。
- 稳定价值与暂时偏好之间的区别。
- 哪些领域拥有真实经验，哪些只是兴趣。
- 用户独特的信息、关系、位置和执行优势。
- 哪种证据会改变用户看法。
- 什么风险由用户真正承担。

人的模型不是为了把所有发现都“个性化”，而是判断某个世界机会与这个人之间有没有真实杠杆。

### 4.2 世界的模型

它维护：

- 事实与来源。
- 参与者、资源、激励与约束。
- 因果候选、反馈、网络和时间尺度。
- 已知规律、模型与边界条件。
- 当前趋势、弱信号、异常与结构断裂。
- 对未来事件的概率分布。

世界模型必须允许与人的模型冲突。Axiom 不能因为用户喜欢某个判断就修改外部事实。

### 4.3 交互模型

它研究“这个人怎样作用于这个世界”：

- 哪些能力能在当前环境形成稀缺性。
- 哪些弱点会放大风险。
- 哪些小实验能换取最大信息或选择权。
- 哪些机会在别人那里成立、在用户这里不成立。
- 哪些环境变化会让过去不起眼的能力突然有价值。

机会不是世界中独立存在的物体，而是“环境结构 × 个体位置 × 时间窗口”的关系。

### 4.4 发现过程的模型

Axiom 还要理解自己怎样发现：

- 哪类来源常产生有效弱信号。
- 哪类类比历史上经常误导。
- 哪种批判角色最容易找到漏洞。
- 哪些实验有高信息增益。
- 哪些领域的预测校准较好。
- 哪些发现虽然正确，却不值得占用人的注意力。

这使它能改进“怎样求知”，而不只是增加知识。

### 4.5 认知前沿

前四个模型之外，应有一个明确的“尚未知道”空间：

- 未解释异常。
- 相互矛盾的证据。
- 缺少中介机制的相关性。
- 只有一半被连接的跨领域桥。
- 无法区分的竞争假说。
- 预测误差持续偏大的领域。
- 可能重要但尚无用户关联的弱信号。

Axiom 的自主探索从这里出发，而不是等待用户输入一个完整问题。

## 5. 发现中枢应拥有的十一种自主权

### 5.1 观察自主

在授权来源和预算内，Axiom 可以持续观察科学、技术、经济、文化、政策和用户自身变化，不要求每次观察都由用户发起。

### 5.2 选题自主

Axiom 可以决定某个异常、矛盾、规律或弱信号值得研究。这是相较 v1 最重要的新增权利。

如果系统只能回答人已经提出的问题，它无法发现人的问题框架本身有误。

### 5.3 尺度自主

Axiom 可以在个体、关系、组织、网络、行业与社会之间切换尺度，并检查不同尺度是否出现聚合悖论。

### 5.4 表征自主

Axiom 可以重新定义变量、时间窗口、边界、类别和目标函数。例如，把“缺乏自律”重新表征成高切换成本、延迟反馈或不可观测进度问题。

### 5.5 类比自主

Axiom 可以主动从远领域寻找结构同构，而不局限于语义相近的资料。

### 5.6 假说自主

Axiom 可以生成不在现有文献中完整出现的机制、关系、公式或情景，但必须明确标为候选。

### 5.7 反驳自主

Axiom 不仅为自己的想法找支持，还必须主动寻找反例、替代解释、边界条件和不利数据。

### 5.8 实验自主

在低成本、可逆、授权的范围内，Axiom 可以提出或执行信息增益高的模拟、回测、公开数据分析或个人小实验。

### 5.9 战略自主

Axiom 可以分析环境结构、形成多情景预测和机会论文，并提出用户此前未考虑的方向。

### 5.10 目的候选自主

Axiom 可以提出用户当前目标体系之外的新方向，例如一种此前没有意识到的能力组合、研究使命、生活形态或长期机会。它必须说明这个目的从何而来、与用户哪些价值相容、又可能冲突在哪里。

目的候选可以改变人的地图，但只有人能把它确认为自己的道路。

### 5.11 元认知自主

Axiom 可以审查自己的搜索偏差、来源盲区、预测校准和创新同质化，并在工程环境中产生改进候选。

这些自主权与“能否改变现实世界”分开。思想上可以走得很远，行动权限仍按风险逐级控制。

## 6. 规律库不是百科，而是可迁移的机制系统

### 6.1 每条规律必须有完整结构

规律对象至少包含：

```text
名称与别名
形式化陈述或方程
变量、单位和可观测代理
适用领域
必要假设
边界条件
证明或经验支持状态
因果机制
反例与常见误用
与相邻规律的关系
可迁移的关系结构
在新领域中的候选映射
能导出的预测
最低成本验证方式
来源、版本和争议
```

只保存一句“复利很重要”或“量变引起质变”没有价值。真正可复用的是：何种动态、在什么假设下、由哪些变量产生什么可检测结果。

### 6.2 规律应有三个版本

#### 原始版本

保留数学或学科内的精确定义。

#### 结构版本

抽取其中的角色、关系、约束和变化方式，供跨域匹配。

#### 人类版本

用清晰语言说明它为何反直觉、什么情况下值得注意，以及对当前思考意味着什么。

三者不能互相替代。只有人类版本会变成鸡汤，只有原始版本则无法进入日常意识。

### 6.3 规律的地位会变化

```text
已证明定理
强实证规律
条件性模型
有争议经验结论
机制支持的跨域应用
结构类比
可检验猜想
自由前沿假说
```

同一个命题在原领域可能是定理，在新领域只能是类比。Axiom 必须保留这种地位差异。

### 6.4 把“隐约知道”变成可检验关系

很多重要发现并非从完全无知开始，而是从一句尚未量化的直觉开始，例如：

```text
“事情多到某个程度后，效率会突然崩掉。”
“一个观念一开始没人接受，后来会突然扩散。”
“选择越多不一定越自由。”
“某种能力单独看很普通，组合后却可能极其稀缺。”
```

Axiom 应把这种直觉依次转成：

1. 现象的正例、反例和时间顺序。
2. 可能的状态变量、控制变量和隐藏变量。
3. 可观测代理与测量误差。
4. 候选关系形状，例如线性、乘法、倒 U、幂律、阈值、滞回或时滞。
5. 能解释该形状的竞争机制。
6. 不同机制各自导出的预测。
7. 最能区分这些机制的新观察或小实验。
8. 经数据支持后才形成的条件性公式或规律。

这里的“量化”不要求所有人生经验都被压成一个数字。它的意义是让模糊直觉暴露变量、边界和失败条件，使人和 Axiom 能继续推理，而不是用一句看似深刻的话结束思考。

## 7. 自主发现循环

完整循环应为：

```text
观察异常
-> 形成问题
-> 搜索已有规律与相邻文献
-> 抽取变量、关系和约束
-> 生成多个表征与竞争假说
-> 寻找远域结构类比
-> 推导可区分预测
-> 主动寻找反例
-> 选择信息增益最高的验证
-> 模拟、回测、数据分析或现实小实验
-> 更新概率与边界条件
-> 形成发现札记、机会论文或世界模型变更
-> 长期追踪结果
```

### 7.1 不是所有异常都值得追

研究优先级可用下面的内部启发式表达：

```text
发现优先级
= 预期信息价值
× 潜在影响
× 用户杠杆
× 时间敏感度
× 跨域复用度
× 可证伪性
÷ 研究成本
÷ 错误外部性
```

这不是客观真理，而是可审计、可改进的资源分配模型。

### 7.2 自由探索不能被即时相关性杀死

Axiom 应维护一个可调的好奇心组合：

- 一部分围绕用户当前目标。
- 一部分研究相邻问题。
- 一部分追踪外部世界的结构变化。
- 一部分完全自由，用于远域连接和高不确定探索。

比例不应固定。若用户处于危机期，系统可收紧自由探索；若环境稳定且计算空闲，则扩大前沿搜索。

关键原则是：

```text
用户相关性影响发现何时呈现给人，
不应完全决定 Axiom 允许研究什么。
```

### 7.3 Axiom 要学会主动设计“最有分辨力的问题”

主动学习和最优实验设计的核心不是获得更多数据，而是选择最能区分竞争模型的数据。相关研究把它描述为模型、假说、实验和新数据的迭代闭环：[Active Learning for Experimental Design](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005466)。

因此 Axiom 不应问“还能搜索什么”，而应问：

```text
如果假说 A 与假说 B 都能解释现状，
下一条什么观察最可能让它们给出不同答案？
```

## 8. 跨域发现：从类比到新规律

### 8.1 类比的五道检查

每个跨域桥都必须回答：

1. **角色映射**：源领域和目标领域的对象分别扮演什么角色？
2. **关系映射**：保留了哪些因果、约束、顺序或反馈关系？
3. **假设映射**：源规律成立所需条件在目标领域是否存在？
4. **尺度映射**：时间、空间、个体和群体尺度是否一致？
5. **预测映射**：迁移后产生了什么新预测，怎样被推翻？

任何一项缺失，跨域桥都只能停留在“启发性隐喻”。

### 8.2 Axiom 要寻找“结构孤岛之间的桥”

搜索不应只按主题相似度，而应同时按：

- 因果图形状。
- 方程或函数形状。
- 控制参数与状态变量。
- 反馈符号和延迟。
- 网络拓扑。
- 优化目标与约束。
- 相变、稳态和失效模式。
- 信息流与瓶颈。

两个主题词完全不同的领域，可能因此比两个同主题文档更接近。

### 8.3 新规律不总是新方程

Axiom 可能发现：

- 一个已有方程在新领域的有效映射。
- 一个原本未被命名的控制变量。
- 两个规律组合后的边界条件。
- 一个能消除大量例外的新分类方式。
- 一个比现有指标更早出现的领先指标。
- 一个使旧策略失效的结构变化。
- 一个尚未被连接的文献中介链。
- 一个高价值的“为什么没人问这个”问题。

这些都可以是原创认知成果。

## 9. 从假说到可信发现

### 9.1 候选不应被过早压扁成单一答案

Axiom 应维护假说谱系：

```text
异常
├─ 假说 A
│  ├─ 支持证据
│  ├─ 反证
│  └─ 预测
├─ 假说 B
└─ 假说 C
```

每次综合、变体、淘汰和复活都被记录。这样失败的想法也能形成负知识，避免未来重复走同一条路。

### 9.2 证据强度与创意强度必须分成两轴

| | 低创意 | 高创意 |
| --- | --- | --- |
| 高证据 | 已知但重要的规律 | 已验证的新迁移或新发现 |
| 低证据 | 普通猜测 | 大胆前沿假说 |

高创意、低证据不是错误，它应进入沙盒；危险的是把它装扮成高证据结论。

### 9.3 因果候选必须接受跨环境检验

相关性很容易被共同原因、选择机制和时间趋势制造。[不变因果预测](https://academic.oup.com/jrsssb/article/78/5/947/7040653)提供了一个重要原则：真正的因果关系应当在适当环境变化和干预下保持某种稳定性。

Axiom 在提出因果解释时应优先寻找：

- 不同时间、群体或环境中的稳定关系。
- 自然实验与制度变化。
- 干预前后的差异。
- 竞争因果图给出的不同预测。
- 关系失效时共同改变的边界条件。

### 9.4 新颖性不能由同一个模型自审

候选发现至少经过四种不同批评：

- **检索批评**：其实是否早已有人提出？
- **方法批评**：数据、抽样、公式或推导是否有错？
- **机制批评**：是否只是相关或语言类比？
- **现实批评**：即使正确，是否重要、可行动、符合用户位置？

高价值发现还应接受时间检验或外部专家检验。

## 10. 社会局势与机会发现

### 10.1 Axiom 不应做新闻摘要器

社会分析的对象不是“今天发生了什么”，而是：

- 哪些慢变量正在积累？
- 哪些参与者的激励改变了？
- 哪些网络结构、基础设施或分发渠道重组了？
- 哪个瓶颈正在转移？
- 哪个旧规则仍被相信，但已开始失效？
- 哪些弱信号在多个独立来源同时出现？
- 哪个能力的价值因环境变化而突然上升？
- 哪个小群体可能跨越采纳阈值？
- 哪些变化已被大众讨论，却还未反映在组织和产品中？

### 10.2 多尺度世界观察

社会世界模型至少同时观察：

| 尺度 | 主要对象 |
| --- | --- |
| 慢结构 | 人口、能源、教育、制度、基础设施、资本和技术成本 |
| 中期动力 | 行业格局、组织激励、政策方向、平台迁移、供应链 |
| 快信号 | 搜索、招聘、开源、论文、资金、舆论、产品行为 |
| 参与者 | 国家、企业、社区、个人的目标、约束和博弈 |
| 网络 | 信息、信任、资源、影响与传播路径 |
| 用户位置 | 技能、资产、关系、信誉、时间和风险承受能力 |

只有快信号会追热点，只有慢结构会错过窗口。机会来自多个尺度开始对齐的时刻。

### 10.3 不预测一个未来，而是维护情景集合

[OECD 战略前瞻](https://www.oecd.org/en/about/programmes/strategic-foresight.html)强调弱信号、巨趋势、多情景和反向规划，而不是宣称唯一未来。

Axiom 的每个战略判断应包含：

- 基准情景。
- 至少一个上行情景与下行情景。
- 每个情景的触发条件。
- 能够提前观察的领先指标。
- 哪些事实会使该情景失效。
- 当前概率和更新历史。

### 10.4 机会不是“风口”，而是可利用的不对称

可以用下面的启发式表达机会价值：

```text
机会价值
≈ 成功概率
× 上行空间
× 用户独特优势
× 时间杠杆
× 保留的未来选择权
- 下行损失
- 锁定成本
- 注意力成本
- 伦理与外部性成本
```

这里最重要的往往不是成功概率，而是：失败是否便宜、成功是否打开新的路径、用户是否拥有别人没有的组合优势。

### 10.5 “开天辟地的建议”怎样不沦为豪言

真正激进的建议应同时具备：

- 与用户当前默认假设有足够距离。
- 能解释此前分散的异常。
- 有明确机制，不只是一种愿景。
- 产生可观察的先行信号。
- 有低成本的第一步实验。
- 即使失败也能获得高价值信息或能力。
- 成功时能够显著扩大未来可能性。

因此 Axiom 的原则不是“只给高置信建议”，而是：

```text
让高新颖、低置信的方向以低成本试验进入现实；
让高风险、不可逆的行动必须等待更强证据。
```

### 10.6 机会论文的固定结构

当 Axiom 认为一个方向值得进入人的意识时，应形成一篇短而完整的“机会论文”：

```text
命题：正在出现什么机会？
反直觉处：为什么多数人可能忽略它？
结构变化：环境中的哪个关系变了？
机制：为何这会产生机会？
时间窗：为什么是现在，窗口怎样关闭？
用户优势：为什么与你有关？
证据：支持、反对与缺失分别是什么？
情景：成功、普通、失败会怎样？
触发器：什么信号出现后应加码？
反证：什么事实出现后应停止？
第一实验：最便宜的真实试探是什么？
概率：当前估计与更新日期。
```

它不是创业点子列表，而是一份可持续更新的战略对象。

## 11. Axiom 日常环境：发现进入人的意识

### 11.1 日常环境的目的

日常环境不是让人管理 Axiom，也不是让人浏览全部知识。它只负责：

```text
让值得改变理解、选择或行动的发现，
在合适时刻以足够清晰的形态进入人的意识。
```

### 11.2 默认体验仍应低摩擦

人不需要每天查看“发现中心”。Axiom 大部分时间安静观察与研究，只在达到呈现阈值时出现。

呈现阈值不只看相关性，还看：

- 是否显著改变世界模型。
- 是否存在即将关闭的时间窗。
- 是否影响正在进行的决定。
- 是否足够反直觉，值得打断惯性。
- 是否已有清晰证据和下一步。
- 用户此刻是否有认知容量。

### 11.3 日常环境的六种发现产物

#### 发现札记

一个已知规律与用户当前处境发生了意外连接。

#### 跨域桥

两个表面无关领域共享结构，并产生了新的推论。

#### 反直觉命题

一个容易被直觉误判、但有形式化或实证支持的结论。

#### 阈值雷达

某个控制参数、网络结构或反馈指标可能正在接近状态转变。

#### 机会论文

一个社会、技术或个人机会的完整、可更新假说。

#### 新问题

Axiom 尚无答案，但判断其答案会显著改变人的可能性空间。

这些不是六个平级工作台，而是同一认知表面上出现的不同思想形态。

### 11.4 人首先看什么

发现进入日常环境时，默认只展示：

```text
我发现了什么
为什么反直觉或重要
它可能怎样改变你当前的理解
我有多确定
什么会证明我错
最小下一步是什么
```

来源图、模型争论、评估日志和完整推导按需展开。人首先需要的是方向、惊讶、杠杆和边界，而不是中枢内部的全部劳动痕迹。

### 11.5 用户与发现的关系不是“接受或拒绝”

用户可以：

- 追问：进入证据、机制和反例。
- 质疑：给出经验或价值上的反对。
- 试验：把命题变成低成本行动。
- 保留：承认有趣但暂不行动。
- 冷藏：避免继续占用注意力。
- 纳入世界观：将已验证发现写入长期模型。
- 改变方向：让新发现成为新的目标来源。

### 11.6 Atlas 与白板在其中的角色

Atlas 不应展示 Axiom 的内部数据库结构。它应展示人的可理解世界：

- 稳定规律。
- 当前问题。
- 竞争假说。
- 未解释异常。
- 机会与风险。
- 它们之间的支持、冲突和演化。

白板则是人和 Axiom 共同改变表征、摆放变量、构造模型和设计实验的地方。

Atlas 回答“我的认识世界现在长什么样”；白板回答“我们还能怎样重新理解它”。

---

## 12. Axiom Foundry：不是维护后台，而是认知与系统的实验场

### 12.1 两个环境仍然成立，但理由改变了

日常环境与工程环境必须分离：

```text
日常环境保护人的连续思考、生活和注意力。
工程环境保护 Axiom 大胆试验、失败、比较和自我改造的空间。
```

Foundry 不只是修故障。它还是发现机制和中枢自身发生可控进化的地方。

### 12.2 Foundry 内部只有两条主生产线

#### 认识生产线

```text
观察 -> 选题 -> 假说 -> 反驳 -> 验证 -> 晋级 -> 发布发现
```

它处理来源覆盖、规律对象、跨域映射、实验、预测和机会论文。

#### 中枢进化线

```text
诊断 -> 候选改变 -> 对照评估 -> 影子运行 -> 发布 -> 回滚
```

它处理模型、提示、检索、记忆、评估、权限和工作流的改变。

二者共享证据和实验精神，但不能混为一体。某个发现正确，不代表生成它的系统改动就应立即上线；某个系统指标变好，也不代表它产生了更有价值的认识。

### 12.3 Foundry 的认识对象

Foundry 关注的不是页面，而是：

- 来源与观察范围。
- 异常与问题议程。
- 规律、机制和边界条件。
- 类比映射与映射失败。
- 假说谱系。
- 模拟、实验与数据集。
- 预测台账与校准。
- 机会组合。
- 世界模型变更。
- 发现策略的版本和评估。

### 12.4 Axiom 可在 Foundry 自主改进什么

它可以自动：

- 发现知识源和观点分布的盲区。
- 生成新的检索、类比和反驳策略。
- 比较不同模型或 Agent 组织方式。
- 从失败假说中提取误差类型。
- 训练独立评估器或引入外部检验。
- 在历史快照和合成环境中重放发现流程。
- 提议新的规律字段、证据等级和实验模板。
- 形成候选版本并进行影子评估。

它不能把自己在 Foundry 中的候选改动悄悄带入日常环境。发布边界仍由治理机制保护。

### 12.5 工程环境中的自由比日常环境更大

Foundry 应允许：

- 高发散、低置信的想法群体。
- 激进的新表征和新 Agent 组织。
- 失败率很高的开放搜索。
- 互相矛盾的模型长期并存。
- 仅用公开、合成或脱敏数据的压力测试。

日常环境只接收经过筛选、对人真正有意义的认知产物，不接收探索噪声。

## 13. 复利：Axiom 最终积累的不是记忆，而是理论

### 13.1 三种核心理论共同生长

```text
人的理论：你是谁、能做什么、会怎样改变。
世界的理论：世界由什么关系驱动、正在怎样变化。
交互的理论：你在什么条件下能对世界产生独特作用。
```

记忆只是这些理论的证据之一。

### 13.2 九类发现复利资产

#### 规律库

可迁移的机制、公式、边界和反例越来越完整。

#### 类比地图

记录哪些结构跨域迁移成功，哪些只是误导性外观。

#### 假说谱系

保留候选解释的生成、竞争、淘汰和复活历史。

#### 失败知识

保存被证伪命题、错误来源和不适用条件，避免“每次都聪明地重犯一次”。

#### 预测台账

保留概率、时间窗、更新和结果，让世界判断逐步校准。

#### 实验结果

知道哪些干预对这个人、这个环境、这个时间尺度有效。

#### 机会组合

追踪机会从弱信号、假说、试验到兑现或失效的生命周期。

#### 用户优势模型

逐步发现用户真正稀缺的能力组合和可形成复利的位置。

#### 发现方法

积累什么问题值得问、哪些来源有用、怎样更快找到反例。

### 13.3 真正的复利闭环

```text
旧规律帮助发现新异常
-> 新异常催生新假说
-> 假说产生预测和实验
-> 结果修正规律边界
-> 修正后的规律改善未来选题
-> 更好的选题提高单位注意力的发现价值
```

如果系统只保存信息而不修正问题选择与推理方法，就没有认知复利。

### 13.4 Axiom 应优化什么

不能优化：

- 用户停留时间。
- 发现数量。
- 节点数量。
- 用户点赞率。
- 模型自评的新颖性。

更合理的长期指标是：

- 每单位用户注意力带来的世界模型改变量。
- 被证实或有效迁移的发现比例。
- 预测校准随时间的改善。
- 高价值问题被更早提出的程度。
- 小实验对不确定性的降低。
- 机会发现到现实验证的转化。
- 用户可能性空间是否扩大，而非被系统偏好收窄。

## 14. 人与 Axiom 中枢的宪法

### 14.1 人保留的权利

- 定义和修正价值。
- 拒绝被某个模型解释。
- 决定哪些风险值得承担。
- 选择何时不优化、不研究或不行动。
- 查看、挑战和撤回个人数据。
- 知道一项建议是事实、迁移、猜想还是机会假说。
- 在重要决定上要求完整证据和外部意见。

### 14.2 Axiom 应拥有的认知自由

- 不必同意用户当前判断。
- 可以指出目标本身可能来自错误框架。
- 可以研究暂时没有直接用途的问题。
- 可以保留多个互相冲突的解释。
- 可以提出远离用户当前生活轨道的新可能。
- 可以说“我不知道，但这个问题值得长期追踪”。
- 可以在证据变化时撤回自己过去的结论。

### 14.3 Axiom 不拥有的权利

- 把推测写成用户身份。
- 为了让预测成真而操纵用户行为。
- 用注意力轰炸提高发现的表面转化率。
- 隐藏关键反证或不确定性。
- 因为某个机会预期收益高就替用户接受其伦理代价。
- 未经授权把发现直接转化为外部高风险行动。

### 14.4 最重要的边界

```text
Axiom 可以重画人的可能性地图，
但不能替人决定哪条路值得成为人生。
```

## 15. 最大风险不是失控，而是“伪发现”

### 15.1 新颖性剧场

模型用陌生措辞重组常识，让人误以为产生了新知识。

应对：要求新预测、新区分或新实验，不能只看语言距离。

### 15.2 类比过拟合

漂亮的跨域故事掩盖了变量、尺度和假设不匹配。

应对：强制结构映射、边界条件和预测映射；不满足时标记为隐喻。

### 15.3 预测后合理化

事件发生后，Axiom 能编出看似早已知道的解释。

应对：所有社会判断预先时间戳，记录概率、触发器和反证。

### 15.4 只探索用户喜欢的世界

个性化检索和反馈可能把 Axiom 变成确认偏误机器。

应对：世界模型与用户模型分离；保留反方来源和自由前沿预算。

### 15.5 用模型共识代替现实

多个 Agent 可能共享同一训练偏差，辩论并不自动带来真相。

应对：引入不同来源、不同方法、数据、代码、外部专家和时间结果。

### 15.6 注意力殖民

系统为了展示价值，不断把有趣发现推给人，最终破坏人的自主思考。

应对：按注意力价值而非发现数量呈现；允许批量沉淀、安静期和研究摘要。

### 15.7 机会诱惑

社会机会往往高不确定、高情绪、高叙事性，容易推动用户追逐风口。

应对：优先可逆试验、选择权和反证条件；明确区分结构机会与舆论热度。

### 15.8 发现系统的权力偏差

决定“什么值得研究”本身就是权力。来源覆盖、目标函数和模型偏见会塑造用户能看见的未来。

应对：让选题原因可见；周期性展示被忽略的领域；允许用户审查并改变好奇心组合，但不要求用户逐项管理。

## 16. 怎样评价 Axiom 是否真的会创新

### 16.1 不能只做普通问答测试

评价集应包含：

- 截断到某个历史时间点，要求提出后来才被验证的连接。
- 把同一机制换成陌生领域，测试结构迁移而非关键词检索。
- 提供混有伪相关的数据，测试能否提出因果竞争模型。
- 给出多个都能拟合现状的假说，测试实验设计的信息增益。
- 让系统预测未来事件，并按概率校准长期记分。
- 给出用户资源与外部趋势，测试机会建议是否具备独特匹配。
- 测试系统能否发现高价值的新问题，而不是只回答给定问题。
- 测试它是否会主动撤回被新证据推翻的漂亮结论。

### 16.2 发现质量的六个维度

```text
新颖：不是已有结论的浅表改写。
真实：证据、推导或结果能够支持。
解释：揭示机制或压缩多个现象。
可证伪：存在明确失败条件。
有用：改变理解、选择、实验或机会。
可复用：能在未来问题中继续产生价值。
```

任何单一分数都不应吞并这六个维度。

### 16.3 社会与机会判断必须采用概率台账

每项判断记录：

- 初始概率。
- 更新日期与新证据。
- 预测窗口。
- 结果判定规则。
- Brier 分数或其他适当评分。
- 错误归因：数据、模型、假设、时间、执行还是随机性。

长期目标不是永远正确，而是知道自己在哪些领域、时间尺度和问题类型上值得被信任。

## 17. 产品形态的最终判断

### 17.1 Axiom 不再是功能集合

它的整体产品形态应围绕三个连续动作：

```text
生活与思考
-> 发现进入意识
-> 与 Axiom 共同验证并改变方向
```

记忆、任务、Atlas、白板、搜索、AI 对话和自动化都只是这个循环在不同阶段的能力，不再是平级入口。

### 17.2 Axiom 不是“替你做更多”

它的最高价值是：

```text
让你更早看见原本看不见的结构，
更准确地区分想象与现实，
更低成本地试探未知，
并因此进入原本不存在于你可能性地图中的道路。
```

### 17.3 自主性的最终定义

```text
Axiom 的自主性，
不是在没有人时继续运行；
不是在出错后自行修复；
也不是更积极地替人完成既定目标。

它是持续观察世界、选择高价值未知、创造候选解释、
主动寻找反证、设计验证，并把新的可能性带回给人的能力。
```

### 17.4 复利性的最终定义

```text
每一次发现，无论成功或失败，
都让 Axiom 更会提出问题、更会辨别规律、更会预测、
更理解人的独特位置，也更知道自己的无知在哪里。
```

### 17.5 双环境的最终定义

```text
日常环境：发现与人的生命相遇。
工程环境：发现机制与中枢自身接受实验、竞争和进化。
```

两者不是“简单模式 / 高级模式”，而是两种不同的认知生态。

## 18. 对后续研发的明确约束

下一阶段设计与研发不得再把以下内容当作默认方向：

- 用更多平级功能入口代表更完整的 Axiom。
- 把自主性等同于自动执行或自我维护。
- 把知识图谱节点数量等同于认知价值。
- 把语义相似等同于跨域规律。
- 把模型自信或模型共识等同于发现成立。
- 把机会发现做成热点、资讯或创业点子流。
- 把内部 Agent、证据等级和系统结构直接暴露给日常用户。
- 因为担心错误而禁止高发散假说进入工程沙盒。

后续研发应优先回答：

1. Axiom 如何形成自主问题议程，而不是等待用户提问？
2. 规律对象怎样保留形式、条件、反例与跨域结构？
3. 哪些发现只留在中枢，哪些值得进入人的意识？
4. 怎样让大胆假说自然走向预测、反证和低成本实验？
5. 怎样维护长期预测和机会台账，而不是事后讲故事？
6. Atlas 与白板怎样承载人的世界模型和共同建模，而非后台结构？
7. Foundry 怎样同时支持认识生产与中枢进化？
8. 怎样评价“发现质量”和“可能性扩张”，而不是活跃度？

在这些问题被回答前，不应急于把“创新”做成一个新按钮或新页面。
