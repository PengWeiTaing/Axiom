# Axiom 产品模型

更新时间：2026-08-31

> 2026-09-05 独立复研与旧研究比较见 [复研报告](AXIOM_INDEPENDENT_RESEARCH_2026-09-05.md)。它建议重新验证 3D 默认、固定下潜路径、导航显露和统一艺术隐喻；这些仍是待验证提案，本页未因此被自动替换为新规格。

这份文档定义 Axiom 对用户呈现的产品形态和内部认知逻辑。页面、功能和数据模型的新增都必须服从这里，而不是反过来扩张一级入口。

## 一句话定义

Axiom 是一个以“此刻”为人与中枢接触面的私人发现型外脑：它持续接住输入、保留事实、理解人和世界、推动下一步，也会自主寻找规律、异常、新问题与机会，并从预测和行动结果中修正自己的理论。

Axiom 不是笔记、任务、记忆、决策和图谱工具的集合。这些是系统内部理解信息的对象，不是用户必须学习的导航结构。

Axiom 也不只是一套更可靠的个人维护系统。它应拥有观察、选题、表征、类比、假说、反驳、实验和战略上的认知主动性，在不替用户占有价值与人生目的的前提下，主动扩大用户能够看见的可能性空间。完整定义见 `docs/AXIOM_DISCOVERY_CORTEX_RESEARCH_V2.md`，各认知器官的独立研究见 `docs/discovery_cortex/00_RESEARCH_MAP.md`；权限治理与发布边界见 `docs/AXIOM_CORTEX_AUTONOMY_RESEARCH_V1.md`。

## 用户面对的形态

Axiom 只有三个主要目的地和一个全局动作：

- **此刻**：默认工作面，回答现在最应该关注什么、为什么、下一步是什么、需要想起什么。
- **资料库**：统一找回记录、文件、记忆、任务和决策；对象类型只是筛选视角。
- **Atlas**：长期认识世界的空间投影；全局 3D 用于认知定向，聚焦后连续展开为适合当前问题的 2D 认识平面与证据审理。
- **记录**：任何位置都能触发的全局动作，不是独立工作台，也不要求用户预先分类。

任务、记忆、决策、处理队列、时间线和回顾只在相关上下文中出现。自动化、结构编辑和系统治理属于独立 Foundry 环境。Axiom 白板从此刻或 Atlas 按问题展开，由中枢把材料、机制、证据、反例、时间与情景编排成可理解、可质疑的认知展演，不是第四个常驻目的地，也不要求用户维护画布。

## 视觉人格

Axiom 的视觉不是后台管理系统，也不是用霓虹和星球隐喻包装的“未来科技”。下一代审美主线是原生暗色的“夜行长卷”：以低刺激暗场承载连续游观、局部显影、尺度变化和时间展开，让人从此刻进入关系地形，再进入问题展演，始终保留来路与下一段线索。它不把旧浅色页面反转，也不使用卡片、阴影、玻璃或光球制造层次。

界面的结构吸收中国手卷的连续观看、Warburg 的关系编排、暗环境艺术对局部光感的控制、数据艺术的尺度与节奏，以及动态媒介让系统行为可感的能力。艺术感不能依靠装饰堆叠获得，而要来自信息远近、虚实、节奏、媒介和认识状态的统一。Atlas 是长期认识地形；白板是 Axiom 针对当前问题策划的一次动态展陈。构图提出解释，但不能冒充事实。

低摩擦是形态约束：默认入口直接恢复一个当前语境；全局记录不要求分类；资料库沿当前问题自然找回；次级对象只在相关上下文中投影，治理能力只进入 Foundry。日常界面不再用“索引”容纳历史工作台。任何新功能都必须先证明它不能融入现有认识路径，才允许增加入口。

完整规则见 `docs/FRONTEND_ART_DIRECTION.md`。新增页面必须延续同一视觉人格，不得重新引入浅色纸面、卡片墙、蓝紫科技风、常驻发光大球或对象类型工作台。

## 此刻

“此刻”是唯一主工作面，不是任务列表或统计看板。它按视觉优先级呈现：

1. 一个当前焦点。
2. 一个可以立即开始的下一步。
3. 本周明确承诺的少量行动与完成进度。
4. 少量备选行动。
5. 等待用户判断的记忆或决策。
6. 最近进入外脑的上下文。

系统应减少选择成本，而不是把所有可能行动同时展示出来。

用户确认的目标是承诺，不是新的一级页面。每项承诺在目标详情中保留“怎样算完成”、可选目标日期、上层目标、复盘节奏和推进状态；这些字段用于形成持续推进的脉络，不把目标重新扩张成工作台。

只有“推进中”的承诺及其行动参与“此刻”判断。暂停、达成或放下会保留历史和关联行动，但行动退出当前候选；重新推进时可以恢复。确认目标尚无未完成行动、完成定义缺失、目标日期临近或复盘到期时，系统把最需要处理的一项原因放入“待你判断”。候选目标和已归档目标不参与行动判断。

“本周承诺”是“此刻”内部的周节奏，不是第四个目的地，也不是另一份任务清单。用户从现有行动中明确选择最多五项，系统只保存引用、当时标题和选择/移出历史；完成的行动留在本周进度中，未完成行动仍是资料库和项目脉络里的同一个对象。

周承诺不会自动替用户填满。系统可以从当前承诺与项目脉络中给出候选，但只有用户明确加入后才成为本周意图。被列入本周会成为“此刻”的可解释辅助信号，行动自身的逾期和明确期限仍然优先。

当一个行动大到无法直接开始时，用户可以在行动详情中把它拆成最多五个执行步骤。拆解不创建任务树工作台：上层行动继续表达原始意图，步骤继承它的目标、项目/生活线、优先级和期限，并作为真正可执行的行动进入“此刻”。只要仍有开放步骤，上层行动就不与步骤争夺当前焦点，也不能被提前标记完成。

步骤始终保留上层行动关系和选择时标题；即使原始行动后来被删除，来源仍可回看。上层行动、本周承诺和项目脉络展示步骤的真实完成进度，而不是把“生成了几个步骤”误当成进展。第一版只允许一层拆解。AI 可以基于目标、完成定义、已有步骤、近期结果和用户保存的周复盘给出临时候选；候选可编辑、可放弃，只有用户明确确认后才创建行动，并保留“手动拆解 / AI 候选确认”的来源。

周复盘仍属于“此刻”内部。系统汇总本周承诺、执行步骤和完成结果，用户只需判断步骤粒度是合适、偏大还是偏碎，并可留下短说明。这个判断是下一次拆解建议的依据，不是 AI 对用户的永久画像；系统保存的是用户判断和可核对的统计，不保存一篇替用户下结论的生成式复盘。

AI 拆解候选的生成、确认、编辑和放弃构成可回顾的结果链，但持久层只保存模型、步数、总时长、候选指纹和处理结果，不保存候选正文。只有累计到足够结果后，下一次建议才能做保守校准；少量样本不得被包装成稳定偏好。

“此刻”可以在有明确证据时显示最多两条可忽略的卡点提示：本周行动长期未启动、已拆步骤持续没有变化，或周后半段承诺仍未收口。提示必须列出可核对依据，只打开原任务或周复盘；它不会自动调用模型、创建行动或形成新的提醒中心。用户选择“本周忽略”后，本周不再重复出现。

## 资料库

资料库承担“找回”，而不是“分类管理”。用户可以按主题、人物、项目、时间或对象类型查看内容，但不需要先选择记忆库、决策台或任务台。

资料库提供“查找”和“项目脉络”两种查看方式。项目或生活线详情汇合目标、材料、事实、行动、决定、进展和历史，而不是把它们拆散到不同模块；父生活线默认汇总子线，用户可以继续下钻。这个详情只是现有对象的上下文编排，不复制数据，也不承担 Atlas 的关系探索职责。

承诺在脉络详情中显示其上层目标、完成定义、目标日期和行动进展；行动即使尚未单独挂载，只要明确关联该承诺，也应跟随承诺出现在脉络中。对象详情可以返回所属项目或生活线，避免用户重新经过对象类型工作台寻找上下文。

## Atlas

Atlas 回答“我的认识世界现在长什么样”。它不是中枢数据库、对象类型和相似度分数的直接可视化，而是为人生成的认识投影。

- 全局 3D 只承担定向：长期领域、少量地标、跨域桥梁、活跃张力、已知未知与真正发生变化的区域。
- 空间以长期区域稳定和解释上的共同运动组织，不再以 Axiom 根节点为中心做球壳撒点，也不把图论中心度当重要性。
- 聚焦不是切换页面，而是保持对象与地标连续，逐渐展开为适合当前问题的 2D 平面。
- 2D 不固定为局部节点图：主张进入证据审理，问题进入竞争模型，规律进入跨域映射，事件进入时间与因果，机会进入情景比较。
- 一条关系必须能翻译成完整主张，并显示最强支持、最强反证、竞争解释和下一条最有判别力的证据。
- 全局只显示会帮助人定向的极少内容；低权重边、内部模型意见、检索链和对象类型留给中枢与 Foundry。

Atlas 采用深石墨静场、精细线描、小型点标与大尺度留白。节点不做行星大球，所有对象不持续呼吸，通用关系线不再使用中心红、外围蓝的装饰渐变。亮度主要表达当前注意，不冒充真实性；未知、反证和竞争解释拥有正式视觉位置。

当前代码仍是 Atlas v1 的 3D 全局与 2D 局部关系图。下一代重构以 `docs/discovery_cortex/07_ATLAS_DISCOVERY_LANDSCAPE.md` 为产品事实源，旧 `docs/axiom_atlas_v_1_spec_for_claude.md` 只作为历史，不再定义目标形态。

## 白板

Axiom 白板回答“围绕这个问题，Axiom 怎样让我真正看懂”。它不是通用画布或 AI 思维导图，而是中枢主动生成的认知展演：Axiom 根据问题选择机制、阈值、时间、比较、情景、类比或定量模型等表示，把最小充分证据、最强反证、边界与未知组织在同一观看过程里。

- 用户打开后直接面对有观点、有来路、有证据边界的第一版展演，不从空白开始创建或整理。
- 人的主要动作是追问、质疑、比较、换尺度、看来源、看反证、推演和作出判断，不是拖动节点、画线和维护布局。
- Axiom 根据人的问题在原地重构展演，同时保留旧解释、变化位置与竞争分支。
- 白板布局只是当次解释，不直接写回 Atlas；只有证据、边界、竞争解释和人的判断引发的认识状态变化，才可能经治理更新长期地形。
- 检索分数、弱候选关系、Agent 内部过程和工程谱系默认留在中枢，需要时只在 Foundry 审计。

火山杯 Learning Board 仍是独立竞赛项目，其代码与交付不定义 Axiom 白板。Axiom 可借鉴画布能力，但产品形态以 `docs/discovery_cortex/08_WHITEBOARD_CO_DISCOVERY_ENVIRONMENT.md` 和 `09_ATLAS_WHITEBOARD_CONTINUUM.md` 为准。白板不是一级工作台，而从当前问题按需展开。

## 内部认知循环

```text
发生了什么
→ 它与什么有关
→ 哪些异常、矛盾或未知值得追问
→ 哪些规律、结构和远域类比可能解释它
→ 形成竞争假说与可区分预测
→ 选择信息价值最高的观察或实验
→ 哪项发现值得进入人的意识
→ 是否需要行动，以及最小可逆试探是什么
→ 预测和行动结果如何
→ 人的理论、世界的理论与发现方法怎样修正
```

系统始终区分：

- **原始事实**：用户真正输入、上传或做过的事情，不被 AI 改写。
- **AI 推断**：带来源、置信度和适用范围的候选理解。
- **规律与模型**：保留形式化陈述、假设、边界、反例和证据地位的可迁移机制。
- **假说与机会**：尚未证实但可证伪、带预测和停止条件的候选认识。
- **用户意图**：由用户确认的目标、承诺和选择。
- **执行结果**：事情后来是否发生，以及真实反馈是什么。

读取和总结可以自动发生；形成长期记忆、改变承诺和执行外部写操作需要与风险相称的确认。

## 行动与记忆

下一步不只按截止日期排序，还应考虑目标贡献、当前时间与精力、解锁作用、不处理的后果、启动成本和近期惯性。默认只突出一个主要行动。

基础判断只使用系统已经掌握的事实：截止压力、用户明确设置的优先级、预估启动成本、生活线近期活动、搁置时长、用户明确选择的本周行动，以及行动与确认目标之间的显式关联。每次判断都必须说明主要理由和可核对的线索；内部权重只用于保持结果稳定，不直接伪装成用户可理解的结论。

目标贡献只能来自用户确认的目标和显式行动关联，并保持为有上限的辅助信号，不能覆盖行动自身的明确期限。已设置的目标日期可以提供较弱的时间边界，暂停或结束的目标不再贡献排序。精力、依赖关系和影响后果尚未进入数据模型时，系统不得自行补全；以后接入这些信号时，也必须保留来源并允许用户修正。

从“此刻”完成行动时，系统应保留当时为什么推荐、用户是否执行以及之后的轻量适配反馈。完成本身是隐式结果；“正合适 / 比预期费力 / 时机不对”是显式反馈，两者不能混为一谈。

单次显式反馈只影响近期判断并随时间衰减：它可以短期调整相近时长或同一生活线的权重，但不能覆盖明确期限，也不能直接固化为长期用户画像。没有时长、生活线或其他依据时，系统只保存反馈，不向其他任务外推。

并非每条记录都成为长期记忆。长期记忆必须保留来源、情境、置信度、可能的过期时间和后续证据，并只在相关时刻自然出现。

## 产品边界

- **MemoryGuard** 是独立的鸿蒙杯项目。Axiom 可以吸收其记忆预览、确认、审计和可撤销原则，但不把它做成新入口或运行依赖。
- **Learning Board** 是火山杯独立竞赛项目；**Axiom 白板** 是按问题生成的认知展演面。两者可以复用基础能力，但导航、数据、产品本体和交付保持独立，Axiom 白板也不是一级工作台或用户创作画布。
- **Cosmos** 是 Atlas 的结构编辑和调试能力，不与 Atlas 并列成为用户产品。
- **聊天** 是上下文中的交互方式，不是覆盖全产品的悬浮入口。

## 判断新功能是否属于主线

新功能至少应改善下面一项，否则不进入 Axiom 主界面：

1. 记得更准确，并保留依据。
2. 更快找到当前需要的上下文。
3. 把长期目标转成此刻可执行的下一步。
4. 通过结果和复盘证明系统在变得更懂用户。
5. 更早发现用户尚未提出的高价值问题、规律、异常或结构变化。
6. 通过可证伪假说、低成本实验和机会判断扩大用户的可能性空间。
