平面区域面积

本节目标：把两条曲线围成的区域写成定积分。

这个知识点解决什么问题

平面上几条曲线围成一块区域，要求这块区域的面积。以 y = x 和 y = x² 为例，先确定区域边界，再把区域切成细条相加。

先求交点

左右边界来自两条曲线的交点。令 x = x²，把等式移到一边并因式分解：

所以积分区间是 [0,1]。

积分上下限不能凭图估计，先解交点。

判断谁在上面，再写一条竖条

在 0 < x < 1 内取 x = 1/2：x = 1/2，x² = 1/4。所以 y = x 在上，y = x² 在下。

在 x 处取一个宽为 dx 的窄条。把高度记为 h = x − x²，因此：

dS = (x − x²)dx

写成“下 − 上”会得到负值；长度本身不会为负。

把所有细条加起来

先用有限个窄条近似。窄条继续分裂，宽度趋近于零，有限和就过渡为定积分。

因此面积为：

S = ∫01(x − x²)dx

得到一般形式

如果在 [a,b] 上，f(x) 始终位于 g(x) 上方，那么：

S = ∫ab[f(x) − g(x)]dx

对 x 积分写“上减下”；积分上下限来自左右交点。

上下关系在区间内交换时，必须在交换点分段。

竖切与横切是同一块面积

竖切时，高度是 x − x²；横切时，同一区域的左边界是 x = y，右边界是 x = √y。

切法不同，微元方向不同；被覆盖的几何区域没有改变，所以两式都等于 1/6。

做题顺序

求交点 → 选 dx 或 dy → 判断上下或左右 → 列式计算。

面积结果不会为负。出现负数通常说明“上减下”或“右减左”写反了，不应直接取绝对值掩盖错误。

自测

求 y = 4 − x² 与 y = 0 围成的面积。交点为 x = −2，2，正确列式是：

S = ∫−22(4 − x²)dx

答案：32/3

小结

对 x 积分：上减下。

对 y 积分：右减左。
